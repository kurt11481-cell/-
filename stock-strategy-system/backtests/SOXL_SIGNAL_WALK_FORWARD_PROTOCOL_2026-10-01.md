### A2. Builder 명확화(2026-10-01 계획 승인분, 결과 전 확정)

데이터·달력
- 종료일은 수집 시점의 마지막 완료 세션이며 소스 JSON에 기록한다. 이후 바꾸지 않는다.
- 시작일: SOXX 2010-01-04, QQQ 2010-01-04, SOXL 2010-03-11, TQQQ 2010-02-11(각 상장일). 벤더 첫 행이 다르면 멈추고 보고한다.
- 휴장일은 규칙 생성기로 만들고, 2018-09~2026-07 구간은 기존 손입력 목록(`walk_forward_soxl_policy_2026-08-05.py`)과 완전 일치해야 한다. 조기 종료일은 규칙 생성 + 기존 목록의 합집합.
- 세션 누락·중복, 시가 0/결측, 허용오차 초과 종가 불일치(분할 기준 정렬 후)는 합성·보간 없이 멈추고 보고한다.
- Nasdaq이 제공하지 않는 세션은 "Yahoo 단일 출처"로 표시하고 계속한다(세션 목록 기록).
- 가격: Yahoo `adjclose/close` 배율을 시·고·저·종에 적용한 조정가로 수익률을 계산한다(갭 = 조정 시가 / 전일 조정 종가 − 1, 장중 = 조정 종가 / 조정 시가 − 1). 체결가는 그날의 시가다.
- 거래량: 신호 종목(SOXX) 거래량. 조기 종료일(당일 또는 전일)과 분할일은 거래량 조건을 불충족으로 처리한다(fail-closed). 종가 신호 자체는 조기 종료일에도 유효하다.
- FRED DGS3MO 수집 실패 시 0% 이자로 표시하고 신호 규칙에 불리한 편향임을 적는다.

체결 엔진
- 목표 비중과 종가 기준 현재 비중의 차이가 조정 폭(기본 10%p) 이상일 때만 다음 시가에 목표로 이동한다. 0에서 진입하거나 0으로 탈출하는 경우는 폭과 무관하게 항상 체결한다. B1은 목표가 바뀔 때만 체결한다.
- 폴드 경계에서 선택 변형이 바뀌면 폭과 무관하게 새 변형의 목표 비중으로 다음 시가에 전환한다.
- 각 변형은 첫 유효 신호 전까지 현금이다(B0는 상장 후 첫 시가부터 보유). 시험 구간은 연속 실행 경로에서 이어받은 비중과 미체결 주문으로 시작하고 자산은 1.0으로 정규화한다.
- 시가 결측·0이면 그 세션의 체결 동작을 동결하고(미체결 유지, 카운트 기록) 시가 이후 구간은 종가 대 전일 종가로만 평가한다. 새 신호가 나오면 이전 미체결을 대체한다.
- 비용 = 체결 비중 × 비용률. 현금 이자는 직전 세션 종가 시점 현금에 그 세션 이전에 공표된 DGS3MO를 적용한다.
- cap = 0.633(민감도 0.517)을 문자 그대로 쓴다(1.9/3, 1.55/3이 아님).

C2 상태 기계 처리 순서
- 전체 단계: 탈출 검사(−k 급락 또는 ref_high 낙폭) → 탈출이면 rally_low = 종가, rally_day = 0.
- 0 단계: rally 갱신(종가 < rally_low면 갱신·rally_day = 0; 아니면 rally_day 규칙) → 1단계 검사(rally_day ≥ 4, 당일 ≥ +g, 거래량 조건).
- 1단계: −k 급락 → 0; 종가 < rally_low → 0(rally_low 갱신, rally_day = 0); 그 밖에 2단계 조건이 참이면 전체(전체 진입일 = t). 1단계 진입일에는 2단계를 검사하지 않는다.
- ref_high는 [max(전체 진입일, t−19), t] 종가의 최댓값이다. 최초 유효 신호일이 첫 전체 진입일이다.
- 신호 유효 시작: SOXX SMA50과 20세션 표준편차가 모두 계산되는 첫 세션.
- σ 계산은 ddof = 1(표본 표준편차), EMA는 `adjust=False`.

선택·게이트
- 선택 후보: C1 계열 6개(기본 + 이웃 5), C2 계열 8개(기본 + 이웃 7). 조건을 만족하는 후보가 없으면 B0를 유지한다. 동률 순서: Calmar → 회전율 → 규칙 단순성(기본 < 이웃, 목록 순서). 통합 선택(C1·C2·C3 15개)은 보고만.
- 학습 구간 지표는 연속 실행 경로를 학습 구간으로 잘라 계산한다(시험 구간 자료 미사용). 비용 스트레스·0% 이자에서도 선택 스케줄은 10bp 기본 결과로 고정하고 재시뮬레이션한다.
- 게이트 판정 행: C1-WF, C2-WF, C1 기본, C2 기본, C3 기본. B1과 QQQ→TQQQ는 보고만.
- G3 "같은 방향": 폴드 MDD가 B0보다 얕으면 개선 폴드. 폴드 수익률이 B0보다 높은 폴드 수(기존 프로토콜 방식)를 병기한다. 개선 폴드에 약세(SOXX 폴드 수익률 < −10%) 또는 고변동 폴드와 강세(> +10%) 폴드가 각각 1개 이상 있어야 한다. 국면 라벨은 사후 보고용이며 규칙 선택에 쓰지 않는다.
- G4: (a) 20bp에서 G1·G2 통과, (b) 50bp에서 B0(같은 50bp) 대비 MDD가 얕고 Calmar가 높음, (c) 이웃 규칙(A1-4). C3는 이웃이 정의되지 않아 (c)는 "해당 없음"으로 표시하고 차단하지 않는다.
- G5: 폴드별 (후보 수익률 − B0 수익률)의 양의 부분 합 중 한 폴드 몫이 50%를 넘으면 실패. 양의 초과가 없으면 "해당 없음"(통과 처리, 표시).
- G6: C2·C3는 시험 구간의 "탈출(전체 → 0) 뒤 전체 재진입" 완결 사이클 수(탈출 횟수 병기). C1은 목표 비중/cap이 0.8 미만으로 내려갔다가 0.95 이상 복귀한 뒤 다시 내려간 경우만 센다. 20 미만이면 "검토 전용". WF 행은 해당 변형이 선택된 폴드 구간의 사건만 센다.
- 추가 보고 산출 범위: 급락 구간표·상위 20일 보유 여부는 워밍업 이후 전체 이력에서 산출하고 1차 OOS 안의 구간은 OOS로, 나머지는 "설계 참고(in-sample)"로 표시한다.
- 시작일별 252세션 −10%/−20% 도달 확률: 1차 OOS 안에서 252세션 창이 OOS 끝까지 완전히 들어가는 시작일만 센다.
- 급락 구간: SOXX 종가가 직전 최고 종가 대비 −25% 이하로 내려간 구간(고점일 ~ 신고가 회복 전 최저 종가일).
- 보조 OOS 두 구간은 폴드 규칙만 같고 보고 전용. QQQ→TQQQ는 기본 파라미터만 실행하고 선택하지 않는다. 미래 정보 없음 검증(잘린 이력 ≥ 8개)은 self-test(합성 데이터)와 실행 시 실제 데이터 양쪽에서 수행한다.
