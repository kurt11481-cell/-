# SOXL 여유 비례 + 변동성 조정(CPV) 시작일 이동 창 검증 사전 등록 (2026-10-01)

## 상태와 권한

- 목적: 사용자 손실 예산(기준 자산 대비 최대 −20%)을 바닥으로 지키면서 레버리지를 남은 여유에 비례시키는 규칙(CPV)을 결과 계산 전에 고정하고 검증한다.
- 성격: 과거 연구 전용. 브로커 상태를 읽거나 바꾸지 않고, 키움 도구를 쓰지 않으며, 주문·수량 권한이 없다. `order_authority=false`, `quantity_authority=none`.
- 결과 등급: D/C 등급 연구. 정책 반영·활성화는 S5 제안 → S6 Judge → S7 사용자 승인 → forward shadow 뒤이며, 이 연구 결과만으로는 활성화 권한이 없다.
- `alert_policy.json`, `portfolio_state.json`, `workspace/policies/*`, S4 파일(러너·입력·결과)은 바꾸지 않는다.
- 결과를 본 뒤 파라미터·규칙·게이트를 바꾸지 않는다. 추가 탐색은 "post-hoc"으로 표시하고 판정에서 뺀다.
- 고정 시점: 2026-10-01, 결과 계산 전. 러너는 이 파일의 해시가 sidecar와 다르면 실행을 거부한다.

## 1. 데이터

- 실제 구간 A: S4 입력(`soxl_signal_inputs_2026-10-01`)의 SOXL·SOXX 결합본과 DGS3MO, 2010-03-11~2026-09-29.
- 미사용 구간 U(합성): ^SOX 1994-05-04~2010-03-10. 합성 3배 일간 수익률 = 3 × 지수 일간 수익률 − 0.0095/252 − 2 × (DGS3MO/100)/252.
- 보조(보고만): ^NDX 합성 3배를 같은 방식으로 만든다.
- 합성 검증(보고만): 2010-03-11~2026-09-29 겹치는 구간에서 합성 3배(^SOX)와 실제 SOXL의 일간 수익률 차이(평균, 표준편차, 연 누적 차이). SOXL 기준 지수 변경 가능성은 "확인 필요"로 표시한다.
- 수집: ^SOX·^NDX(1994-05-04~) Yahoo 일봉(단일 출처), FRED DGS3MO 전체 기간(S4 입력은 2009-12부터라 U에 쓸 수 없음). 수집 실패나 세션 누락이면 멈추고 보고한다(합성·보간 금지, 금리 결측은 직전 값 유지만 허용하고 개수 기록).

## 2. 체결과 비용

- A: S4와 같다(종가 t 결정 → t+1 정규장 시가 체결, 갭 포함).
- U: 지수 시가 품질 때문에 종가 t 결정 → t+1 종가 체결(하루 지연).
- 비용: 체결 비중당 10bp 기본, 20bp·50bp 스트레스. 현금: DGS3MO 이자 + 0% 민감도. 세금·환율 제외.

## 3. 규칙 CPV 기본값

- 기준 자산 A0 = 창 시작일 자산. 바닥 F = 0.80 × A0(창 안에서 고정).
- 여유 c = max(0, (E − F) / E).
- 변동성 조정 v = min(1, med / σ20). σ20 = 그 레버리지 상품(A: SOXL, U: 합성 3배) 일간 수익률 최근 20세션 표준편차(t 포함), med = 그 계열 데이터 시작부터 t까지 σ20의 확장 중앙값(최소 120개).
- 목표 비중 w* = min(0.633, m × c) × v, m = 2.0. E ≤ F면 w* = 0이고 그 창이 끝날 때까지 현금(잠금, 자동 재시작 없음).
- 조정: |w* − w| ≥ 10%p, 또는 w* = 0 < w, 또는 w = 0 < w*일 때만 체결.
- 이웃(하나씩): m 1.5/2.5, σ 창 15/30, 변동성 조정 없음(v = 1), 조정 폭 5%p/15%p. 보고만: 바닥 올림(F = 0.8 × 창 안 최고 자산).

## 4. 기준선

- B0: SOXL 0.633 고정(10%p 조정).
- BAD: B0 + 손실선(E ≤ 0.90×A0 → 0.333 이하로 줄여 유지, E ≤ 0.80×A0 → 0 잠금).
- BV10: 0.333 × v(1.0배 + 변동성 조절, 손실선 없음).
- BF10: 0.333 고정(1.0배, 손실선 없음).

## 5. 평가: 시작일 이동 창

- 창 길이 1년(252세션)·3년(756세션). 시작일은 워밍업(σ 중앙값 최소 120개) 뒤 매 세션, 창이 해당 구간 안에서 끝나는 것만.
- 구간(시작일 기준): U(합성, 창 끝 ≤ 2010-03-10), A(실제, 창 끝 ≤ 2026-09-29). 세부 국면: U1 1994~99, U2 2000~02, U3 2003~07, U4 2008~09, A1 2010~15, A2 2016~20, A3 2021~25.
- 지표: 최종 수익 중앙값·평균·하위 25%, 창 중 최저 자산, 1년 뒤 −20% 이하 비율, 잠금 비율, −10% 도달 비율, 최악 최종 수익, 평균 유효 레버리지, 겹치지 않는 창 수.

## 6. 게이트: CPV 기본값

- H1 바닥 유지(필수): U·A와 모든 세부 국면, 두 창 길이에서 창 중 최저 자산 ≤ 0.78×A0 비율 ≤ 2%, 최악 최저 자산 ≥ 0.75×A0.
- H2 성장: A의 3년 중앙값 ≥ BV10 3년 중앙값의 90%(둘 다 양수일 때, 아니면 CPV ≥ BV10). U도 같은 기준으로 판정.
- H3 잠금: U·A와 모든 세부 국면에서 1년 창 잠금 비율 ≤ 15%.
- H4 견고성: 이웃 7개 중 과반이 H1·H3 통과. 20bp에서 H1~H3 통과, 50bp에서 H1 유지. 현금 이자 0% 결과 병기.
- H5 미사용 구간: U에서 H1·H3 통과(m은 2010년 이후 데이터를 보고 정했으므로 U가 유일한 깨끗한 검증이다).
- H6 표본: 겹치지 않는 1년 창 수(U·A 합계)를 보고.
- 판정: 모두 통과 → "S5 제안 후보(forward shadow 필요)". H1·H3·H5 중 하나라도 실패 → 기각. 그 밖의 실패 → 검토 전용.

## 7. 추가 보고(게이트 아님)

- 기준선 대비 표(U·A·세부 국면), 이웃 표, 합성 검증 표.
- 급락 국면(2000~02, 2008, 2020, 2022, 2025) 시작 창의 CPV 경로 요약.
- 현재 조건 표시(보고 전용, 주문·수량 아님): 기준 자산을 2026-09-29 자산으로 둘 때 규칙상 유효 레버리지 상한(σ 조정 반영).

## 8. 사전 명시

- m = 2.0은 Cowork가 2011~2025 실제 데이터에서 m 1.5/2/3 재현을 본 뒤 고른 값이다(in-sample). A 결과에는 설계 오염 가능성이 있다.
- 2010년 이전 구간은 이 규칙에 한 번도 쓰지 않았다(Cowork는 S3b에서 변동성·휩쏘 통계와 1배 200일선 필터 비교만 계산했고 CPV·손실선 규칙 성과는 계산하지 않았다).

## 부록 1. 구현 명확화 (결과 전 추가, 2026-10-01, 사용자 승인)

1. 창 정의: 창의 첫 세션을 s, 끝 세션을 z = s+L−1(L = 252 또는 756)로 둔다. s−1 종가에 A0 = 1.0, 전액 현금 상태로 시작하고, 첫 결정은 s−1 종가(E = A0, w = 0)에서 한다. 체결은 A에서 s 시가, U에서 s 종가다. 첫 결정에서 c = 0.2이고 w* = 0.4 × v다.
2. 엔진: 목표가 E와 잠금에 의존하므로 S4 `simulate`(목표 배열 선입력)를 쓰지 않고 같은 산술의 새 엔진을 둔다. 동치는 self-test ⑦(목표 0.633 고정 시 S4 B0 재현, 상대오차 1e-12 이하)로 증명한다. 실행 속도를 위해 창 시작일 방향으로 벡터화한 러너를 두고, 스칼라 참조 엔진과 대조한다(부록 2-A).
3. U 체결: 시가를 종가로 대체한다(`O := C`). 당일 수익은 기존 포지션이 받고, 체결가는 그날 종가다.
4. 합성 3배: 금리는 S4 `rate_array` 규칙(t 이전 마지막 관측, 미래 정보 없음)을 쓴다. 일수익률이 −100% 이하이면 clip하지 않고 멈춘다. 합성 계열의 σ·중앙값은 합성 데이터 시작부터 계산하며 실제 SOXL 계열과 이어 붙이지 않는다. 일간 차입·비용 차감은 세션마다 고정(/252)이다.
5. 워밍업: 모든 설정이 같은 창 집합을 쓰도록, s−1이 σ 창 15·20·30의 중앙값이 모두 유효해지는 첫 세션(σ 창 30 기준: σ 첫값 + 중앙값 120개) 이상인 창만 쓴다.
6. 구간 배정: 창은 시작 세션 s의 날짜로 U·A와 세부 국면(달력 연도)에 배정한다. 2010-03-10과 11 경계를 걸치는 창은 제외하며 이어 붙이지 않는다. U 합성 계열은 전체 기간으로 만들어 σ·중앙값을 계산하되(인과적), U 창은 끝 ≤ 2010-03-10만 쓴다.
7. 빈 칸: 창 끝 조건 때문에 창이 없는 칸(예: 3년 창의 U4)은 "해당 없음"으로 보고하고, 해당 게이트에서는 제외한다.
8. 기준선: BAD의 0.90 선(→ 0.333)과 0.80 선(→ 0)은 한 번 걸리면 창 끝까지 유지한다(자동 복귀 없음). 판정은 종가 E로 한다. BV10·BF10의 "1.0배"는 3배 상품 비중 0.333이며, BV10의 v는 CPV와 같은 σ20 계열이다. 모든 기준선도 10%p 조정 폭과 같은 체결 규칙을 쓴다.
9. H4 판정: 이웃 7개는 기본값과 같은 칸(U·A, 세부 국면, 두 창 길이)에서 H1·H3를 동시에 통과해야 "통과"이며 4개 이상이면 과반이다. 20bp·50bp 검증은 같은 비용의 기준선(H2의 BV10)과 비교한다.
10. 겹치지 않는 창 수: 각 구간에서 유효 창 시작 세션이 걸치는 기간의 세션 수를 창 길이로 나눈 몫(floor)이다.
11. 달력: S4 생성기는 2009년부터라 이 러너에 1994~2008 휴장을 추가한 생성기를 둔다(MLK 1998년 이후, 2001-09-11~14, 2004-06-11, 2007-01-02, 그 밖의 S4 휴장 규칙). Yahoo 세션이 생성 달력과 다르면 멈추고 보고한다.
12. 통계 정의: 창 중 최저 자산 = A0를 포함한 s−1..z 종가 자산 최저 / A0. "1년 뒤 −20% 이하 비율" = 창 끝 최종 수익 ≤ −20%인 창 비율. "−10% 도달 비율" = 창 중 최저 자산 ≤ 0.90×A0인 창 비율. 잠금 비율 = 창 안에서 잠금이 한 번이라도 걸린 창 비율. 평균 유효 레버리지 = 3 × 창 안 종가 기준 비중 평균. 상위 요약은 창 길이와 칸별로 낸다.

(13~16은 1~12 승인 뒤 사전 등록 문서화 중 Builder가 추가한 보고 전용 구체화이며 게이트 판정에 영향을 주지 않는다. 결과 전 추가이고 사용자 확인 필요로 보고서에 표시한다.)

13. 급락 국면 시작 창(보고 전용): 해당 연도 첫 세션에서 시작하는 창 — 2000-01-03, 2008-01-02(U), 2020-01-02, 2022-01-03, 2025-01-02(A). 창 길이 252·756 중 창 끝 조건을 만족하는 것만 낸다. 요약: 최저 자산과 날짜, 잠금 날짜, 63·126·252세션 자산, 최종 수익, 최대·평균 비중, 체결 횟수(CPV, 비교용으로 BAD·B0 최종 수익과 최저 자산).
14. 현재 조건 표시(보고 전용, 주문·수량 아님): 2026-09-29 종가 기준 v(σ 창 20)와 규칙 유효 레버리지 = 3 × min(0.633, 2.0 × 0.2) × v(기준 자산 = 그날 자산일 때, c = 0.2), 그리고 구조적 상한 3 × 0.633 × v를 병기한다.
15. ^NDX 합성 3배 보조(보고만): 1994-05-06 이후 전 구간을 종가 체결(하루 지연)로, CPV와 기준선 4종을 10bp·현금 이자 포함으로 같은 창·같은 통계로 계산하고 시작 연도 기준 국면(U1~A3 정의 동일, 접두어 N)별로 낸다. 게이트에는 쓰지 않는다.
16. ^SOX 이상치 중단 규칙(부록 2-B의 구체화): ^SOX와 Yahoo SOXX(2001-07-13~2010-03-10)의 같은 날 일간 수익률 차이가 8%p 이상인 날이 하나라도 있으면 `--run`은 결과를 계산하지 않고 해당 날짜 목록과 함께 멈춘다(자동 수정 없음). SOXX가 없는 기간의 |r| ≥ 15% 날은 "교차검증 불가(확인 필요)"로 목록만 싣고 멈추지 않는다.
