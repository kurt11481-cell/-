# 정책 v4 보완 및 walk-forward 활성화 판정

## 최종 결론

현재 정책은 **안전 권한을 줄이는 네 가지 변경만 활성화**한다.

1. SOXL의 `weakness_10ema` 단독 신호는 감축이 아니라 `B/관찰`, 수량
   `null`로 처리한다.
2. 확인된 감축 체결 뒤에는 관련 EMA 회복과 3개 완료 세션을 모두
   확인해야 다음 기술적 약세 슬롯이 재무장된다.
3. 과도한 갭과 명시적 거래정지는 기존 수량 후보를 취소하고
   `B/관찰`, 수량 `null`로 낮춘다. 거래 가능한 가격이나 체결을
   추정하지 않는다.
4. 캘린더·종목 정체성·동일 세션 OHLCV·독립 종가 교차검증·지표 공식
   재계산·출처 원장을 매번 검증한다.

반면 **재진입, 피크 손실, time-stop, 동적 총 레버리지 상한, MA/MACD/
RVOL/Stochastic/Chaikin 추가 투표는 활성화하지 않는다.** 사전등록한
5년 다중국면 walk-forward를 실행할 원자료가 부족하여 결과가
`failed_closed`, `activation_eligible=false`이기 때문이다.

현재 브로커 가용현금은 USD 0이다. 따라서 기술 조건을 충족하더라도
신규 매수·재진입은 `Watch/Wait`, 수량 `null`이다. 확인되지 않은
매도대금은 현금으로 계산하지 않는다. NBIL 1주는 반복 알림에서
무시할 수 있는 de-minimis 예외지만, 실제 계좌 레버리지 산술에는
포함한다.

2026-08-06 08:13 KST에 검증된 source Skill을 전역 설치 경로에
동기화했다. SKILL.md, evaluator, timing engine, 관련 reference의 해시가
일치했고 설치본 31개 테스트가 모두 통과하여 자동 모니터 deployment
gate를 다시 열었다.

## 현재 활성 규칙

### SOXL

- 보유 99주, 기준 평균단가 USD 123.3251.
- 평균단가 기준 최대손실 검토선은 미반올림 USD 98.66008이다.
- 공통 감축 검토 슬롯은 24/24/24주이고, 27주는 hard-risk 또는 별도
  사용자 지시 전까지 잔여 보유분이다.
- 10EMA 약세 단독: 관찰만, 슬롯 미소비.
- 20EMA 약세·failed reclaim·technical stop·승인된 과열 거부: 다음
  공통 슬롯의 B등급 사람 검토 후보가 될 수 있다.
- 신호는 체결이 아니다. 사용자 확인 체결 전에는 슬롯·보유수량·현금을
  바꾸지 않는다.

### 감축 뒤 재무장

```text
ARMED
→ 신호 관측
→ B 검토 후보
→ 사용자 확인 체결
→ LOCKED
→ 관련 EMA 회복 + 3개 완료 세션
→ REARMED
→ 이후 새 false→true 약세만 다음 슬롯 검토
```

- 20EMA 약세, failed reclaim, technical stop, 과열/익절 거부는 EMA20을
  회복 기준으로 사용한다.
- 보유 ETF와 확인 프록시가 동일한 완료 세션에 관련 EMA 위에서
  마감해야 한다.
- technical stop도 재무장을 우회하지 않는다.
- 수량 없는 평균단가 hard-risk D 검토만 재무장을 우회한다.
- 체결 세션·원인·수량이 빠지면 fail closed한다.

### 갭·거래정지·데이터 오류

- 절대 시가 갭이 `max(5%, ATR14/전일 종가)`를 넘거나 기술적 stop을
  통과하면 기존 수량 후보를 취소한다.
- 명시적 halt/pause/suspension만 거래정지로 본다. 거래량 0만으로
  거래정지를 추정하지 않는다.
- 첫 거래 가능 정규장 OHLCV 또는 보유종목 완료 종가가 없으면 F로
  동결한다.
- 갭이나 거래정지 가격에서 체결됐다고 추정하지 않는다.

## 비활성 연구 규칙의 확정 설계

### 감축 후 재진입

재무장과 재진입은 별도 상태로 관리한다. 미래 활성 후보의 최소 조건은:

- 확인된 매도 슬롯과 체결 세션·원인·수량 존재;
- SOXL과 SOXX가 각각 EMA20 위에서 2개 연속 완료 종가;
- 양쪽 모두 EMA10>EMA20이고 EMA20 상승;
- 승인된 pullback/reclaim 또는 breakout/acceptance;
- 과도한 갭·halt·hard-risk·데이터 오류 없음;
- 양의 검증된 가용현금, 위험예산, 총 레버리지 여유 존재;
- 복원 수량은 `매도 슬롯·현금·위험예산·레버리지 상한` 중 최솟값;
- 조건 유효기간 10개 완료 세션, 최대 복원비율 후보 25/50/75/100%.

현재 현금 0에서는 언제나 수량 `null`이다. 기본방향이 감축인 MVLL은
재진입 대상이 아니다.

### 피크 손실과 time-stop

- 피크 손실 후보: 활성일 이후 완료 종가 고점 기준 20/25/30/35%.
  SOXL과 SOXX 모두 EMA20 아래인 새 breach만 검토한다.
- 기존 잔여 보유분의 HWM은 부분 감축으로 초기화하지 않는다. 새
  재진입 슬롯은 별도 HWM을 가진다.
- time-stop 후보: 새 진입·재진입에만 10/20/30 완료 세션, MFE<0.5R,
  양쪽 EMA20 하회. 기존 보유분에는 소급 적용하지 않는다.
- 두 규칙 모두 현재 `active_candidate_generation=false`이다.

### 동적 총 레버리지 상한

LLM이 매일 서사에 따라 숫자 상한을 올리는 방식은 금지한다. 검증용
결정론적 산식은:

`총 유효 레버리지 = 3×|SOXL 비중| + 2×|MVLL 비중| + 2×|NBIL 비중|`

`반도체 클러스터 = 3×|SOXL 비중| + 2×|MVLL 비중|`

2026-08-05 브로커 표시 평가액을 그대로 사용한 참고치는 각각 약
2.557x와 2.555x다. 이는 완료 종가로 재검증한 실시간 수치가 아니다.

SOXL 단독 연구 tier는 0.75/1.50/2.25/3.00x로 사전등록했다. 그러나
SOXL 단독 결과로 MVLL·NBIL을 포함한 계좌 상한을 승인할 수 없다.
계좌 전체 OOS에서 MDD 5%p 이상 개선, 회복기간 10% 이상 단축,
기준 CAGR 90% 이상 유지가 필요하다.

## 추가 지표 판정

5년 수익률 우열을 계산하지 못했으므로 어떤 후보도 활성화하지 않는다.

| 지표 | 현재 역할 |
|---|---|
| SMA20 | EMA20과 중복성이 높아 대체 ablation만 |
| SMA50 | 중기 국면 필터 후보 |
| SMA60 | SMA50의 대안이며 동시 투표 금지 |
| SMA200 | SOXX 장기 국면·향후 재진입 필터의 우선 후보 |
| MACD(12,26,9) | EMA 추세와 중복성이 높아 보조 ablation만 |
| RVOL20 | 가격과 다른 거래량 차원이지만 공식 재계산 필수 |
| Stoch(20,3,3) | 향후 재진입 보조 후보만 |
| Chaikin(3,10) | 저우선 연구; 기관 매집 지표로 단정 금지 |

현재 최소 세트는 EMA10/20, ATR14, RVOL20, prior price structure이다.
SOXX SMA200과 기울기는 향후 재진입 연구 필터일 뿐, 현재 매수 권한을
만들지 않는다.

## 향후 활성화 기준

원자료를 확보해도 다음을 모두 만족해야 한다.

- 10개 fold 중 7개 이상, bull과 bear/high-vol 모두 개선;
- CAGR +5%p와 MDD 악화 3%p 이내, 또는 MDD +5%p 개선과 기준 CAGR
  95% 이상 유지;
- Calmar 10% 이상 개선;
- 20bp 비용 통과, 50bp에서도 방향 우위 유지;
- 인접 파라미터 안정성, 단일 fold가 초과수익의 50% 미만;
- 독립 trigger/re-entry cycle 20회 이상;
- 이후 3~6개월 또는 독립 신호 20회의 전향 shadow 검증.

주문을 전송하거나 예약하지 않았고, 체결·매도대금·보유수량 변경을
추정하지 않았다.
