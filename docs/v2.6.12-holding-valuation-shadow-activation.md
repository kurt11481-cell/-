# v2.6.12 Holding Valuation and Shadow Activation

## Scope and authority

This change adds deterministic, non-authoritative research infrastructure for
SOXL, MVLL/MRVL, and NBIS. It does not change the live strategy, portfolio,
provider scope, quantities, hard-risk thresholds, rearm rules, or order
authority. `order_authority=false` remains mandatory.

The starting `origin/main` commit was
`18ed98e51ec649cafebfe99592daa5a454a79736`. The rollback branch is
`backup/pre-holding-valuation-shadow-activation-20260814-140013`. The feature
branch is `feature/v2.6.12-holding-valuation-shadow-activation`.

## Architecture

The existing four-layer ownership model remains intact:

1. canonical instrument profile;
2. immutable slow research baseline;
3. completed-session overlay;
4. deterministic context compiler.

The new issuer valuation snapshot is an immutable point-in-time input. It uses
only a finalized Kiwoom Raw regular-session close for Primary price authority,
with yfinance as diagnostic Shadow. Basic, base-diluted, and stress-diluted
share counts remain separate. Cash, restricted cash, debt, secured financing,
preferred claims, and other claims also remain separate. The formula version is
`holding-valuation-v2.6.12-1`.

The event-link artifact binds a candidate baseline hash to the active event
bundle hash. Product and supplemental issuer links are distinct. The
non-authoritative compile consumes the candidate baseline, valuation when
applicable, current overlay, current event link, current portfolio state, and
versioned policies. Only a `PASSED` compile can enter per-ticker atomic Shadow
activation.
