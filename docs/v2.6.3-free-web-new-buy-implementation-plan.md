3. Extend Web evidence semantics without creating a second close resolver.
4. Extend Shadow policy and audit logic to 1/5/10/20/60 sessions with exact
   scoped, explicit-user-approval-only promotion.
5. Update the automation contract, localized messages, CI hygiene checks, and
   documentation.
6. Add offline fixtures and tests for Massive-free startup, new-buy separation,
   Web routes, leveraged products, staged promotion, broker/Pre-Open safety,
   and invariants.

## Safety invariants

- `order_authority=false` everywhere.
- No share quantity is generated.
- No portfolio, cash, fill, cost-basis, timing-quantity, rearm, or hard-risk
  threshold mutation.
- Watchlist approval remains separate from new-buy approval.
- Web MATCH changes only price-evidence status and cannot promote execution.
- Manual smoke, replay, and route acceptance never count as operational
  Scheduled Task sessions.
