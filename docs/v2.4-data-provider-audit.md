# v2.4 Data Provider Audit

## Completed-session data

- Primary raw collector: `yfinance` with the existing sequential, bounded,
  non-pre/post-market contract.
- Independent completed-close adapter: implemented and fixture validated.
- Approved live independent provider: none configured.
- Current preflight: `UNAVAILABLE / NO_APPROVED_PROVIDER_CAPABILITY`.
- Live Tactical Radar readiness: `DATA_PROVIDER_BLOCKED`.

The source-capability registry now explicitly records the unconfigured
independent-close capability. It does not pretend that Alpha Vantage, Nasdaq,
or a second Yahoo endpoint is approved. A future provider must be enabled,
timestamped, point-in-time eligible, session compatible, and independent of the
primary builder before preflight can pass.

## Failure behavior

A provider-wide outage produces one `GLOBAL_INDEPENDENT_CLOSE_OUTAGE` incident
and zero ticker-level urgent notifications. The incident retains all seven
affected symbols, failure type, recovery trigger, delivery ID, and no order
authority. A single ticker mismatch/missing row blocks only that ticker; a
`PARTIAL` report may continue to show an unrelated valid candidate.

No retry storm, IP rotation, stale fallback, or silent provider substitution is
permitted.
