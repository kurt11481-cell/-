# FX-1009 fx-5a 사전 등록 — 위험 예산 대칭 리플레이와 채우기 기본 대상

## 0. 범위와 금지

- fx-5a만 한다. fx-5b(공통 규칙 C 기준값, R-RI1, R-REC1 재설계)는 하지 않는다.
- 과거 리플레이만 한다. 주문 도구·정책·상태·결정 일지·예약 작업·관제판 외 운영 파일은 바꾸지 않는다.
- 결과가 어떻게 나와도 위험 예산(1.55)·채우기 기본 대상(SOXL)·S5/S7 정책은 Independent Judge + 사용자 승인(K3) 전까지 그대로다(fx-0 Q9 a).
- 등급 상한 C(과거 재현, Yahoo 지수 단일 출처, 합성 상품). 실제 상품(SOXL·SOXX) 대조는 보고 전용이다. 계좌 금액·수량은 적지 않는다.

## 1. 질문

- A. 고정 위험 예산 1.00·1.32·1.55 가운데, R-REC1-X 도전안에 쓴 것과 같은 기준으로 다른 예산을 이기는 것이 있나? 현행 1.55는 그 잣대를 통과하나? (D3: 도전안에만 엄격한 잣대)
- B. 같은 목표 노출을 SOXL(3배 + 현금)로 채우는 것(현행 기본, S5 C.8)과 1배 코어를 먼저 채우는 것 중 같은 기준으로 이기는 쪽이 있나? 3배 상품의 경로 손실은 얼마인가? (D2)

## 2. 사전 지식 (계산 전 공개 — 기준을 결과에 맞추지 않았다는 근거)

- S5 정안 C.6 탐색표(D, 스크립트 미저장, 1배 + 3배·현금 0%·10bp·조정 폭 10%p): SOX 32년 연수익/최대 낙폭/최악 1년 = 1.0 15.1%/−88%/−64%, 1.32 16.2%/−96%/−76%, 1.55 15.5%/−98%/−84%. SOX 2010~ = 23.7/−47/−39, 28.4/−56/−49, 32.3/−64/−58. SOX 최근 5년 = 30.9/−47/−39, 39.2/−56/−49, 38.3/−64/−58.
- S4-3 고정 배수표: SOX 32년 1.00배 15.14%, 1.32배 15.67%.
- R-REC1-X의 B(고정 1.55, 매일 조정, ETF 코어): SOX 32년 15.06%/−98.51%/−84.45%, 2010~ 31.76%/−64.96%/−57.54%, NDX 17.08%, S&P 500 8.44%.
- 이 지식으로 예상할 수 있는 것: 높은 예산이 낮은 예산을 이기려면 b·d(낙폭·최악 1년)를, 낮은 예산이 높은 예산을 이기려면 a(+0.5%p)를 넘어야 한다. "어느 방향도 기준을 못 넘음"이 나올 수 있고, 그 경우도 그대로 결과로 쓴다.
- 기준 값은 R-REC1-X 사전 등록 4절에서 한 글자도 바꾸지 않았다. e(증액 표본)만 이 비교에 해당하지 않아 판정에서 뺀다(3-4절).
- B는 계산한 적 없다. 이론 메모: 매일 조정하면 두 구성 모두 하루 수익이 "목표 노출 × 지수 수익"에 가깝고 차이는 보수·금리·거래비용뿐이다. 3배 상품의 경로 손실(변동성 끌림)은 조정 사이에 비중이 흔들릴 때 드러난다. 그래서 B의 주 판정은 실제 S5 조정 규칙(목표 ±0.3을 벗어나면 조정)으로 정한다.

## 3. 규칙 (고정)

### 3-1. 공통 관례 (R-REC1-X 결과 문서 5절과 같음)

- 합성 상품: 3배 일간 = 3r − 0.0095/252 − 2 × 3개월 국채 금리/252, 1배 일간 = r − 0.0035/252(모든 시장 0.35%). 비용 = 거래 비중의 10bp. 현금 이자 0(주 판정). 배당 없음(가격 지수).
- 금리: 1981-09-01부터 DGS3MO, 그 전은 DTB3(S4-3 이음). S&P 500만 DTB3 구간을 쓴다.
- 시장(지수 자체 기준): SOX = cpv `SOX_yahoo_raw.csv`(1994-05-04~2026-09-29), NDX = cpv `NDX_yahoo_raw.csv`(1994-05-04~), S&P 500 = leverage_up `SPX_yahoo_raw.csv`(1954-01-04~). 첫 종가는 수익 기준점.

- 1년 창 최악 = 252세션 창 수익의 최저값(S4-3 w1_min). 기준 d의 차 = X의 최저 − B의 최저(S4-3 A3).
- 판정은 시작일 이동 0. 이동 0~9(앞에서 k개 종가를 버림)는 보고만 한다.

### 3-2. A — 고정 위험 예산 (주 판정)

- 후보: F1.00, F1.32, F1.55(목표 고정).
- 구성: ETF 코어 `core`(목표 T ≥ 1이면 3배 (T−1)/2 + 1배 나머지, 현금 0). 1.00 = 1배 100%, 1.32 = 3배 16% + 1배 84%, 1.55 = 3배 27.5% + 1배 72.5%.
- 조정: 매일(엔진 band 0), R-REC1-X의 B와 같다.
- 비교: 순서쌍 6개 (X, B) = (1.32, 1.00), (1.55, 1.00), (1.55, 1.32), (1.00, 1.32), (1.00, 1.55), (1.32, 1.55). 쌍마다 기준 a~d 판정.

### 3-3. B — 채우기 기본 대상 (주 판정)

- 같은 목표 T ∈ {1.00, 1.32, 1.55}에서 두 구성.
  - S = SOXL 채우기(현행 기본): 엔진 `cash3` — 3배 T/3 + 현금. 1.00 = 3배 33.3%, 1.32 = 44%, 1.55 = 51.7%.
  - K = 1배 코어 우선: 엔진 `core` — 1배를 100%까지 먼저 채우고, 1을 넘는 몫만 3배로(3-2와 같은 비중).
  - 뜻: 카드 종목 코어가 비어 있을 때 남은 노출을 무엇으로 채우나의 양 끝이다. 코어가 일부 차 있으면 비중이 두 구성 사이에 놓인다(계산하지 않음, 6절).
- 조정: S5 조정 폭 ±0.3(목표에서 0.3 이상 벗어나면 목표로 되돌림). 엔진 band 환산 — S는 band 0.10(E = 3w이므로 |Δw| ≥ 0.10 ⇔ |ΔE| ≥ 0.30), K는 band 0.15(현금 0에서 E = 1 + 2w₃이므로 |Δw₃| ≥ 0.15 ⇔ |ΔE| ≥ 0.30). K의 1.00은 1배 100%라 첫 체결 뒤 조정이 없다.
- 비교: 각 T에서 (X = K, B = S)와 (X = S, B = K) 두 방향, 기준 a~d. 판정 T = 1.55(현행 예산). 1.00·1.32는 보고하되, A에서 변경 후보가 나오면 그 T의 B 결과도 판정 칸에 함께 적는다.

### 3-5. 무엇이 채택 후보인가

- A
  - 변경 후보: F1.00 또는 F1.32가 X로서 B = F1.55에 대해 a~d를 모두 충족.
  - 현행 통과: F1.55가 X로서 B = F1.00과 B = F1.32 둘 다에 대해 a~d를 모두 충족(도전안과 같은 잣대 통과).
  - 둘 다 아니면: "우열 미확인" — 1.55는 "사용자 승인 위험 예산(미검증 현행안)" 그대로다.
  - (1.32, 1.00)·(1.00, 1.32)는 판정 범위 안의 쌍이지만 현행 예산을 바꾸는 근거는 아니다(D3의 S4-3 1.32 기준 완화 확인용).
- B (T = 1.55)
  - 변경 후보: K가 X로서 B = S에 대해 a~d를 모두 충족.
  - 현행 통과: S가 X로서 B = K에 대해 a~d를 모두 충족.
  - 둘 다 아니면: "우열 미확인" — SOXL 기본은 "사용자 결정(미검증)" 그대로다.
- 채택 후보가 나와도 Independent Judge(별도 Claude Code 세션) → 사용자 승인 → S7 Builder(정책 반영) 전까지 정책·예약 점검은 바뀌지 않는다. 실제 매수·매도에는 여전히 카드 근거(G3)·현금(G4)·위원회가 필요하다.

### 3-6. 보고 전용 (판정에 쓰지 않음)

- A: ① S5 조정 폭 ±0.3(core band 0.15) ② 조정 폭 10%p(core band 0.10, C.6 탐색 관례 — C.6 표와 대조) ③ 3배 + 현금 구조(cash3, band 0) ④ 시작일 이동 0~9의 판정 ⑤ 최근 구간 2016-01-01~·2021-10-01~(같은 연속 실행에서 자름) ⑥ 1배 보수를 S4-3 시장별 값으로(NDX 0.20%, S&P 500 0.09%) ⑦ 지표: 최악 하루, 고점 대비 −10%·−20% 도달 하락 구간 수, 고점 대비 −10% 이하 세션 비율, 평균 노출, 연간 조정 횟수, 3년 창 최악.
- B: ① 매일 조정(band 0) — ±0.3 조정과의 차 = 비중 흔들림 효과 ② 현금 이자 = 3개월 국채(S에 유리한 쪽) ③ 시작일 이동 0~9의 판정 ④ 최근 구간 ⑤ 실제 상품 대조(SOXL·SOXX 수정종가, 2010-03-11~2026-09-29, 엔진에 실제 일간 수익을 넣음; T = 1.00·1.32·1.55, ±0.3과 매일 조정) ⑥ 같은 지표 묶음.
- 경로 손실(보고): 창 길이 L ∈ {20, 60, 120, 252}세션, 모든 시작일, 조정 없이 보유. PL = (3배 보유 수익)/3 − (1배 보유 수익) — 노출 1단위로 맞춘 3배의 손실. 합성(SOX 32년·SOX 2010~·NDX·S&P 500)과 실제(SOXL/3 − SOXX, 2010-03-11~)의 최저·5%·중앙값·평균·음수 비율. 구간 점검 1개: 2026-06-22 종가 → 2026-09-29 종가(자료 끝)의 SOXL·SOXX·합성 3배·합성 1배 수익과 PL. 종목 프로토콜 a1 §27-1의 "6/22→10/2 SOXX −10.1%, SOXL −45.6%"는 자료 끝 뒤라 그대로 재현하지 않는다.

- 독립 재구현: 이 문서(부록 산식 포함)만 보는 별도 에이전트가 S4-3 엔진과 이 리플레이 스크립트를 보지 않고 새로 구현한다. 일치 기준 — 판정에 쓰는 값(각 시장·구간·구성의 연수익·최대 낙폭·1년 창 최악)이 |차| ≤ 1e-6, a~d 판정 전부 같음, 경로 손실 창 분포(중앙값·최저)가 |차| ≤ 1e-6. 불일치는 원인을 찾아 기록하고, 해소되지 않으면 결과 문서에 "대조 불일치 — 판정 보류"로 남긴다.

## 6. 한계 (미리 적음)

- 지수 기반 ETF 코어다. 실제 계좌의 카드 종목 코어(개별 종목, 실제 V, 실적 갭, 종목 고유 위험)는 재지 않는다.
- K의 1배 코어는 합성 1배 지수 상품이다. SOXX·SMH·USD는 사용자 조건으로 쓰지 않으므로 K가 이겨도 실제 상품 대응(카드 종목 추가 또는 승인 상품 재검토)은 S7 2단계 설계 몫이다.
- 코어가 일부만 찬 중간 상태는 계산하지 않는다(비중이 S와 K 사이).
- 현금 이자 0이 주 판정이라 현금을 많이 들고 있는 S에 불리하다 → 국채 이자 민감도로 보고한다.
- 현금의 선택권 가치(하락 뒤 매수 여력, R-REC1 취지)는 고정 규칙 리플레이로 재지 않는다.
- 노출 = 명목 노출(지수 기준). 실제 E = max(N, V)의 V(SOX 환산 변동성)는 지수 상품에서는 N에 가깝다고 보고 따로 계산하지 않는다.
- 기준 e(표본 수)는 해당 없음으로 뺐다. 다중 비교(A 6쌍 + B 2방향)라 한 쌍이 우연히 통과할 수 있다 — 채택 후보도 Judge가 다시 본다.
- 세금·환율·분할 매수·호가 차이 없음. S&P 500 1954~1961년은 장중 저가가 없으나 이 리플레이는 종가만 쓴다.

## 부록. 산식 (독립 재구현용 — 엔진 동작을 그대로 적음)

입력 만들기
1. 지수 종가 c₀…c_N(날짜순). 시작일 이동 k면 앞에서 종가 k개를 먼저 버린다.
2. 금리(%) = 1981-09-01 전 DTB3, 그 뒤 DGS3MO. 종가 날짜와 금리 날짜의 합집합에서 앞값 채우기(ffill) 뒤 종가 날짜 값만 쓴다. rate = %/100, rc_t = rate_t/252.
3. r_t = c_t/c_{t−1} − 1, r3_t = 3r_t − 0.0095/252 − 2rc_t, r1_t = r_t − fee1/252(fee1 = 0.0035). 첫 종가 행(t = 0)은 버린다 → 실행 인덱스 i = 0…n−1은 종가 1…N이다. 남은 행에 금리가 비면 오류.

엔진 core(목표 T 고정, band = β)
- e = 1, i = 0: 비중 w₃ = w₁ = 0(포지션 없음), E₀ = 1.
- i ≥ 1: ① 성장 g₃ = w₃(1 + r3_i), g₁ = w₁(1 + r1_i), g_c = (1 − w₃ − w₁)(1 + cash_i) (주 판정 cash_i = 0, 국채 민감도 cash_i = rc_i). tot = g₃ + g₁ + g_c, e ← e·tot, w₃ ← g₃/tot, w₁ ← g₁/tot.
  ② 조정(종가 i−1에 정한 목표를 종가 i에 체결): T ≥ 1이면 t₃ = (T − 1)/2, t₁ = 1 − t₃(T < 1이면 t₃ = 0, t₁ = T). |t₃ − w₃| ≥ β − 1e−12 또는 |t₁ − w₁| ≥ β − 1e−12 또는 (t₃ = 0 < w₃) 또는 (w₃ = 0 < t₃)이면 e ← e − e·0.0010·(|t₃ − w₃| + |t₁ − w₁|), w₃ ← t₃, w₁ ← t₁.
  ③ E_i = e, 노출 X_i = 3w₃ + w₁.
- i = 1의 첫 체결은 0에서 시작하므로 비용 = 0.0010·(t₃ + t₁).

엔진 cash3(목표 T 고정, band = β)
- i = 0: w = 0, E₀ = 1. i ≥ 1: e ← e·(w(1 + r3_i) + (1 − w)(1 + cash_i)), w ← w(1 + r3_i)/(같은 합). 목표 p = min(1, max(0, T/3)). |p − w| ≥ β − 1e−12 또는 (p = 0 < w) 또는 (w = 0 < p)이면 e ← e − e·0.0010·|p − w|, w ← p. E_i = e, X_i = 3w.

실제 상품 대조(보고): SOX 입력(3번)을 2010-03-11부터 자른 실행 인덱스에서, 3배·1배 일간 수익 대신 SOXL·SOXX `adjclose`의 일간 변화율을 그 날짜에 맞춰 넣는다(첫 행의 결측은 0, 그 밖의 결측은 오류). 비용·조정·현금 규칙은 같다.

구간 지표(연속 실행의 [a, b))
- S = (a = 0이면 E[0:b], 아니면 [1] 다음에 E[a:b]/E[a−1]). n = b − a.
- 연수익 = (S 끝/S 처음)^(252/n) − 1(비율 ≤ 0이면 −1). 최대 낙폭 = min(S/누적최대(S) − 1).
- 1년 창 최악 = min_j T[j + 252]/T[j] − 1, T = E[a:b](기준점 1 없음), j = 0…len(T) − 253. 3년 창은 756.
- 구간 시작: 전체 a = 0, 2010~ a = 날짜 ≥ 2010-03-11인 첫 인덱스, 최근(보고) ≥ 2016-01-01·≥ 2021-10-01.
- 최악 하루 = 구간 안 min(E_i/E_{i−1}) − 1(a = 0이면 i ≥ 1). 하락 구간 수 = 누적최대가 새로 갱신될 때마다 묶음을 나눠, 묶음 안에서 S/누적최대 − 1 ≤ −0.10(−0.20)이 한 번이라도 있는 묶음 수. 연간 조정 횟수 = (첫 체결을 뺀 거래 횟수)/(n/252), 전체 실행 기준.

경로 손실(보고)
- P3_i = Π_{1≤j≤i}(1 + r3_j), P1_i 같은 방식(P_0 = 1). 실제는 실제 상품 대조의 실행 인덱스(SOX 날짜, 2010-03-11~)에서 SOXL·SOXX 일간 변화율의 누적곱(전체 [0, n)).
- 구간 [a, b) 안의 모든 시작 j(j ≥ a, j + L ≤ b − 1): PL = (P3_{j+L}/P3_j − 1)/3 − (P1_{j+L}/P1_j − 1).
- 구간 점검(2026-06-22 → 2026-09-29)은 두 날짜의 P 비율로 계산한다(합성은 SOX 전체 실행의 P3·P1).
