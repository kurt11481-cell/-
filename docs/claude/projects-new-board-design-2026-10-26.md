K3에는 ③·⑤·⑥·⑦·⑨와 ②의 원래 뜻(금지 유지)만 남는다(5절 첫머리).**

5. **cashflow-api-gap(cf-b2n)과 순서는 그대로 cf-b2n이 먼저다. "파일 겹침 없음"은 Q1 b에서 틀렸다** — 같은 reference 파일(대조 '확인' 절차)과 reconcile 쪽 confirmed-via를 둘 다 건드린다(7절).
6. **② 셸 우회 막기는 "전면 차단"에서 "검증된 승인 뒤 정해진 명령만 허용"으로 다시 정의한다.** 승인 실행 경로(apply·dev-merge·Builder/Judge 시작)가 Desktop Commander(CLAUDE.md 54-55·114)라 전면 차단과 충돌한다. 저장소 settings deny는 헤드리스 Builder 보호 때문에 유지.
