## 3. P1 설계와 위험
```
스레드: 조언이 필요한 때(지금 fable-advisor 부르는 때)
   ↓  파일 도구로 요청 파일 쓰기(질문 + 허용 경로 안의 파일·줄 범위) — 셸 안 씀
회사PC 실행기 (10분마다 깨어남, 'advise'는 정해진 시각이 아니라 요청이 있을 때 도는 새 방식)
   ↓  '처리 중' 표시 → 허용 경로만 읽어 claude-fable-5-2 1회 호출(키는 INVESTV2_ANTHROPIC_API_KEY, Claude는 안 읽음)
   ↓  답 파일 + usage.jsonl 1행 → '끝' 표시
스레드: send_later로 깨어나 답 읽기 → 반영 → "Fable 조언(API)" 표시
   ↓  25분 넘게 '처리 중'도 아니면 → 요청에 '취소' 표시 후 지금 방식(구독)으로 한 번 부르고 한 줄 알림
```
- **새 통로라는 점:** 스레드가 쓴 커밋 안 된 파일이 회사PC의 유료 외부 호출을 일으킨다. 지금 실행기는 정해진 시각·하루 한 번·켜기 파일은 커밋본만 읽음(llm-runner2-builder-prompt 37~45·76~77행). 그래서 실행기 코드·켜기 파일·시험을 바꾸는 개발 큐 작업이 필요하고, 이것이 권한 변경 검토 대상인지는 사장 판단(K3 검토 권장).
- **민감 자료 반출 막기:** 실행기는 허용 경로(docs/claude, 코드 폴더)만 읽고 .env*·상태·일지·원장·계좌 경로, 절대 경로, `..`, 링크는 거부, 크기 상한, 보낸 경로 목록만 기록. 비밀 패턴이 보이면 보내지 않고 BLOCKED. 조직 보관 설정을 확인하기 전에는 보유·수량이 든 투자 판단 조언은 지금 방식(구독)에 둔다.
- **비용 폭주 막기:** 한 번 깰 때 1건, 하루 N건, 요청당 입력·출력 토큰 상한, 월 $40(usage.jsonl을 못 읽으면 멈춤), 같은 요청 재처리 금지, '취소' 표시된 요청은 건너뜀(크레딧·구독 이중 지불 방지).
- **지연:** 대기 최대 10분 + 호출 3~5분. 급한 매도·줄이기 후속 답은 11/24 사장 결정('급하면 먼저 답, 조언은 뒤에') 그대로라 답을 늦추지 않음.
- **품질:** 한 번 호출판은 요청자가 고른 줄만 보므로 독립성이 떨어질 수 있다. 2주 동안 몇 건을 구독판과 나란히 비교하고, 부족하면 '읽기 도구만 가진 Agent SDK 조언자'(P1b와 같은 검토)로 바꾼다.
- 대안(기본 아님): Desktop Commander 실행 예외에 조언 스크립트를 더하는 길(즉시 답, CLAUDE.md·지침 3절 개정 + K3). 클라우드 환경에 API 키를 넣는 길은 키가 회사PC 밖으로 나가 권하지 않음.
