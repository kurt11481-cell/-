# R-REC1 세 번째 재설계(r3) 사전 등록

## 0. 요약

- 질문: 현행 관문이 첫 매수를 늦추는 비용을 줄이면서, **현행만큼의** 꼬리 방어(60세션 최대 역행 하위 10%)를 유지하는 더 단순한 규칙이 있는가.
- 이번이 다른 점:
  1. **주 판정 자료가 R-REC1 리플레이로는 처음 쓰는 자료다** — SOX 지수, 사건 시작일 1994~2010. 10/9 두 리플레이는 SOXX 2011~2026을 이미 두 번 봤다. (SOX 1994~ 자료 자체는 S4-2·S4-3에서 다른 규칙 검증에 쓴 적이 있다.)

- 채택은 기준 통과 + 독립 Judge + 사용자 승인 뒤에만. 그 전에는 아무것도 바뀌지 않는다.

### 2-2. 가격 기준

- P1 SOX: 원값 close·high·low·volume을 쓴다. adjclose 열은 무시한다(지수라 배당 재투자 없음, 두 팔에 같게 작용). 지수는 정규장에서만 계산돼 시간외 저가가 섞이지 않는다.
- SOXX_combined: 조정계수 f = adjclose / close를 close·high·low에 곱한다(10/9 두 사전 등록과 같음).
- 키움 후보·GRID: 수정주가(adjusted 1)라 f = 1. 종가 = cur_prc, 고가 = high_pric, 저가 = low_pric, 거래량 = acc_trde_qty, 날짜 = dt(YYYYMMDD → YYYY-MM-DD). 오름차순 정렬. GRID 거래량 0 행 74개는 그대로 둔다(fx5b와 같음, 전날 값 반복 자리표시로 보임).
- 운영 코어는 30분봉 정규장 집계 일봉을 쓰지만 과거에는 그 자료가 없다(키움이 2026-04-01 이전 30분봉을 주지 않음, fx1009-closing 1-2). 키움 일봉 저가에 시간외 값이 섞일 수 있어 F2로 의심일 수만 센다.

### 2-3. 계산 전 점검 (결과 아님)

- SOX 전체: 결측·중복·날짜 역행 없음, 저가 ≤ 종가 ≤ 고가 위반 0. 고가 = 저가인 날은 1994~2010에 0, 전체에 1일(2019-08-13, P1 밖).
- 운영 `build_series` 기준(σ60 = 오늘 포함 60개 수익률, H20 = 오늘 제외 앞 20개 종가, EMA50 = 첫 50개 평균 시작): 첫 평가 세션 1994-07-29, 1994-07-29~2010-12-31 평가 세션 4,138개. 그중 EV1일 81, EV2 상태일 1,479(36%), EV2 진입일 213. |일간 수익률| > 12%는 2000~2001년 6일.
- 승패·수익·관문일은 계산하지 않았다.

## 3. 기준선 V0 = 운영 코드

### 3-1. 호출 방식

- 계열: 자료마다 `build_series(bars, calendar_sessions, through=마지막 날)`을 한 번 만든다. `calendar_sessions` = 그 자료의 날짜 목록(전부 연속). 모든 지표가 과거 값만 쓰므로, 세션 t의 판정에는 벤치마크·후보·GRID 계열의 **모든 리스트 키를 같은 방식으로 t까지, 마지막 130세션만** 잘라 넘긴다(`rrec1`이 쓰는 가장 오래된 인덱스는 t − 63). 자체 시험: 무작위 50개 세션에서 "t까지 자료로 새로 만든 계열의 판정 = 잘라 넘긴 판정".
- 매 평가 세션 t에 `rrec1(benchmark=…, candidate=…, evaluation_session=t, ev3_user_dates=[], thesis_damage=[], ev4_sessions=[], candidate_symbol=…, research_sessions=None, rg2_series=…)`.
  - P1: benchmark = SOX, candidate = None, rg2_series 기본값(벤치마크 자신). 후보 = 벤치마크 자신이므로 운영의 종목 호출과 같다(EV5 = EV1, 후보 EMA50 = 벤치마크 EMA50).
  - P2: 운영 `auto_core_decide.py` 1066~1071행과 같게 benchmark = SOXX, candidate = 후보, rg2_series = `rg2_benchmark(섹터)`의 계열. 섹터 = `watchlist-registry.json`의 값 그대로(MU "B1 메모리", LITE "A3 광부품", DELL "AI 서버", PWR "A1 전력(그리드 시공)", BE "A1 전력(온사이트)") → PWR·BE는 GRID, 나머지는 SOXX(`rg2_benchmark` 923~925행).
- 매수 허용(관문 쪽) = 반환값 `status == "ok"`. 근거: 매수 요건 (5)(`auto_core_tickets.py` 268~276행)는 status unk → 막힘, open → RG1~RG4 모두 ok여야 통과, 열린 사건 없음 → 통과이고, 이는 `status == "ok"`와 같다. 요건 (5)는 종목별 호출 결과만 쓰고 포트폴리오 호출(1072행)은 쓰지 않는다(1093행 `shock=shocks[symbol]`).
- `thesis_damage=[]`이라 RG1 = "사건 뒤 2세션 경과"만 남는다(공식 훼손 재현 불가 — 실제 운영은 더 늦거나 더 막힐 수 있음). EV3·EV4는 재현하지 않는다.

### 4-1. W2 규칙

- 사건 e 뒤 세션 k(e < k ≤ i)를 차례로 볼 때, low_k가 None이면 운영처럼 RG3 = unk. low_k < L_ref이면 L_ref := low_k, C_ref := close_k, 그리고 k를 DS1 날로 센다(RG3 연속 카운트와 시간 소멸 시계 재시작). 시작값 L_ref = L0, C_ref = C0.
- DS1(k) = 그날 재기준 또는 close_k < L_ref(그날 갱신 뒤 값) 또는 close_k < EMA50_k. (재기준 뒤에는 close ≥ low ≥ L_ref라 "종가 < L_ref" 쪽은 사실상 쓰이지 않는다.)
- RG3(i) = (i − 마지막 DS1 ≥ 2) 그리고 i−1·i 종가 모두 > C_ref. 마지막 재기준 뒤 저가는 정의상 모두 ≥ L_ref다.
- 시간 소멸(i) = i − 마지막 DS1 ≥ 20 그리고 RG2 — 식은 운영과 같고 DS1에 재기준 날이 들어갈 뿐이다. 그래서 W2는 시간 소멸이 V0보다 늦어질 수도 있다(항상 느슨한 쪽은 아님).
- 사건 목록·EV 판정·60세션 창·RG1·RG2·RG4는 바꾸지 않는다. 출력 `event.c0`·`l0`는 원래 값, 마지막 C_ref·L_ref는 `rebase` 칸에 따로.

## 5. 에피소드와 비교 팔

- 허용_t = (status_t == "ok"). 에피소드 개시 t0 = 허용_{t0−1}이 참이고 허용_{t0}이 거짓인 세션. 끝 u = t0 뒤 처음 허용인 세션.
- 끝 종류: **열림**(u의 반환값 `closed_at == u`, rg 4개 모두 ok) · **시간 소멸**(`closed_at == u`, rg에 ok 아닌 것 있음) · **창 이탈**(`closed_at` 없음, 창 안 사건 없음).
- 왼쪽 검열: 개시 t0의 사건 창 [t0−59, t0]의 모든 세션에 벤치마크 σ60(P2는 후보 σ60도)이 있어야 판정에 넣는다. 없으면 사건을 덜 볼 수 있으므로 뺀다(개수 보고). P1에서 이 조건을 처음 채우는 날은 1994-10-21이다.
- 평가 시작: P1 = SOX의 σ60·EMA50이 모두 있는 첫 세션. P2 = SOXX·후보(·GRID)의 σ60·EMA50이 모두 있는 첫 공통 세션(후보 σ60이 없으면 운영 826행이 EV5를 조용히 건너뛰므로).
- 날짜: P2는 SOXX·후보(·GRID) 공통 날짜만 쓰고 세션 수(f, 지연, 20·60세션 창)도 그 공통 날짜로 센다.
- 팔(1배 1회 매수, 비용 10bp: P = 종가 × 1.001):
  - **X1′** = t0 + 1 종가 체결(실행 가능한 "충격 다음 날 매수"). 주 비교 대상.
  - **G** = u + 1 종가 체결(운영 읽기: 끝 종류와 상관없이 막힘이 풀린 다음 세션 LOC).
  - X1 = t0 종가(이상형)와 N(매수 안 함 = 0)은 같은 표에 나란히, 판정 안 씀.
  - 매수 대상 가격: P1 = SOX, P2 = 그 후보 종목의 종가·저가.
- R_H = c_{f+H} / P − 1, MAE_H = min(low_{f+1..f+H}) / P − 1 (H = 20, 60). 창이 자료 끝을 넘으면 그 지표에서 뺀다(개수 보고).
- 지연 = f_G − t0. 놓친 반등 = P_G / P_X1′ − 1.
- 표본 기간: P1은 t0가 2010-12-31 이하(왼쪽 검열 조건 적용)(결과 계산에 2011년 이후 가격을 써도 됨). P2는 t0가 2011-01-03~2026-09-29. 자료 끝까지 u가 없으면 오른쪽 검열(판정에서 뺌, 개수 보고).
- P2 합동 표본은 같은 SOXX 사건을 후보 수만큼(최대 5번) 다시 센다(독립 아님, 한계).

## 6. 채택 기준 (계산 전 고정)

판정 쌍 = G와 X1′의 R60·MAE60이 모두 완성된 에피소드. 주 읽기에서는 모든 기준(a~d)을 판정 쌍으로 계산한다(S4 읽기의 예외는 8절 S4). V0와 각 변형은 에피소드 집합이 다르므로 **각자 자기 판정 쌍**으로 계산하고, 비교(c′, d-B)는 같은 부분 표본(P1 · P1 반분 · P2) 안에서 각자 값끼리 한다.

| # | 기준 | 값의 출처 |
|---|---|---|
| a | MAE60 중앙값(G) − 중앙값(X1′) ≥ +2.0%p | 10/9 그대로 |
| b | R60 중앙값(G) − 중앙값(X1′) ≥ −3.0%p | 10/9 그대로 |
| c | MAE60 하위 10% 분위(G) − (X1′) ≥ +2.0%p, 분위 = `numpy.percentile(x, 10)` 선형 보간 | fx5b 그대로 |
| c′ (새) | P1에서 변형의 c ≥ V0의 c (꼬리 방어를 현행보다 잃지 않음). P1에서만 요구 | 질문 "현행만큼 유지"를 그대로 옮김 |
| d | **현행 대비 수익 개선(C안):** Δ = R60 중앙값(W, 자기 판정 쌍) − R60 중앙값(V0, 자기 판정 쌍) > 0. 지연 세션 수는 보고만 한다 | 새 기준(사용자 결정 2026-10-16 14:13, 13절) |

- 중앙값 = `statistics.median`(짝수 개면 가운데 둘의 평균). 반올림하지 않은 값으로 비교.
- **변형 W의 채택 후보 조건 (모두):**
  1. **V0가 2(c′ 제외)·3·4·5를 모두 넘지 못했을 것.** C안에서 V0의 d는 Δ = 0이라 "> 0"이 항상 거짓이므로 이 조건은 늘 충족되어 역할이 없다(기록으로만 남김).
  2. P1에서 W가 b ∧ (a ∨ c) ∧ c′ ∧ d.
  3. P1 반분(t0 ≤ 2002-12-31 · t0 ≥ 2003-01-01) 각각에서 W가 b ∧ d(Δ는 그 반분 안의 V0 대비)이고, 2에서 충족한 기준(a 또는 c) 중 하나 이상의 차이가 두 반분 모두에서 > 0.
  4. P2 합동 표본에서 W가 b ∧ d(Δ는 P2 V0 대비)이고, 2에서 충족한 기준(a 또는 c) 중 하나 이상의 차이가 > 0.
  5. S4 읽기(8절)로 V0와 W1~W3 모두를 다시 계산해 1~4와 아래 "단순한 쪽 고르기"까지 적용했을 때 **고른 변형이 주 읽기와 같을 것**(둘 다 "없음"이면 같음). 다르면 채택하지 않는다. 이 조건은 채택을 막는 쪽으로만 작동한다.
- 쌍이 15개 미만이면 그 표본은 "표본 부족": P1이면 판정 보류(= NO_CHANGE), 반분·P2면 미충족(fail-closed).
- 여러 변형이 통과하면 W1 < W2 < W3 순으로 단순한 쪽.
- 통과 변형이 없으면 **NO_CHANGE**: 현행 R-REC1 그대로, 결과만 기록하고 알린다(사용자 질문 없음).
- 통과해도 바로 바뀌지 않는다: 독립 Judge(Opus, 별도 세션) → 사용자 승인 → 코드 변경(권한·한도 경로, `CONSTANTS` 주석 "Changing a value is an authority/limit change"). 이 관문은 계속 매수를 막거나 늦추기만 하고 매도·예산·노출 상한에 영향 없다.
- **기준 이동 위험(정직하게 적음):** a·b·c 값은 10/9 그대로이고 c′와 반분 조건(3)은 통과를 어렵게 하는 쪽이다. 그러나 (i) fx5b의 세 부분 표본(SOXX 전반·후반·QQQ)이 P1 반분 + P2로 바뀌었고, (ii) 운영 읽기로 시간 소멸·창 이탈 에피소드도 G가 매수한 것으로 세어 표본 집단이 바뀌었다 — 이 둘이 통과를 쉽게 하는지 어렵게 하는지 방향은 모른다. d의 B안은 새 값이다. B를 고르면 결과 문서 첫 줄에 이 문단을 그대로 적는다.
