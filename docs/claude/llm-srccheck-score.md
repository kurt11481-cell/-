- 한 건 = `workspace/outputs/llm/srccheck/<날짜>/checks.md`의 한 줄.

## 3. 1일차 관찰 (2026-11-26)
- Batch 안 웹 가져오기는 됐다. sec.gov 문서 4개를 모두 열었고 결과 URL이 입력과 같았다(설계 7절 3, 원장 508행 '직접 열람 실패' 걱정은 이번엔 없음).
- `web_fetch_20260209`는 동적 필터링이 자동으로 켜져 응답에 코드 실행 결과 블록이 섞였고 text 인용이 0개였다. 그래서 4건 모두 '확인 불가'가 됐다. 고침 = 개발 큐 llm-srcfix(도구 판 `web_fetch_20250910`, DEF 14A 주장 문구).
- 주장 문구 문제: SEC `report_date`를 늘 '보고 기준일'로 불러 DEF 14A에서 틀린 주장이 됐다(모델은 '맞음'으로 넘어감 — 주장 일부만 맞아도 '맞음'을 준 예).
- 비용(정가 환산, Batch): 4건 합 약 $0.13, 건당 입력 약 14k~43k토큰.
- 집계: 셈에 드는 건 0 / 20.
