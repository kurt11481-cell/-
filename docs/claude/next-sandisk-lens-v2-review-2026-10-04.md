## 0. 결론 (먼저)

1. 10/4 판정(씨앗 0)은 맞았다. 문제는 '관찰'이라는 이름표다. 새 수요(G1)와 과점(G3)만으로도 관찰이 되니, 호황 중기에 흔한 '병목 노출 우량주'가 샌디스크 후보처럼 읽혔다.
2. 지금 추천(v1.1, 11/7 예약 실행 전): ① 관찰을 'G2 포함'과 '병목 품질주(G1+G3만, 참고)'로 나눠 표시 ④ 창의 질문 3에 '굶는 형제 제품' 추가. 판정 규칙과 예약 작업 지시문은 바꾸지 않는다.
3. 2027-01 정기 검토(c-nextsndk-v2)로 넘김: ② 씨앗의 폭발력 조건(순도·바닥 출발) ③ 점화 I2 강화 ⑥ 빠른 공식 데이터 — 위원회가 찾은 구멍을 메운 뒤 21건으로 시험.
4. 보류: ⑤ 추정치 표시(2축 지도·이익 민감도·통행료 경고). 실행 모델이 지어낸 숫자가 근거처럼 읽힐 위험이 크다.
5. 10/4 결과를 v1.1로 다시 보면: 씨앗 0 · 관찰 4 = G2 포함 0 + 병목 품질주 4(CIEN·HWM·CRS·SOLS) · 제외 1(GFS) · 미달 5. 씨앗 판정은 그대로다.

### 위원회
- 설계자: 크기(순도·바닥)와 I2를 지금 넣자 — 과거 판정은 거의 그대로이고 호황 중기 우량주가 씨앗이 되는 것만 막는다. → 위원회 뒤 ②③ 철회.
- 회의론자: 바꾸지 않는다. 씨앗 0은 정상이고, 감사 전에 규칙을 바꾸면 기준선이 사라진다. 오류 비용이 비대칭이다 — 거짓 씨앗은 정밀 분석 한 번으로 걸러지지만 놓친 씨앗은 5배 기회를 잃는다. 씨앗 0인 지금 조이면 싼 오류만 준다.
- 실용주의자: 한두 줄로 끝나는 ①④만. 버전과 변경 기록을 남기고, 10/4 자료로 새 표를 다시 돌려 확인한 뒤 11/7에 넘긴다.
- 비판자: ②의 '8분기' 창은 이미 폭발한 종목도 바닥 출발로 통과시키고, 상위 범주로 잰 순도(CRS 66%)도 문을 연다. ③은 기저가 0 근처이거나 GAAP·조정 EPS 중 유리한 쪽을 고르면 통과되고, EPS 가이던스가 없는 회사는 '확인 필요' 표시 없이 조용히 탈락한다. ⑤⑥ 추정치는 지어내기 쉽다. ④ 예시가 메모리면 이미 79배 오른 같은 뿌리를 다시 찾게 된다.

### 판정
- 합의: ④ 전원 지금. ① 3명 중 2명 지금(비판자 조건 포함). ②③ 지금 아님(전원). ⑤⑥ 보류.
- 가장 강한 반대: 회의론자의 '오류 비용 비대칭'. 이 때문에 설계자 안 ②(씨앗 조이기)를 철회했다. 지금 할 일은 깔때기를 넓히는 일(④)과 이름표를 정확히 하는 일(①)이다.
- 전제 점검: '관찰 종목이 샌디스크형이 아니다'는 판정 오류가 아니라 이름표 문제였다. 씨앗·점화 규칙은 이미 그 종목들을 걸렀다.
- 조정: ①을 '관찰 정의 변경'에서 '관찰 표시 분리'로 낮췄다. 예약 작업 지시문이 "관찰 = G 2/3"을 직접 적고 있어, 정의를 바꾸면 지시문과 설계 문서가 어긋난다. 표시 분리는 지시문과 충돌하지 않고, 판정 기준선도 유지해 회의론자의 우려도 피한다.
- 권고: v1.1 = ① 표시 분리 + ④ 질문 3 보강, 11/7 전 적용(사용자 결정).

## 4. v1.1 적용 문구 (2026-10-04 설계 문서에 반영됨)

1. 4절 첫머리: "- 버전: v1.1(2026-10-04) — 관찰 표시 분리·질문 3 보강. 판정 규칙은 v1과 같다."
2. 4-5 끝에 추가: "- 표시(v1.1): 관찰은 'G2 포함'과 '병목 품질주(G1+G3만, 참고)'로 나눠 N-4에 적고, N-0에는 두 수를 함께 쓴다(예: 관찰 4 = G2 포함 0 · 병목 품질주 4). 병목 품질주도 I1~I3은 계속 기록하고, I 2/3이면 N-0에 '참고 종목 점화 신호 — 사람 검토' 한 줄. 판정 규칙은 그대로."
3. 5-1 질문 3 교체: "3. **다음 병목**: 'X가 풀리면 어디가 막히나? X로 투자가 몰리면 무엇이 굶나(굶는 형제 제품)?' — CoWoS 2027 완화 → HBM·기판·테스트. 굶는 형제 제품은 같은 회사·같은 공장에서 만드는 구형 규격·성숙 공정 제품 등에서 찾되, 실제 부족은 공식 자료로 확인한다. 메모리 뿌리는 사이클 말기(X5)라 이 질문의 답에서 뺀다."
4. 15절에 결정 9행, 10/4 결과 문서 N-4에 재분류 1줄.
- 예약 작업 지시문은 바꾸지 않는다. 지시문이 읽는 4·5절에 들어가므로 11/7부터 반영된다.

## 5. 2027-01 정기 검토로 넘기는 것 (c-nextsndk-v2)

- ② 폭발력: '부문'은 회사가 공시한 사업부문·제품 매출로 한정(상위 범주로 대신하지 않음, 없으면 확인 필요 = 아니오). '바닥 출발'은 회복이 시작된 시점에 묶는다(예: 직전 4분기 안 저점 + 현재 마진이 아직 정상 이하) — 이미 폭발한 종목이 통과하지 않게.
- ③ I2: 두 분기 같은 기준 EPS(조정이면 둘 다 조정), 기저가 0 근처면 영업이익으로 판정, EPS 가이던스가 없으면 'UNKNOWN(가이던스 없음)'을 명시.
- ⑥ 빠른 공식 데이터: 21건에 대해 공식 과거 시계열(수출 단가·생산자물가 등)로 '더 일찍 잡았을지' 한 번 시험한 뒤 판단.
- 결정 4(시총 $5B 하한)·결정 7(G2 선판매 해석)과 함께 본다.
- 판정 규칙을 바꾸면 예약 작업 지시문 5)·6)의 규칙 문구도 함께 갱신해야 한다(지시문이 규칙을 직접 적고 있음, 승인 필요). 이때 지시문이 규칙을 다시 적지 않고 설계 4절을 따르게 바꾸는 것도 함께 검토한다.

## 6. 왜 틀릴 수 있나

- 21건은 정성 분류이고 생존 편향이 있다(D급). 표본이 작다.
- 이름표만 바꾸면 '수요형 승자'(CLS·BE·CRDO, 9~21배) 사각지대는 그대로다 — 일반 월간 발굴·R2.1 경로의 몫이다.
- '병목 품질주'라는 이름이 이 종목들을 실제보다 덜 매력적으로 보이게 할 수 있다. 샌디스크형이 아니라는 뜻이지 나쁜 투자라는 뜻이 아니다(관심 명단 판단은 카드·R2.1).
