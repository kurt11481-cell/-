## 1. 장중 매매(단타) 도입 검토

### 1-1 장중 매매가 성립하려면
- **시간**: 미국 정규장은 11/02(미국)부터 한국 시간 23:30~06:00. 지금 1단계는 사장이 키움에 직접 넣는다(CLAUDE.md 5~8행) → 장중 매매 = 사장이 밤새 화면 앞에 있어야 함. 일상 손 0 목표(CLAUDE.md 16행)와 반대.
- **자동 제출·장중 감시**: 2단계도 아직이다(로드맵 T5 "조건 미충족", roadmap.md 23행). 장중 감시(실시간 스트림 상시 프로세스)·취소 자동화·봉투는 3단계 조건이다(f-trading-infra-gap 5절 67행).
- **자료**: 키움 해외 30분봉(usa06011) 원 페이지가 저장소에 거래일마다 쌓이고 있다(workspace/outputs/regular-session-closes/pages/<종목>/, git 제외). SOXX·SOXL은 각 48개 파일, 2026-04-01~10-30 정규장 **148세션**(세션마다 09:30~15:30 13봉 전부). SPY 포함 다른 9종목(보유·관심·참고 ETF)도 쌓이지만 **QQQ는 없다**. 5분·1분봉 제공 여부와 과거 길이는 **확인 필요**(키움 명세 조회는 사장 요청 때만). 148세션은 모두 여름 시간(UTC −4)이라 봉 표기가 확인된 구간이고, 겨울 시간 표기는 11/03 아침 측정 예정(active-decisions.md dst-label 행, regular_session_close_history.py 61~64행).
- **비용**: 키움 미국주식 온라인 수수료 0.25%(2차 자료, 확인 필요 — 이벤트 할인 0.07% 가능, 확인 필요). 아래는 저장된 30분봉에서 직접 계산한 값(신호 성적은 계산하지 않음 — 비용 크기만).

| | SOXX | SOXL |
|---|---|---|
| 세션 | 148 | 148 |
| 개장 30분봉 폭의 절반(= 손절까지 최소 거리) 중앙값 | 0.84% (25~75%: 0.62~1.11) | 2.45% (25~75%: 1.79~3.36) |

  진입은 범위 위에서 하므로 실제 위험 폭은 이보다 커서 실제 배수는 조금 작다. 뜻: 2R 목표면 SOXX는 0.25% 수수료에서 목표에 먼저 닿는 비율이 대략 53% 넘어야 본전(손절·목표만 있다고 칠 때).

## 2. 주문 허용 — 최종 목표와 길

### 2-1 이미 목표에 있다
- 헌법 §14: READ_ONLY → ORDER_INTENT_ONLY → HUMAN_PER_ORDER → GUARDED_AUTOMATIC_APPROVAL → AUTONOMOUS_GUARDED_EXECUTION(426~443행), "시스템은 자신의 Authority Envelope를 스스로 확대할 수 없다"(446행).

### 2-2 "주문 허용"의 실제 모양
- Claude(대화형·예약·Judge)는 계속 주문 도구를 부르지 않는다. 주문은 **Windows 작업이 돌리는 결정론 제출 모듈 하나**만 키움 주문 API를 부르고, 그 모듈이 권한 경로에 등록된다(f-trading-infra-gap 3절).
- 제출 전 관문(신선한 코어 결과·단계 플래그·정지 스위치·**주문표가 비교 모드 아님**·미체결 없음·장부 중복 없음·토큰 유효, 39행), 제출 전 장부 기록(40행), 응답 불명은 재전송 금지(41행). 키움 주문 API에는 클라이언트 주문 ID가 없어 중복 방지는 우리 장부로만 한다(1절 발견 1).

## 4. "지침에 얽매이지 말고" — 그래도 남기는 선 4개
1. **LLM은 실계좌 주문을 직접 내지 않는다.** 주문이 열려도 결정론 제출 모듈 + 사장 승인으로 낸다.
2. **새 매매 신호는 사전 등록 시험을 먼저 통과한다.** 실패한 시험을 설정만 바꿔 다시 재지 않는다(Kronos·C3 선례).
3. **권한·한도는 사장만 올린다.** 시스템이 스스로 단계를 올리지 않는다(헌법 §14 446행).
4. **기존 규칙은 바뀔 때까지 유효하다.** 이 문서의 후보는 제안이고, 승인 경로를 밟기 전에는 아무것도 바뀌지 않는다.
- 이 넷 말고는 지금 규칙을 이유로 후보를 버리지 않았다(예: 모의 주문은 지금 Hard safety에 걸리지만 후보로 올림).

## 10. 사전 등록 — 장중 그림자 리플레이 (실행 전 고정)
- 근거: 9절 결정. D3 예외 1건 = 계산 파일 docs/claude/intraday_shadow_replay.py + 이 절.
- 가설: 개장 30분 범위 돌파(1-4절 규칙, 목표 2R)는 SOXX·SOXL 정규장에서 한쪽 수수료 0.25%를 빼고도 1회 평균 R이 0보다 크다.
- 고정 규칙(계산 파일 머리 설명과 같음):
  1. 범위 = 09:30 봉(고가 H, 저가 L). 진입 = 10:00 봉부터 마지막 정규 봉(종가 이력의 bar_cntr_tm) 바로 앞 봉까지 중 종가 > H인 첫 봉의 종가. 매수만, 종목·세션마다 1번.
  2. 손절 = (H + L) ÷ 2를 센트 아래로 버림(원문 trader-exit SKILL 62~63행). 위험 = 진입 − 손절. 위험이 진입가의 0.05% 미만이면 거래 안 함(원문 거절 규칙, 같은 파일 65~67행).
  3. 목표 = 진입 + 2 × 위험, 센트 반올림(원문 63~64행).
  4. 진입 다음 봉부터 마지막 정규 봉까지 차례로: 시가 ≤ 손절 → 시가에 정리 / 시가 ≥ 목표 → 목표가 / 저가 ≤ 손절 → 손절가(같은 봉에서 목표에 닿아도) / 고가 ≥ 목표 → 목표가 / 끝까지 없으면 마지막 정규 봉 종가.
  5. 1회 R = (정리 − 진입) ÷ 위험 − c × (진입 + 정리) ÷ 위험 (c = 한쪽 수수료).
