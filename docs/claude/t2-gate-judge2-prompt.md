# Judge 2차 지시문: t2-gate REMOVE-v2 (T2 "켜" 관문 R2의 연속일 요건 제거 + 차이 분류 의무, K3 · 제약 완화)

너는 독립 Judge다. 파일을 고치지 않는다(Read·Grep·Glob만). 커밋·푸시·병합 안 함. 비밀(.env*, 토큰, 계좌번호)·키움 도구 금지. 보고는 한국어.

## 판정 대상
docs/claude/roadmap-fix-decisions-2026-10-26.md **1-1절**(사장 원문 "결정 t2-gate: REMOVE-v2", 2026-10-26 16:07 KST 사장실 스레드 직접 입력). 1절은 1-1절로 대체됐다.
1차 Judge 원문: 저장소 루트 t2-gate-judge-1.txt(UTF-16, VERDICT FAIL, 조건 1~6 제시). 1차 지적이 1-1절에 빠짐없이, 더 약해지지 않게 반영됐는지가 핵심이다.

## 읽을 원문
1차 지시문 docs/claude/t2-gate-judge-prompt.md의 "읽을 원문" 전부 + 1차 Judge 원문.

## 확인 항목 (각각 PASS/FAIL + 원문 행)
1. 1차 조건 1~6이 1-1절에 모두 있고, 문구가 1차 Judge 제안보다 약하지 않은가.
2. 1차 사례 A~D(코어 트리거 결함, 총자산 현금 정의, S7 파생값, 분류 의무 소멸)를 1-1절 조건 1~4가 각각 잡는가. 못 잡는 것이 남으면 사례로.
3. R2에서 실제로 빠지는 것은 "5거래일 연속"(하루 미설명이면 0부터)뿐이고, 차이 설명 의무·CORE_BUG 보류는 남는가.
4. 노출·예산·권한·주문 단계·decision_mode·R3 불변.
5. 효력 뒤 기록 연결(사전 등록 48-54행 방식 덧붙임)이 명시돼 있는가. 무응답·FAIL 기본값이 이전 조건인가.

## 출력
마지막 줄 한 줄: `VERDICT: PASS` 또는 `VERDICT: FAIL — <이유 한 줄>`. PASS라도 보탤 조건이 있으면 그 위에 적는다.
