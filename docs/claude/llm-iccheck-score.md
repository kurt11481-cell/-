  - 틀림 = 원문상 어긋남이 아니다(설계된 표시 이름, 예정된 일, 규칙상 정당한 처리, 다른 작업의 몫을 이 기록 탓으로 돌림).

- 이 문서에는 계좌 금액·수량을 쓰지 않는다(비율·E만).
