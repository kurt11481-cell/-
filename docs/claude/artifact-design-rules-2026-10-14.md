# 투자_V2 화면 디자인 유지 규칙 (2026-10-14)

## 1. 규칙
- 아래 화면의 HTML을 고치거나 재게시하는 세션은 이 문서의 색·글자·크기 규칙을 유지한다. 새 칸을 추가할 때도 같은 변수와 크기를 쓴다.
- 재게시 전에 Artifact `read`로 현재 버전을 읽고 그 위에서 고친다(이전 사본으로 덮어쓰면 디자인이 되돌아간다).
- 이 규칙은 화면 표시만 다룬다. 데이터 읽기·쓰기, 계산·판정, 권한(order_authority=false, quantity_authority=none)은 바꾸지 않는다.
- 저장소(db) 데이터만 갱신하는 예약 작업은 HTML을 재게시하지 않으므로 해당 없음(us-stock-board-close, integrated-check-daily, dev-board-weekly-review 확인 2026-10-14).

## 4. 글자 (KRDS 기준)
- 글꼴: "Pretendard GOV", "Pretendard", "Noto Sans KR", "Apple SD Gothic Neo", "Malgun Gothic", system-ui, sans-serif. 웹 글꼴은 Google Fonts의 Noto Sans KR(400·700). 숫자·코드용 고정폭 글꼴은 유지해도 된다.
- 굵기는 400(본문)과 700(제목·강조) 두 가지만 쓴다.
- 크기: 본문 17px, 표·빽빽한 수치 15px, 단위·시각 같은 짧은 표기 13px(최소). 문장은 16px 아래로 내리지 않는다. 제목 19/24px, 페이지 제목 휴대폰 22px · PC 24px 이상.
- 줄간격 1.5.

## 5. 누르는 요소와 화면 폭
- 버튼·선택칸·입력칸·체크박스 줄은 높이 44px 이상(기본 버튼 48px). 키보드 포커스 외곽선 3px, 대표색.
- 휴대폰 폭(375px)에서 페이지 전체가 가로로 밀리지 않게 한다. 넓은 표는 표 안에서만 가로 스크롤하고, 휴대폰에서는 목록 줄(ListRow) 모양을 우선한다(미국주식 현황판 보유 종목 참고).

## 6. 재게시 전 확인
1. 현재 버전을 `read`로 읽고 그 위에서 고친다.
2. 휴대폰(375px)·PC 폭, 라이트·다크에서 렌더해 오류·가로 밀림이 없는지 본다.
3. 바꾼 색 조합의 대비를 계산한다.
4. 바뀐 점을 사용자에게 한국어로 짧게 알린다.

## 7. 상태·숫자·움직임·차트 (2026-11-03 추가)
사장 결정 design-rules-7 · 2026-11-03 16:31 KST(버튼 "7절 추가"). 근거: artifact-design-rules-update-proposal-2026-11-03.md(ui-ux-pro-max 커밋 713eef5 자료 대조). 1~6절과 2026-10-14 결정(토스 팔레트·초록=상승·주문 칸 키움 색)은 바꾸지 않는다. 적용은 다음 재게시 때부터.
- A. 숫자: 가격·수량·비율 칸은 `font-variant-numeric: tabular-nums`로 자릿수를 맞추고 오른쪽 정렬한다. 1,000 이상은 천 단위 쉼표.
- B. 자료 상태: 불러오는 중은 자리를 고정한 회색 틀(스켈레톤)로, 자료가 없으면 "없음 — 이유"를, 오류는 해당 칸 옆에 문구 + `role="alert"`로 보인다. 칸마다 자료 시각(KST)을 쓰고, 낡은 자료는 "낡음" 표시를 붙여 숨기지 않는다.
- C. 움직임: `prefers-reduced-motion: reduce`를 지킨다(켜져 있으면 움직임을 끄고 최종 상태만 보인다). 장식용 무한 애니메이션은 쓰지 않는다. 숫자 변화 애니메이션·경보 펄스는 8절에 따라 ui-ux-pro-max 금융 대시보드 권고대로 쓸 수 있다.
- D. 누르는 요소 간격: 버튼·선택칸 사이 8px 이상. 중요한 동작을 마우스 올리기(hover)만으로 열지 않는다.
- E. 차트: 시간 추이는 선, 항목 비교는 막대(15개 이하, 넘으면 표). 점이 4개 미만이면 숫자 카드. 한 차트에 계열 6개 이하. 계열은 색과 함께 선 모양·끝 라벨로 구분하고, 같은 값을 표로도 볼 수 있게 한다.
- F. 글꼴 로딩: 웹 글꼴은 `font-display: swap`.
- 넣지 않은 것: ui-ux-pro-max의 "금융 대시보드 다크 기본", "Navy+Gold 팔레트" 권고(8절 예외).

- 예외(따르지 않음): 금융 대시보드 "다크 모드 기본·라이트 기본은 피할 것", "Navy + Trust Blue + Gold" 팔레트 권고. 라이트·다크 둘 다 지원과 3절 색(토스 TDS 팔레트)을 유지한다.

- 표시 전용: 데이터·판정·권한(order_authority=false, quantity_authority=none)은 바꾸지 않는다. 버전이 올라가 지침이 바뀌면 바뀐 점을 사장에게 알리고 따른다(예외 두 가지는 유지).
