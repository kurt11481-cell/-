## 3. 규칙 (고정)

- r_t = c_t / c_{t−1} − 1. σ_t = 오늘 포함 최근 60개 r의 표본표준편차(ddof=1). 60개 미만이면 결정하지 않는다. (설계 7-2 "σ = 키움 종가 최근 60세션 일간 수익률 표준편차", ddof는 문서에 없어 1로 고정)
- **결정일 t**(매 세션): 기준가 B1 = c_t, 첫 상한 cap1 = c_t × (1 + 0.5 σ_t). 지시서는 세션 t+1에 유효(한국 아침 발행 → 저녁 LOC 입력 → 그날 미국 종가).
- 1차 시도: c_{t+1} ≤ cap1이면 체결, 체결가 c_{t+1}.
- 1차 미체결이면 재발행 1회(세션 t+2):
  - **A 현행:** cap2 = c_{t+1} × (1 + 0.5 σ_{t+1}) (새 기준가 = 미체결일 종가, σ도 그날 기준).
  - **B R-RI1:** cap2 = min(c_{t+1} × (1 + 0.5 σ_{t+1}), cap1).
  - **C 재발행 없음:** 재발행하지 않는다(결정 종료, 미체결).
  - A·B: c_{t+2} ≤ cap2이면 체결, 체결가 c_{t+2}. 아니면 결정 종료(설계 7-3: 두 번 미체결이면 카드 재검토 — 이 리플레이 범위 밖).
- 결정은 서로 독립으로 센다(매 세션 하나, 창이 겹친다). 수량·현금·보유는 모형에 넣지 않는다.
- 비용: 체결 때 10bp. 진입가 P = 체결가 × 1.001. 매도 비용 없음, 현금 이자 0.

### 4-2. B(R-RI1) 채택 기준 — B 대 A, 주 구간 풀링

| # | 기준 |
|---|---|
| ⓪ 표본 | \|S_AB\| ≥ 15. 미만이면 "표본 부족 — 보류" |
| ① 결정 단위 비용 | 평균 D20(B) − 평균 D20(A) ≥ −0.25%p (전체 결정, 미체결 = 0) |
| ② 추격 체결의 질 | S_AB에서 A 체결의 R20 중앙값 ≤ 1차 체결 전체(주 구간 모든 결정)의 R20 중앙값 |
| ③ 일관성 | 전반·후반 각각에서 ① 충족 |

- **채택 후보 = ⓪ 그리고 ① 그리고 ② 그리고 ③.** 채택 후보면 Independent Judge(별도 Claude Code 세션) → 사용자 승인 → 설계 7-3 공식 반영(K3-4). 미달이면 R-RI1은 규칙 후보 그대로이고 다음 행동은 사용자 결정이다.
- 근거(기준을 이렇게 둔 이유, 계산 전): ①은 "꾸준히 오르는 장에서 매수를 놓친다"는 가장 강한 반대의 크기를 결정 하나당 평균 비용으로 잰다. 비용 0.25%p는 매수 비용(10bp)의 2.5배다. ②는 관심 종목이 오른 뒤 뽑힌 종목이라 생기는 상승 편향(아무 때나 사도 이익)을 덜기 위해 같은 표본의 보통 체결과 비교한다. ③은 한 국면에서만 나오는 결과를 거른다.

### 4-3. C(재발행 없음) 보고 기준 — C 대 B, 같은 방식

- ⓪′ \|S_BC\| ≥ 15 · ①′ 평균 D20(C) − 평균 D20(B) ≥ −0.25%p · ②′ S_BC에서 B 재발행 체결의 R20 중앙값 ≤ 1차 체결 R20 중앙값 · ③′ 전반·후반 각각 ①′.

5. 독립 재구현: 이 문서와 1-1 입력 파일만 받은 별도 에이전트(스크립트·결과 미열람)가 구현해 결정 수, 팔별 체결률, \|S_AB\|·\|S_BC\|, ①~③·①′~③′ 값과 판정을 대조한다.
6. 권한: 과거 계산만. 주문 도구·정책·상태·결정 원장·예약 작업을 바꾸지 않는다.

## 7. 한계 (미리 적음)

- 선택 편향: 관심 종목은 크게 오른 뒤 뽑혔다(MU·LITE·PWR 등 2025~2026 급등). 아무 때나 사도 이익인 표본이라 "체결을 놓친 비용"이 크게 나오기 쉽다(①이 B에 불리). ②가 이를 일부 덜 뿐이다.
- 결정을 매 세션 놓았다. 실제 지시서는 트리거·관문(G0~G5, R-REC1, 실적 금지 구간)·위원회를 거친 날만 나온다. 결정끼리 겹쳐 독립 표본이 아니다.
- 미체결 현금은 0% 수익으로 둔다. 실제로는 다음 결정에서 다시 살 수 있다(놓친 비용을 과대평가할 수 있음).
- 키움 수정주가 일봉 종가를 LOC 체결가로 본다. 공식 종가 경매와 다를 수 있고, 미입력(R-NE1) 경우는 넣지 않았다.
- NBIS는 실제 거래 약 1.97년이라 주 구간 앞부분이 σ60 예열로 빠진다. SOXL은 3배 상품이다(민감도 3에서 뺌).
