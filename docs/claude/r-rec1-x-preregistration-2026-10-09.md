# R-REC1-X 사전 등록 — 회복 확인 뒤 일시 증액

## 1. 질문

하락 뒤 회복이 확인되면 노출을 예산(1.55)보다 일시적으로 높이는 것(최대 1.85, 상한 1.9 미만)이 고정 1.55보다 낫나? 사용자 논리(2026-10-09 03:00 KST): "하락장 대비 현금 → 회복 신호 때 현금으로 매수 → 한도 초과가 논리적". 관련 선행: S4-3 추세 증액 T1(+4.1%p)·T2-132b(+4.5%p)는 반도체지수에서 가장 좋았으나 다른 지수 견고성 관문에서 기각, 급락 추가 매수 X1 기각.

## 2. 규칙 (고정)

- 기준 B: 목표 1.55 고정(현행 S5 예산), 매일 조정.
- 후보 X: B와 같되, 아래 증액 상태일 때 목표 1.85.
- 이벤트 열기(R-REC1 중 과거 재현 가능한 것만): EV1 지수 1일 수익률 ≤ −2.0 × σ60, EV2 지수 종가 ≤ 20세션 종가 고점 × (1 − 3 × σ60). 이벤트 중 새 이벤트 → 기준점 갱신. 기준점 C0 = 이벤트일 종가, L0 = 이벤트일 장중 저가.
- 증액 시작(이벤트 열린 상태에서 모두): RG2 지수 종가 ≥ EMA50 · RG3 연속 2세션 종가 > C0이고 이벤트 뒤 L0 아래 장중 신저가 없음 · RG4 판정일 |1일 수익률| ≤ 2σ60 그리고 5세션 σ ≤ 1.5 × σ60 · 추가 조건 지수 종가 > SMA200. RG1(뉴스·공식 확인)은 과거 재현 불가 → 충족으로 간주(한계로 기록). 증액이 시작되면 이벤트는 닫힌다.
- 증액 종료(먼저 오는 것): 20세션 경과 · DS1 지수 종가 < L0 또는 < EMA50 · 전략 자산이 고점(HWM) 대비 −10% 이하. 종료 뒤 1.55. 같은 이벤트로 재증액 없음(새 이벤트 필요).
- 구현: S4-3 엔진 관례 — 종가 t 결정, 종가 t+1 체결. ETF 코어(1배 ETF + 3배, 현금 0): 1.55 = 1배 72.5% + 3배 27.5%, 1.85 = 1배 57.5% + 3배 42.5%. 합성 3배 일간 = 3r − 0.0095/252 − 2 × 3개월 국채 금리/252, 합성 1배 = r − 0.0035/252. 비용 거래 상품마다 10bp. 현금 이자 0. 보조(민감도): 3배 + 현금 0% 구조(1.55 = 3배 51.7%, 1.85 = 61.7%).
- 지표 창: σ60 = 60세션 일간 수익률 표준편차, EMA50, SMA200은 종가 기준. 지표가 없는 초기 구간은 증액 없음.
