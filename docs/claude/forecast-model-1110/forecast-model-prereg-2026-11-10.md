# FM-1 예측 모형 사전 등록 (결과를 보기 전 고정)

- 성격: 표시·채점 전용. 주문·정책·상태·자동 코어 입력·한도·예약 작업 변경 0. 결과로 매매하지 않는다.
- 판정 틀은 evolve-1029 Kronos 채점(trading-tools-review-2026-10-29.md 11-3절)을 그대로 다시 쓴다(REUSE): CRPS 점수 P1, 80% 구간 포함률 P2, 이동 블록 부트스트랩.
- 계산 파일: scripts/fm1.py (이 문서의 실행판). 두 파일과 입력 파일의 sha256은 같은 폴더 fm1-prereg.sha256에 실제 자료 첫 실행 전에 적는다.

## 1. 질문

"과거 자료만으로 만든 확률 범위 예측이, 가장 단순한 기준(지난 1년 변동성 그대로·과거 분포 그대로)보다 20일·60일·250일 뒤 지수 수준을 더 잘 맞히는가? 그리고 요즘(2020년~)에도 그런가?"

점 하나(목표가)를 맞히는 시험이 아니다. 범위(분포)를 내고, 실제 값이 그 범위에 제대로 들어오는지를 잰다.

## 2. 자료

- 대상 3개: 필라델피아 반도체 지수(^SOX), 나스닥 100(^NDX), S&P 500(^GSPC). 야후 일봉 종가(가격 지수, 배당 제외). 참고 등급 자료다(키움 우선 원칙 — 판정은 '모형이 쓸 만한가'에만 쓰고 매매 근거가 아니다).
- 금리: 10년물(^TNX), 3개월물(^IRX) 야후 종가. 빈 날은 직전 값.
- 사용 구간: 1962-01-02(금리 시작) 또는 각 지수 시작일 중 늦은 날 ~ asof 2026-11-06. 수집일의 마지막 행(11-09)은 임시값일 수 있어 뺀다.
- 채점 시작점: 세 지수에 모두 있는 거래일 중 2005-01 첫 거래일부터 5거래일마다. 결과(h거래일 뒤 종가)가 asof 안에 있는 시작점 전부.
- 맞힐 값: 시작점 종가 → h거래일 뒤 종가의 로그 수익률. h = 20, 60, 250.
- 모든 예측은 시작점 당일 종가까지의 자료만 쓴다(결과가 시작점 이전에 끝난 과거 구간만 표본으로).

## 3. 비교 기준 (evolve-1029와 같음)

- B1 랜덤워크: 평균 0, 표준편차 = 직전 252일 일간 표준편차 × √h, 정규분포.
- B2 추세 랜덤워크: B1 + 평균(252일 일간 평균 × h).
- B3 과거 분포: 직전 2,520거래일(10년) 안의 겹치는 h일 수익률. h=20은 evolve와 같은 252일 창(B3s)도 함께.
- '가장 좋은 기준' = 수평선별로 CRPS 합이 가장 작은 기준.

## 4. 후보 모형

- M1 변동성 조건부: 하루 변동성 = EWMA(λ 0.94). 수평선 변동성² = w·EWMA² + (1−w)·전체 기간 분산, w = 반감기 60거래일로 되돌아간다고 본 평균 가중(h 20/60/250 → 약 0.89/0.72/0.33). 분포 모양 = 과거 모든 시작일의 (결과 ÷ 그날 수평선 변동성) 표본 × 오늘 수평선 변동성.
- M2 닮은 과거: 특징 6개(52주 고점 대비 낙폭, 250일 수익, 60일 수익, 20일/252일 변동성 비, 10년물 60일 변화, 10년−3개월 금리 차)를 그날까지의 순위(0~1)로 바꾸고, 거리가 가까운 과거 시작일 10%(최소 60개)의 실제 결과를 분포로 쓴다. 회사가 닫은 질문(VIX 계열·200일선·신용 띠)은 특징에 넣지 않는다.
- M3 반반: M2 절반 + B3 절반(회사 '반반' 관례).
- **M4 합침(주 후보)**: M1·M2·B3를 1/3씩 섞은 분포.
- 모든 표본 분포는 199개 분위(0.5%~99.5%)로 줄여 채점한다.

## 5. 지표와 판정

- P1 = 1 − (모형 CRPS 합 ÷ 가장 좋은 기준 CRPS 합). 세 지수를 합쳐 수평선별로 계산.
- P2 = 80% 예측 구간(10~90% 분위) 포함률.
- 신뢰구간: 시작점 h/5개(4·12·50개)를 한 덩어리로 뽑는 이동 블록 부트스트랩 1만 번, 같은 시작점의 세 지수는 함께. 시드 20261110.
- 수평선별 통과 = 아래 넷 모두:
  1. P1 > 0 그리고 95% 하한 > 0
  2. P2의 95% 구간이 80%를 품음
  3. 요즘 구간(시작점 2020-01~) P1 > 0
  4. 이웃 설정 4개(λ 0.90·0.97, 닮은 과거 5%·20%) 중 3개 이상에서 P1 > 0
- 판정 대상은 **M4 하나**다. M1·M2·M3는 참고로만 적는다. 참고 모형이 M4보다 좋아 보여도 이 자료로 주 후보를 바꾸지 않는다(바꾸면 사후 맞춤). 다음 사전 등록의 가설로만 쓴다.
- 지수별·시대별(2005~2012, 2013~2019, 2020~) P1은 참고 표시.

## 6. 기본 처분 (CLAUDE.md Default disposition)

- 통과한 수평선: '후보(표시 전용)'. 2026-11-10 뒤 시작점으로 2차 전진 채점(같은 코드·설정)을 한다. 회사 전략 점검의 참고 입력으로 쓰는 것은 사장 승인을 따로 받는다.
- 통과 못 한 수평선: NO_CHANGE. 그 수평선에는 모형을 쓰지 않고 기준(B) 분포를 그대로 쓴다. 설정을 바꿔 같은 자료로 다시 재지 않는다.
- 어느 쪽이든 노출·예산·권한을 올리지 않는다.

## 7. 한계 (미리 적음)

- 설계자(이 세션)는 이 기간 시장을 안다. 그래서 설정은 문헌 관례값(λ 0.94)과 회사 관례(반반, 20/60/250일)로만 잡았고 이웃 설정을 판정에 넣었다.
- 250일 수평선은 독립 구간이 약 21개뿐이라 통과·탈락 모두 약한 증거다.
- 지수 3개는 서로 상관이 높다(독립 표본 3배가 아님). 부트스트랩이 같은 시작점을 함께 뽑아 이를 반영한다.
- 야후 지수 자료의 과거 수정 가능성. 입력 파일 해시를 고정한다.
- 실적·밸류에이션·옵션 내재 변동성·예측시장은 긴 무료 이력이 없어 이 시험에 넣지 못했다. 이 층들은 전진 기록으로만 잰다(설계서 5절).
