## 1. 지켜야 할 것
- 추정(③)은 연구 기록(research-record.json)·카드 등록부(card_action)·결정 일지에 쓰지 않는다. 기록 전 검증에서 "estimate가 runs 문서 tickers[] 밖에 있으면 실패" 검사를 추가.
- "확인 필요" 줄은 지우지 않는다(②가 있어도 그대로).
- 이름: "손절선" 대신 "점검선·무효선(표시만)". 
- R5 표시: core 상태 "near"는 종가 ≤ 고점 × 0.75이면서 검토가 열려 있지 않은 상태(auto_core_rules.py r5_state 720~726행) — 종가가 점검선(× 0.70) 아래인데 검토가 이미 끝난 경우에도 "near"로 나온다(오늘 SOXL 103.29 < 114.954, NBIS 171.56 < 174.923, 둘 다 "near"). 화면에는 "근접"이 아니라 "선 아래 · 검토 끝남(다음 새 고점 뒤 다시 검)"처럼 종가와 선을 비교한 문구로 쓴다(core 값은 그대로, 표시만).
- 카드 문서(md): 다음에 카드를 새로 쓰거나 고칠 때부터 맨 위 표에 "보유 n주 · 중요 가격선(이름·값)"을 넣는다. 수량(주문표)은 카드에 옮기지 않는다.
