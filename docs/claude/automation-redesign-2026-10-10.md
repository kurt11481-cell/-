# 투자_V2 전면 재설계안 — "결정론 자동 운영 코어" (2026-10-10)

## 0. 결론

- **사용자 판단이 맞다.** 지금 시스템은 "자동화 시스템"이 아니라 **사람이 실행자인 문서 시스템**이다. 매일 하는 결정론 작업(키움 조회·대조·계산)을 사람이 PowerShell과 확인 코드로 돌리고, 자동화 개선안(아침 수집 R1, 대조 자동 apply, 개발 파이프라인 D1)은 모두 승인까지 받고도 "FX-1009 동결 해제 뒤"로 묶여 있다.
- **근본 원인 3개**: ① 목표 순위에서 자동화를 맨 아래에 뒀다(9/30 결정 "판단 품질 > 운영 부담 > 단순화 > 자동화", 헌법 §3에서 4순위). ② 매일 판정의 중심에 LLM이 읽는 산문 규칙(통합 점검 규칙 파일 82,682바이트)을 두고, 그 불안정을 사람 확인·Judge·해시 고정으로 막아 왔다. ③ 브로커가 이미 확정해 준 숫자를 믿지 않고 사람 확인을 끼워 넣었다(대조 확인 코드, 거래내역 수작업, 오늘 드러난 현금 검사 ⓐ).
- **재설계**: 외부 자동매매 시스템의 일반 구조를 따른다 — **매일 Windows 작업 1개(결정론 코드)**가 키움 조회 → 자동 대조 → 노출·규칙 계산 → 주문표 → 일지 → 예외 알림까지 끝낸다. LLM은 연구·설명·개발에만 쓰고, 실패해도 코어를 막지 않는다. 계산 모듈은 이미 있는 코드를 그대로 쓴다(새로 쓰는 것은 묶는 코드·규칙 이관·주문표 계산기).
- **사람의 일(목표)**: 결과 알림을 받는 것, 저녁 키움 주문 입력(주문 자동화 단계 전까지 유일한 일상 개입), 예산·상품·한도 같은 정책 변경, 긴급 정지. 그 밖의 일상 개입은 0.
- **결정은 한 번**: 7절 `재설계: A1 a, A2 a, A3 a, A4 a, A5 a, A6 a, A7 a`. 채택하면 같은 날 T1 Builder 지시문을 쓴다.

## 3. 목표 구조 — 자동 운영 코어(AUTO-CORE)

### 3-1. 원칙
- **P0** 자동 운영이 막히면 심각한 결함이다. 고칠 때는 사람 단계를 늘리는 방향을 고르지 않는다(사용자 2026-10-10).
- **P1** 브로커가 정답이다. 보유·현금·체결은 키움 숫자 그대로 쓴다. 현금 = 주문 가능액(체결 직후 대금 포함, 사용자 10/9·10/10). 가격 움직임으로 체결을 추정하지 않는 규칙은 그대로다(체결은 브로커 체결 내역으로만).
- **P2** 매일 판정은 결정론 코드가 한다. LLM은 연구(관심 명단·발굴·외부자료·SAVE)·한국어 설명·개발에만 쓰고, LLM 작업이 실패해도 코어는 돈다.
- **P3** 사람은 결과만 받는다. 알림은 행동이 있거나 예외가 있을 때 하루 1건으로 묶는다.
- **P4** 안전은 "사람 확인"이 아니라 **코드의 불변 조건 + 한도 + 자동 멈춤 + 되돌리기(백업·해시 사슬)**로 지킨다.

### 3-5. 안전 — 지키는 것과 바꾸는 것

**지키는 것(코드가 강제)**
- 키움 주문 도구는 주문 2단계 승인 전까지 쓰지 않는다. 데스크톱 앱의 주문 게이트 0도 그대로다.
- 체결은 브로커 체결 내역으로만 안다. 가격으로 추정하지 않는다.

## 5. 루프 점검 (loop-design-check, 설계 의견 — 승인 아님)
- **판정: 진행(조건부).** 형태 = 불감대 있는 조정기(매일 돌고, 바뀐 것이 있을 때만 기록·행동). 골격 = 문서 주도 정비(코드가 결과만 쓰고 상태는 한 방향, 종료 코드가 최종).
- **완료(매 실행)**: 필수 조회 return_code 0 + 불변 조건 통과(또는 HOLD 기록) + 결과 파일 스키마 통과 + 종료 코드 0. **외부 대조원**: 키움 잔고·주문 가능액·체결 내역(자기 보고 아님).
- **경계**: 코어는 정책·한도·규칙 코드·테스트를 바꾸지 않는다. **재시도**: 실행 안에서 0회 — 첫 실패에서 멈추고 알림, 다음 실행이 자연 재시도.
- 실패 1(애매한 목표) 통과 · 2(피고=판사) 통과(판정은 브로커 숫자와 코드) · 3(테스트 삭제) 보강 필요 — Builder 완료 기준에 "테스트 수 감소 금지·허용 경로 밖 변경 = FAIL" · 4(실행 중 질문) 통과 — 모르면 HOLD · 5(비대한 지시문·낡은 문서) **해당** — T4에서 정리.
- **레드 라인**: 주문 제출(2·3단계)·한도·정책 변경과 코드 병합은 사람이 마지막 스위치를 켠다. 첫날부터 전자동은 하지 않는다(T1 비교 모드 3거래일).
