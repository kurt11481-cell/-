## 왜 틀릴 수 있나 / 확인 필요

- kill 기준을 "kill"·"철회 기준" 글자로 찾는다. 앞으로 카드가 다른 표현을 쓰면 놓칠 수 있다 → 카드가 바뀌면 해시가 달라져 그날 넓게 읽으며 대조한다.
- PWR 카드 3행은 "kill 기준 ①~④ 확정", 표의 kill 줄은 "제안(… 사용자 수락 전)", PW3는 "kill ①~③" — 카드 안 문구 불일치(확인 필요, 판정에는 kill 줄을 그대로 씀).
- 대시보드 머리글 "관심 MU·BE·DELL·AMD" 고정 문구와 "A3~A6" 표기는 설계 3-6 대시보드 수정 전까지 실제 대상과 다르게 보인다 → 적용 순서 2번.
- SAVE 메모 작업(05:50)의 종목 목록에 PWR·LITE가 없다 → 통합 점검은 "메모 대상 아님"으로 표시. SAVE 작업 지시문 변경은 별도 후보(분석 라이브러리 설계의 연결 문제와 같은 종류).
- 지시문이 약 5.8KB 늘었다(python 포함). 실행 시간 변화는 수동 실행에서 확인 필요.

## 완료 기준 (기계 판정)

- 수동 실행 보고의 관심 종목이 MU·BE·DELL·PWR·LITE이고 AMD 행이 없다.
