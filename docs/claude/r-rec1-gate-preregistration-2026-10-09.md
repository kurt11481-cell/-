# R-REC1 회복 관문 리플레이 사전 등록

## 1. 질문

R-REC1 관문(막기·늦추기만)이 충격 뒤 매수를 늦춰서 (a) 더 얕은 역행을 얻고 (b) 반등 수익을 크게 잃지 않는가? 이 검증은 recovery-gate-R-REC1-2026-10-09.md 5절을 구현 수준으로 고정한 것이다. 5절의 수치·채택 기준은 바꾸지 않는다. 앞선 R-REC1-X 리플레이(노출 한도 일시 증액)와는 별개다.

## 2. 자료 (계산 전 해시 기록)

- `stock-strategy-system/backtests/soxl_signal_inputs_2026-10-01/SOXX_combined.csv` — 2010-01-04 ~ 2026-09-29, 4,210행, sha256 `00e8cdd030c38748eac563fc025222a16b2ada9e4cc09be3f6d7f28e224535f6`.
- 가격 기준: 모든 가격에 조정계수 f = adjclose / close를 곱한 값을 쓴다(종가·저가 모두). 신호(수익률, σ60, EMA50, SMA200)와 수익·MAE가 같은 조정 기준이다. 운영 규칙은 비조정 가격이지만 SOXX 배당 영향은 작다(한계로 기록).
- 2010년은 지표 예열용이다. 이벤트 판정은 2011-01-03 이후 세션에서만 시작한다(5절의 "2011~2026").
- 10/1~10/8은 자료에 없으므로 이번 EV3는 대상이 아니다. 등급 상한 C(과거 재현, 외부 가격 참고용).

## 3. 지표 정의 (오늘 t의 판정은 t 종가까지의 자료만 쓴다)

- 일간 수익률 r_t = c_t / c_{t-1} − 1 (조정 종가).
- σ60_t = 오늘 포함 최근 60개 r의 표본표준편차(ddof=1). 60개가 안 차면 지표 없음.
- σ5_t = 오늘 포함 최근 5개 r의 표본표준편차(ddof=1).
- EMA50 = `ewm(span=50, adjust=False)`, 50번째 종가부터 유효(저장소 관례). SMA200 = 200세션 단순평균(민감도에만 사용).
- 20세션 종가 고점 H20_t = 오늘 포함 최근 20개 종가의 최댓값.

## 4. 에피소드 규칙 (고정)

- 이벤트일: EV1 r_t ≤ −2.0 × σ60_t, 또는 EV2 c_t ≤ H20_t × (1 − 3 × σ60_t). EV3(뉴스)·EV4(계좌)·EV5(종목)는 과거 재현이 불가능해 넣지 않는다(한계).
- 에피소드가 없을 때 이벤트일이 오면 에피소드를 연다(개시일 t0). 열려 있는 동안 새 이벤트일이 오면 기준점을 갱신한다: C0 := 그날 종가, L0 := 그날 저가, 이벤트일 t_e := 그날, RG3 연속 카운트 := 0, DS1 마지막 날 := 없음.
- C0·L0는 개시일(또는 갱신일)의 종가·저가이다.
- 매 세션 t(> t_e) 종가에서 아래를 계산한다.
  - **RG1:** t − t_e ≥ 2세션이고 공식 훼손 없음. 과거 재현이 불가능해 "공식 훼손 없음"은 항상 충족으로 간주한다(한계).
  - **RG2:** c_t ≥ EMA50_t. (후보 = 벤치마크 = SOXX이므로 후보 조건은 같은 식이다.)
  - **RG3:** 최근 2개 세션(t−1, t) 모두 종가 > C0이고 DS1 날이 아니며, t_e 다음 날부터 t까지의 모든 저가 ≥ L0.
  - **RG4:** |r_t| ≤ 2 × σ60_t 그리고 σ5_t ≤ 1.5 × σ60_t.
  - **DS1(하락 지속):** c_t < L0 또는 c_t < EMA50_t. DS1 날은 RG3 카운트를 0으로 되돌린다(최근 2개 세션 조건이 이 날을 포함하지 못한다). 이벤트 기준점은 DS1로 바뀌지 않는다.
- **관문 열림:** 세션 t에서 RG1~RG4가 모두 참이면 열린다. 같은 세션에 시간 소멸 조건도 해당하면 관문 열림이 우선한다. 에피소드는 닫히고 매수 체결은 t+1 종가이다(LOC 다음 세션).
- **시간 소멸:** 마지막 이벤트일 또는 마지막 DS1 날로부터 20세션이 지난 세션에서 RG2가 참이면 관문이 열리지 않은 채 에피소드가 닫힌다("끝내 안 열림"으로 센다).
- 자료 끝(2026-09-29)에서 아직 열린 에피소드는 "검열(censored)"로 센다. 비율 계산의 분모에서 뺀다.
- 에피소드가 닫힌 같은 세션에 새 이벤트일이 오면 새 에피소드를 연다. 20·60세션 창이 서로 겹쳐도 에피소드는 그대로 센다(독립이 아님을 한계로 기록).

## 5. 비교 대상 (에피소드마다, 1배 SOXX 1회 매수 가정)

| 팔 | 체결 | 설명 |
|---|---|---|
| X1 | 개시일 t0의 종가 | 5절 문구 그대로 "이벤트일 종가 매수". 같은 날 종가 체결이라 실행 불가능하게 유리한 이상형이다(관문 쪽에 불리하게 보수적). |
| G | 관문이 열린 세션 t의 다음 세션 종가 | 관문 열린 에피소드만 존재. |
| N | 매수 안 함 | 수익 0, MAE 0으로 기준선. |

- 비용: 매수 체결 1회에만 10bp를 뺀다(60세션 뒤 매도 비용은 넣지 않는다, 두 팔 동일). 현금 이자 0. 수익·MAE에서 비용을 뺀다(G·X1 모두).
- 체결일 f의 가격 P_f(조정 종가)에 대해:
  - R20 = c_{f+20} / P_f − 1, R60 = c_{f+60} / P_f − 1 (비용 차감 후). f+20 또는 f+60이 자료 끝을 넘으면 그 표본은 해당 지표에서 제외하고 개수를 보고한다.
  - MAE60 = min_{k=1..60}(low_{f+k} / P_f) − 1 (음수, 값이 클수록 얕음). 60세션이 모자라면 있는 세션까지 쓰되 "미완" 표시하고 판정 표본에서는 제외한다. MAE20도 같은 식으로 보고한다.
- 놓친 반등 = P_G / P_X1 − 1 (양수 = 관문이 기다리는 동안 오른 폭, 음수 = 더 싸게 산 경우).
- 끝내 안 열린 비율 = (시간 소멸로 닫힌 에피소드) / (닫힌 에피소드 = 열림 + 시간 소멸). 검열 에피소드는 제외하고 개수를 따로 쓴다.

## 6. 채택 기준 (recovery-gate 5절 값 그대로)

관문이 열린 에피소드 중 G와 X1의 R60·MAE60이 모두 완성된 쌍만 쓴다.

| # | 기준 |
|---|---|
| a | MAE60 중앙값(G) − MAE60 중앙값(X1) ≥ +2.0%p (G가 2%p 이상 얕음) |
| b | R60 중앙값(G) − R60 중앙값(X1) ≥ −3.0%p (G가 3%p 넘게 나쁘지 않음) |

- 둘 다 충족하면 채택 후보(Independent Judge 후보), 하나라도 미달이면 미달 → 규칙 후보를 재설계한다(수치 변경은 새 사전 등록).
- **읽기 규칙(새 수치 아님):** 판정 표본(위 쌍)이 15개 미만이면 판정은 "표본 부족 — 보류"로 쓰고 채택/기각 어느 쪽 근거로도 쓰지 않는다.
- **읽기 규칙(새 수치 아님):** 기준 a는 바닥 뒤에 늦게 들어가는 팔(G)에 구조적으로 유리하다. 그래서 어떤 판정이든 결과 보고는 7절의 합산 보기와 '끝내 안 열린 에피소드'의 X1 손익을 판정 표와 같은 표에 나란히 적는다.
- 채택 후보가 되어도: Independent Judge(별도 Claude Code 세션) → 사용자 승인 → 정책·예약 점검 반영(K3)까지 아무것도 바뀌지 않는다. 이 관문은 계속 막기·늦추기만 하며 매수 근거·예산·노출 한도에 영향을 주지 않는다.

## 7. 필수 보고 (판정에 쓰지 않음)

- 에피소드 수, 열림·시간 소멸·검열 개수, 개시일 목록(연도별).
- 열림 에피소드의 개시일→체결일 평균·중앙값 세션 수, 놓친 반등 분포.
- **끝내 안 열린 에피소드의 X1 R60·MAE60 분포**(관문이 막아서 피한 손익). 이것이 좋은 반등이었다면 관문의 비용이다.
- 합산 보기: 모든 닫힌 에피소드를 하나로 보고 G(열린 것만 매수, 안 열린 것은 N)와 X1(모두 매수)의 R60·MAE60 중앙값·평균.
- 민감도(판정 불변):
  1. X1을 실행 가능형(개시일 다음 세션 종가 체결)으로 바꾼 비교.
  2. RG3의 신저가 판정을 "L0 고정"이 아니라 DS1(c < L0)이 오면 L0 := 그날 저가, C0 := 그날 종가로 재기준.
  3. RG2에 SOXX 종가 > SMA200 추가(200일선 이력이 있는 구간만).
  4. 전반(2011~2018)과 후반(2019~2026) 따로.
  5. **EV2를 상태가 아니라 진입일에만 이벤트로 셈** (EV2가 참인 날 중 전날 EV2가 거짓이었던 날만 이벤트일, EV1은 그대로). 주 판정의 해석은 R-REC1-X와 같은 문구 그대로의 읽기(EV2가 참인 날마다 이벤트 갱신)이며, 이 경우 이벤트가 오래 열려 있어 관문이 늦게 열릴 수 있다. 두 읽기의 판정이 다르면 결과 보고에 그대로 쓰고 어느 쪽으로도 채택하지 않는다.
