## 1. 쓰는 법 (기술 기준 1절과 같은 다섯 줄)

1. 스레드·제안서가 심리 지표를 인용할 때 등급과 꼬리표를 함께 적는다. 예: "S2− 선물 과매수(판정 불가, 표시만 · 켜진 지 n세션)".
2. 등급 2·3 심리 지표로 새 매매 규칙 시험을 올리지 않는다.
3. 등급 1도 매매 여부의 근거가 아니다. 판정 규칙으로 만들려면 §20 사전 등록 시험과 사장 승인이 먼저다(사장 직접 규칙은 미검증 표시).
4. 심리 단서가 여러 개 켜졌다는 것을 확신의 크기로 쓰지 않는다.
5. 나스닥 종합으로 잰 등급을 SOXL·SOXX·QQQ·개별 종목의 결과로 인용하지 않는다.

선: 심리 단서는 표시 전용이다 — 증거 강도 0. 매수·매도 어느 쪽의 근거로도 인용하지 않고, 예산·한도 상향에 쓰지 않으며, 매도를 막지도 않는다.

## 3. 심리 단서 꼬리표 (정의 원본 = 사전 등록 3절)

| 단서 | 쉬운 말 | 켜짐 | 쓸 수 있는 날 |
|---|---|---|---|
| S1− / S1+ | 빚 내 산 돈(FINRA 신용 잔고)이 1년 새 크게 늘었다 / 줄었다 | 1년 변화율의 누적 백분위 ≥ 0.80 / ≤ 0.20 | M월 값은 M+2월 첫 세션부터 |

## 6. 바뀔 조건

- NAAIM·AAII 과거 자료를 받으면 S4·S5는 새 사전 등록으로만 등급을 낸다.
- CFTC가 공개 주기·기준일을 바꾸면 S2 운영 정의를 사장 카드로 다시 정한다(사전 등록 6절).
- 이 등급표는 다시 계산하지 않는다. 새 시험은 새 사전 등록 + 독립 검수 + 고정을 거친다.
