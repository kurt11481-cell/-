# FX-1009 fx-3 실행 기록 (2026-10-09 15:0x KST, Cowork)

## 결론

- **겨울 표기 측정은 지금 할 수 없다.** 키움 30분봉(usa06011)이 2026-04-01 이전 자료를 주지 않는다. 그래서 `LABEL_VERIFIED_UTC_OFFSETS`에 "-05:00"을 넣지 않는다(측정 없이 넣으면 검증 안 된 표기를 검증됨으로 선언하게 된다). 계획 5-3의 1번 대안대로 측정을 11/2 첫 세션으로 미루고 Builder는 준비만 한다.
- **11/2 하루는 S7 종가가 "미확인"으로 표시된다**(fail-closed, 알려진 한계). 11/3 06:00 KST 이후 측정하고 한 줄 변경하면 풀린다. 계획서의 10/30 마감은 "준비 완료" 기준으로는 지킬 수 있고, "겨울 표기 반영 완료" 기준으로는 지킬 수 없다.
- 테스트 기준선(A6)은 측정과 무관하므로 Builder 0단계로 지금 만든다.

## 이탈·위험

1. 계획 5-3 완료 기준 "LABEL_VERIFIED_UTC_OFFSETS에 측정으로 확인한 겨울 시간대"는 10/30까지 충족할 수 없다(위 결론). 관제판 fx-3은 "준비 완료 + 11/3 측정"으로 갱신했고, p-u2 재개일 11/2는 그대로 둔다.
2. 겨울에는 S7 루틴(Kiwoom 30분봉 수집) 시각도 한 시간 늦다(한국 06:00 이후). 관제판 p-s7-routine의 "05:00" 표기는 11/3부터 맞지 않는다 — 그날 고친다(지금 고치지 않음).
3. 키움이 겨울 분봉 라벨을 미국 동부 현지 시각으로 주는지는 11/3까지 확인 필요다. 다르게 주면(1시간 어긋남 등) "-05:00"을 넣지 않고 사용자에게 보고한다.
