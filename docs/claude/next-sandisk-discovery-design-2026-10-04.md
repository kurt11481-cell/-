# "Next 샌디스크" 발굴 프로세스 설계 (2026-10-04, 사용자 결정 반영)

- 성격: 설계(K0, 이 문서만 새로 씀). 정책·상태 파일, 관심 명단 파일, 예약 작업, 카드는 바꾸지 않았다(이후 10/4 사용자 지시로 월간 발굴 예약 작업 1개 신설 — 17절). 사용자 결정은 15절. order_authority=false, quantity_authority=none. 매수·매도 권유 아님.
- 입력: ① 웹 리서치 3건 — 샌디스크 사례, 현재 병목 지도, 과거 5배 이상 사례 21건(실패 8건 포함) ② 시스템 자료 — `library/INDEX.md`, `next-leading-sectors-2026-10-03.md`, `watchlist-rotation-design-2026-10-03.md`(R2.1·교체 규칙), `watchlist-rubric-r2-comparison-2026-10-03.md`(현재 점수 분포), `external-claims-ledger.md`, 외부자료 「AI 인프라(2) 병목을 가진 회사와 푸는 회사를 산다」, `evals/cases/SNDK/README.md` ③ 스킬 — decision-council(Full), loop-design-check.
- 가격은 Yahoo 일봉 등 외부값(참고용, 키움 미대조). 리플레이는 D급(근사).

## 0. 결론 (먼저)

1. **새 시스템을 만들지 않는다.** 이미 있는 "월간 전체 발굴(첫 토요일) → 주간 R2.1 재채점 → 관심 5슬롯 → 카드" 앞에 **'병목 씨앗' 단계 하나**를 붙인다(REUSE). 씨앗은 발굴 결과 문서(next-sandisk-scan-YYYY-MM-DD.md)의 N절에 적는다(10/4 변경, 17절).
2. **우리 점수표로 샌디스크를 다시 돌려봤다(근사 리플레이, 3절).**
   - 포착: 현 R2.1은 2025-08-29(종가 $52.47, 저점 대비 +77%)에 8점 → 그 뒤 고점까지 약 44배. 단, 그달 발굴 문서가 NAND를 분야 게이트(F5) 안에 넣었어야 한다.
   - 유지: 정상 조정 때 점수가 6점(2025-11~12월)·4점(2026-08-07)으로 떨어진다. 지금 후보 상위권이 9~10점이라, 자동 교체였다면 **2025-11-28(약 $223)과 2026-08-07(약 $1,212) 평가에서 밀려났을 가능성이 크다.** 둘 다 큰 상승 직전이었다.
   - 그래서 필요한 것은 ① 앞단(병목 분야를 놓치지 않고 카드를 미리 준비)과 ② 유지 보호(가격 항목만으로 빼지 않기) 두 가지다.
3. **판별은 고정 판별표 'N-렌즈 v1'(4절)**: 필수 3(새 수요 · 빨리 못 늘리는 공급 · 과점) + 점화 3 중 2(바닥 후 첫 가격 인상 · 가이던스 점프 · "수요>공급" 공식 발언). 공식 출처만, 모르면 '아니오'(fail-closed). 사이클 말기 뿌리에서는 새 씨앗을 만들지 않는다.
4. **주기(5·17절)**: 월 1회(첫 토요일 07:32 예약 실행, 제안 모드 초안 → 사용자 수락) + 수시(사용자 요청, 부록 E-5)로 병목 지도·씨앗 갱신 → 나머지 토요일은 주간 점검(씨앗·G2 포함 관찰이 있을 때만, 푸시만 — 17-4) → 분기 실적 시즌에 집중.
5. **결정(6절)**: 점화 때만 위원회(decision-council, 월 1회 상한) → 관심 카드 → 기존 R2.1·교체 규칙 → 매수는 기존 상품 승인(K3, 사용자만). 위원회와 씨앗은 매매 근거가 아니다(근거는 카드).
6. **오늘 시범 적용 결과(부록 B): 지금 '씨앗'은 0개.** 가장 강한 병목의 소외주는 대부분 일본 OTC ADR(결정 3에 따라 '지표 종목'으로만 사용). 미국 상장은 '관찰'(G 2/3) 기준을 채운 종목도 없다 — VSH·TTMI는 G1 하나만 보여 '관찰 미달', WDC는 G 3/3이지만 메모리·저장 뿌리가 사이클 말기(X5)라 '지속 감시'(10/4 정정). 메모리 뿌리는 사이클 종료 신호 10개 중 8개가 켜졌지만 마이크론 반대 근거도 있어 고점 여부는 UNKNOWN.
7. 사용자 결정 완료(15·16절): B 단계형 · R2.1 연결 규칙(F5 + 유지 보호 '다음 실적 반응 재측정까지·최대 13주') · 점화 씨앗 전용 칸 1개(관심 5 + 씨앗 1) · OTC는 지표 종목 고정 · 씨앗 시총 하한 $5B · 사이클 시계는 10/8 M6 카드 입력으로만 · 발굴 실행은 예약(월 1회) + 수시(결정 6, 17절).
8. **수시 발굴 1회차(2026-10-04, 18절, 수락): 씨앗 0 · 관찰 4(CIEN·HWM·CRS·SOLS) · 제외 1(GFS, X2).** 증설이 2027~28년에 몰려 대부분 G2에서 막혔다. G2 해석(선판매된 증설)은 바꾸지 않음(결정 7, 2027-01 재검토). 판별표는 v1.1로 표시만 바꿈(결정 9).

### 1-3. 시장이 놓친 것

1. **원자재 취급**: 소비자·PC용 NAND 회사, 영업권 손상, P/B 0.5배로 봤다.
2. **원가 구조 레버리지**: 합작(JV) 원가 구조라 가격 인상분이 거의 그대로 마진이 됐다(총마진 22.7% → 84.6%, 5분기).
3. **대체 수요**: HDD 부족(리드타임 약 1년) → 데이터센터가 QLC SSD로 대체. 이어서 엔비디아가 KV 캐시 SSD 구조를 표준화.
4. **공급 절제**: 업계 감산 + 투자가 DRAM·HBM으로 쏠려 NAND 증설이 늦었다.
5. **추정 지연**: 가이던스가 컨센서스의 1.5~3배인 분기가 반복됐다.

## 2. 과거 5배 이상 사례에서 뽑은 공통점 (21건, 정성 판단)

- **5배 이상의 공통 3조건**: 아주 큰 새 수요 + 12~24개월 안에 물리적으로 못 늘리는 공급 + 바닥·소외 출발. 새 수요만 있었던 경우는 약 3배에서 멈추거나 −73~−94%로 무너졌다(SMCI 2024, AAOI 2017, Wolfspeed).
- **판별력 1위**: 공급 확대에 18~24개월 이상 걸리는가(5배와 3배를 가름). 과점 여부는 하락 깊이를 정한다.
- **가격 인상은 '바닥 후 첫 인상'만 의미 있다.** 사이클 말기의 인상·가이던스 서프라이즈는 고점 신호와 겹친다.
- **끝나는 신호**: 가격 상승률 둔화 + 증설·신규 진입 + 좋은 실적에도 주가 무반응이 함께 켜질 때.
- **주가가 데이터보다 먼저 움직였다**(MU 2016 주가 바닥이 계약가 반등보다 먼저, AXTI는 매출 −11%일 때 30배 상승) → 공식 출처만 쓰면 늦을 수 있다(13절).
- 한계: 생존 편향, 표본 작음. N-렌즈는 가설(v1)이고, 실패 사례 검증 전까지 매매 근거가 아니다(8절).

### 3-2. N-렌즈(공식 출처만)로 본 시점

## 4. N-렌즈 v1 (병목 씨앗 판별표)

- 사람이 정하고, 루프는 바꾸지 않는다(바꾸려면 사용자 결정).
- 버전: v1.1(2026-10-04, 결정 9) — 관찰 표시 분리·질문 3 보강. 판정 규칙은 v1과 같다(재검토: `next-sandisk-lens-v2-review-2026-10-04.md`).
- 모든 '예'는 공식 출처(회사 IR·보도자료·SEC·실적 원고·법령 원문) URL과 날짜가 있어야 한다. 업계 통계(TrendForce 등)는 G3에만 보조로 쓴다(출처·날짜 필수). 모르면 '아니오'.

### 4-1. 필수 (3개 모두 '예' → 씨앗)

| 항목 | 질문 | '예' 기준 |

| G1 새 수요 | 큰 새 수요가 숫자로 보이나? | 최근 공식 자료에서 ① 관련 부문 매출 YoY ≥ +20% ② 수주/출하 비율 ≥ 1.2 ③ 장기계약·선급금 공시 ④ 주요 고객의 공식 설비투자 상향 + 회사가 그 투자에 자기 제품이 들어간다고 공식 언급 — 중 하나 |

### 4-3. 증폭 (우선순위용, 필수 아님)

- A1 소외 출발: P/B ≤ 1.5 또는 EV/매출 ≤ 2, 또는 52주 고점 대비 −30% 이하, 또는 분사·손상차손 12개월 안.
- A2 가격 → 마진 레버리지: 총마진 저점 ≤ 30%이고 회사가 가격 주도 회복을 언급.

- P 플랫폼 신호: 엔비디아·하이퍼스케일러 행사에서 해당 부품을 새 표준으로 공식 언급. 주목용이고 판정에는 쓰지 않는다.

### 5-1. 병목 지도를 만드는 5개 질문 (창의 단계)

1. **대체재**: "X가 부족하면 고객은 무엇으로 바꾸나?" — HDD 부족 → QLC SSD(= 샌디스크).
2. **상류**: "X를 늘리려면 무엇이 더 필요한가?" — 광모듈 → 레이저 → InP 기판 → 결정 성장 장비.
3. **다음 병목**: "X가 풀리면 어디가 막히나? X로 투자가 몰리면 무엇이 굶나(굶는 형제 제품)?" — CoWoS 2027 완화 → HBM·기판·테스트. 굶는 형제 제품은 같은 회사·같은 공장에서 만드는 구형 규격·성숙 공정 제품 등에서 찾되, 실제 부족은 공식 자료로 확인한다. 메모리 뿌리는 사이클 말기(X5)라 이 질문의 답에서 뺀다(v1.1).
4. **아키텍처 전환**: "새 표준이 새 부품 줄을 만드나?" — KV 캐시 → SSD, 800V DC → SST·SiC/GaN, CPO → 고출력 외부광원, 글라스 코어 기판.
5. **다른 뿌리**: "AI 설비투자가 아닌 이유로도 부족한가?" — 전력망 정책(EO 14420), 수동부품 사이클, 핵심광물 수출통제. 모든 후보가 AI 설비투자 한 뿌리면 종목 분산 ≠ 테제 분산이다.

## 9. 루프 점검 (loop-design-check)

- 판정: **고쳐서 진행.** 유형: 불감대 조절기(새 공식 이벤트가 있을 때만 판정) + 월·주 일정. 골격: 문서 주도(사람 = 판별표·수락, 루프 = 결과·제안, 상태는 한 방향).
- 0단계 조건: 월간 부분은 주 1회 미만이라 자동 루프로 만들지 않는다(수동 Cowork). 주간 점화 확인만 기존 주간 작업에 얹는다(씨앗이 생긴 뒤). 단, 10/4 사용자 지시로 월간 부분을 예약 실행으로 만들었다(결정 6) — 이 조건의 예외라 제안 모드 초안·쓰기 2곳·사람 수락으로 묶는다(17-1). 주간 점화 확인은 예약 발굴의 주간 점검으로 옮겼다(결정 10, 17-4).
- 완료 기준: 월간 — 씨앗 ≤ 3, 씨앗마다 G1~G3 공식 URL·날짜, 점화 조건·kill·기한, 쓰기 허용 2곳(결과 문서·조사 원본 폴더) 밖 변경 0. 주간 — 새 공식 이벤트가 있는 씨앗만 I1~I3 예/아니오/확인 필요 + 출처, 쓰기 0.
- 경계: N-렌즈 v1·R2.1·교체 규칙·트리거·정책·상태·상품 승인 목록은 루프가 바꾸지 않는다.
- 반복 상한: 새 씨앗 월 2개, 점화 제안 주 1건, 위원회 월 1회, 씨앗 기한 12개월.
- 외부 대조: 공식 IR·SEC·실적 원고, 키움 일봉, 사후 성과는 SOXX·SPY·현금.
- 실패 유형: ① 막연한 목표 — 수정됨(고정 판별표) · ② 피고 = 판사 — 일부 해당(같은 모델이 고르고 판정) → 사후 채점·놓친 승자 감사·사용자 수락으로 보완 · ③ 경계 — 통과 · ④ 실행 중 판단 — 해당 → 컨센서스(외부값)를 판정에서 빼고 공식 숫자만, OTC는 지표 종목으로 고정(결정 3) · ⑤ 지시문 비대 — 주의 → 주간 지시문(약 29KB)에 15줄 이내만 추가(부록 C).
- 레드라인: 사람이 판별표·수락 보유, 배분·주문 자동화 없음, 루프가 자기 규칙을 고치지 않음 — 통과.

## 10. 위원회 결과 (decision-council, Full · 2026-10-04)

질문: "Next 샌디스크"를 주기적으로 찾으려면 어떤 구조로 할까? A 그대로(NO_CHANGE) · B 최소 추가(월간 N절 + 주간 점화 1단계 + 점화 시 위원회) · C 별도 서브시스템(씨앗 파일·월간 예약 작업·스크리너 코드·대시보드).

- 설계자: B — R2.1은 확인 게이트로 충분하고, 빈틈은 앞단과 유지다. 기존 문서·원장·명단·카드를 재사용한다.
- 회의론자: A — SNDK로 만든 렌즈가 SNDK를 잡는 자기 검증이고, 실패 사례 리플레이가 없다. 지금은 늦었고(종료 신호 8/10) OTC라 사기도 어렵다. "79배는 발굴이 아니라 보유에서 나왔다."
- 실용주의자: B 단계형 — 이번 달은 월간 N절만, 주간 단계는 첫 씨앗 뒤에. 씨앗 ≤ 3, 공식 점화만, 위원회 월 1회, 35일 STALE 표시.
- 비판자: B 조건부 — fail-closed(공식만, 결측 = 아니오), 위원회는 자문, OTC는 거래 확인 전 슬롯 차단. "리플레이는 포착만 봤지 유지는 안 봤다."

판정
- 합의: B 단계형(설계자·실용주의자·비판자). 새 파일·새 예약 작업·코드 없음.

## 13. 왜 틀릴 수 있나

1. 사례 하나로 만든 사후 설계다(과적합). 실패 사례 검증 전까지 N-렌즈는 가설이다.
2. 점화 신호는 사이클 말기에도 나온다. '바닥 후 첫 인상'과 사이클 시계로 줄이지만 완벽하지 않다.
3. 후보 대부분이 AI 설비투자 한 뿌리일 수 있다. '다른 뿌리' 질문(5-1 ⑤)은 보완일 뿐이다.
4. 공식 출처만 쓰면 늦을 수 있다(주가가 데이터보다 먼저 움직인다). 대신 오탐과 추격이 준다 — 의도한 교환이다.
5. 리플레이 가정: S1은 관대하게 판정, SOXX 비교는 Yahoo 값, 경쟁 후보 점수는 지금 분포로 추정. D급이다.
6. 수동 월간 세션을 건너뛰면 씨앗이 낡는다 → 주간 결과에 STALE을 표시한다.
