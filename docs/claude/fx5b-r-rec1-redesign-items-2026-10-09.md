# fx-5b R-REC1 재설계 — 사전 등록에 넣을 항목 (2026-10-09)

## 0. 결론

- 재설계의 목표는 하나다: **관문의 지연 비용(중앙값 11세션, 놓친 반등 +2.5%, R60 −1.64%p)을 줄이면서 꼬리 방어(급락 지속 구간 회피)를 잃지 않는가.**
- 주 변형은 3개(V1 RG4 한쪽만, V2 부분 관문 ⅓, V3 = V1+V2)로 제한하고, 나머지는 진단(판정 없음)과 민감도로만 낸다. 변형을 늘릴수록 우연히 통과하는 변형이 생기기 때문이다.
- 첫 리플레이에서 같은 SOXX 자료를 이미 봤으므로 이번 검증은 "깨끗한 표본 외 검증"이 아니다. 그래서 **전반·후반 둘 다 같은 방향 + QQQ 같은 방향**을 채택 조건에 넣는다.
- 기존 기준 a·b는 바꾸지 않는다(비교 가능성). 꼬리 기준 c는 새로 더하되, 채택 규칙을 계산 전에 고정한다(4절).

## 1. 이번에 확인된 설계 문제 (재설계 대상)

## 2. 주 변형 (판정 대상, 3개로 제한)

| 변형 | 바꾸는 것 | 그대로 두는 것 |
|---|---|---|
| V0 기준선 | 현행 R-REC1(첫 리플레이 구현, 해석 I2) | — |
| V1 RG4 한쪽 | RG4 = 판정일 1일 수익률 ≥ −2σ60(하락 쪽만 막음) + 5세션 σ ≤ 1.5σ60 유지 | RG1~RG3, 이벤트·DS1·시간 소멸 |
| V2 부분 관문 | RG2(벤치마크) + RG3 충족일 다음 세션에 **⅓** 매수(설계 7-1 기존 단계 재사용), 이후 RG1~RG4 모두 충족일 다음 세션에 나머지 ⅔. 부분 매수 뒤 DS1이 오면 나머지는 시계 리셋(이미 산 ⅓은 매도 규칙대로, 이 리플레이에선 보유) | RG 정의·수치 |
| V3 결합 | V1 + V2 | — |

- 진입가: V2·V3는 두 회차의 가중 평균 진입가(⅓·⅔)로 R20·R60·MAE를 계산한다. ⅔ 회차가 끝내 안 열리면 ⅓만 보유한 것으로 계산하고 별도 보고한다.
- 비교 팔: X1(이벤트 첫날 종가, 이상형)과 X1′(다음 세션 종가, 실행 가능형)을 둘 다 낸다. **주 판정은 X1′**로 한다(첫 리플레이 한계 "X1은 이상형" 반영). X1 기준 값은 같은 표에 나란히.

## 3. 진단·민감도 (판정 없음, 보고만)

- D1 RG4 차단 분석: 열린 에피소드 중 "마지막으로 충족된 조건이 RG4"인 수, 그 RG4 미충족일의 1일 수익률 부호(상승일 비율). P1의 크기를 잰다.
- D2 RG별 기여(하나씩 빼기): V0에서 RG2만 뺌 / RG3만 뺌 / RG4만 뺌 — 각각 개시→체결 세션 수 중앙값, 놓친 반등, R60·MAE60 차.
- S1 기준점 갱신: 새 이벤트일이 와도 EV1(새 가격 충격)일 때만 C0·L0 갱신, EV2 연속일은 갱신 안 함(해석 5와 다름 — 이벤트 개시는 그대로 셈).
- S2 시간 소멸 10세션(현행 20).
- S3 EV3 대리: SOXX 1일 ≤ −1.0σ60이면서 EV1·EV2가 아닌 날을 "약한 충격"으로 열고 V0·V1·V2를 같은 방식으로 계산. 뉴스 조건이 없어 EV3와 같지 않다(D, 참고만).
- S4 전반(2011~2018)·후반(2019~2026) 분리, QQQ 같은 계산(기준 ETF 바꿈, 수치 그대로).
- S5 후보 종목(PWR, 벤치마크 GRID): 자료 길이가 되면 보고만. 짧으면 "표본 부족".

## 4. 채택 기준 (계산 전 고정 — 사전 등록에 그대로 옮긴다)

표본: 각 변형에서 G와 X1′의 R60·MAE60이 모두 완성된 쌍. 15쌍 미만이면 보류.

| # | 기준 | 비고 |
|---|---|---|
| a | MAE60 중앙값(G) − (X1′) ≥ +2.0%p | 기존 값 그대로 |
| b | R60 중앙값(G) − (X1′) ≥ −3.0%p | 기존 값 그대로 |
| c (새) | 합산 보기(닫힌 에피소드 전부, 안 열린 것 = 매수 안 함)에서 MAE60 하위 10% 분위(G) − (X1′) ≥ +2.0%p | 꼬리 방어. 하위 10%는 계산 전 고정 |
| d (새, 지연 상한) | 개시→첫 매수 세션 수 중앙값 ≤ 6 | V0 11세션의 약 절반. V2·V3는 ⅓ 회차 기준 |

- **채택 후보 = b 그리고 (a 또는 c) 그리고 d**, 그리고 S4에서 전반·후반·QQQ 모두 b·d를 충족하고 (a 또는 c)의 차이 부호가 같을 것.
- 여러 변형이 통과하면 구조가 단순한 쪽(V1 < V2 < V3)을 고른다. 통과 변형이 없으면 "재설계 미달" — R-REC1은 규칙 후보(D) 그대로, 다음 행동은 사용자 결정(현행 유지 / 보류 K3).
- 기준 c·d는 이번에 새로 더한 것이다. 첫 리플레이에서 미달한 뒤 기준을 더하는 것은 "통과할 때까지 기준 바꾸기" 위험이 있다. 그래서 a·b는 그대로 두고, c는 OR로만 쓰며(기준 a를 대체하지 않음), d는 통과를 더 어렵게 하는 쪽으로만 둔다. 이 판단은 사전 등록 문서에 그대로 적는다.

## 5. 고정 문구 (구현 해석 차이를 미리 막음)

- F1 이벤트일 처리: 이벤트일에는 기준점(C0·L0·t_e)만 갱신하고 그날 관문을 평가하지 않는다(첫 리플레이 해석 I2). 독립 재구현에도 이 문장을 그대로 준다.
- F2 가격: 판정·수익·MAE 모두 정규장 일봉(조정계수 f 적용). 주간거래·프리·애프터 가격은 쓰지 않는다. 일봉 저가가 정규장 저가보다 3% 넘게 낮은 날은 이상치로 표시만 하고(과거 자료엔 정규장 저가가 따로 없음) 결과에 개수를 보고한다.
- F3 ⅓·⅔ 회차는 세션당 1회, 같은 날 두 회차 없음. V2의 ⅓ 회차는 RG2(벤치마크 종가 ≥ EMA50)와 RG3가 같은 날 충족돼야 한다.
- F4 비용: 매수 회차마다 10bp(V2·V3는 두 번).
- F5 RG1은 과거 재현 불가 → 모든 변형에서 "항상 충족"(첫 리플레이와 같음). 결과 해석에 "실제 운영은 RG1 때문에 더 늦을 수 있음"을 적는다.

## 6. 운영 연결 (채택될 때만, 지금 바꾸지 않음)

- 채택 후보가 나오면: recovery-gate 문서 2절 수정안 + 주문 지시 설계 G5 문구 + 통합 점검 2-3)④ 문구를 K3 Builder·Judge로. 그 전까지 현행 R-REC1 그대로(사용자 2026-10-09 "A 유지").
- V2가 채택되면 ⅓ 회차는 설계 7-1의 "첫 진입 ½ 규칙"과 겹친다 — 둘 중 작은 쪽을 쓴다(사전 등록에 적음).
- 이 문서 항목은 FX-1009 동결 예외가 아니라 이미 등록된 fx-5b 주제(Q3 a "R-REC1 재설계안 사전 등록") 안이다. 새 리플레이 주제가 아니다.

## 7. 틀릴 수 있는 이유

- 같은 SOXX 자료를 두 번 보는 것 자체가 과적합 위험이다(1절 문제를 결과를 보고 찾았다). S4 조건은 그 위험을 줄일 뿐 없애지 못한다.
- V1은 "급반등 추격" 쪽으로 기우는 변경이다. 반등 뒤 재하락(데드캣) 구간에서 손실이 커질 수 있고, 기준 c가 그걸 잡도록 둔 것이다.
- EV3 대리(S3)는 뉴스가 없어 실제 EV3를 대표하지 못한다.
- 단일 자산 1배 매수 가정이다. 레버리지(SOXL) 채우기·종목(PWR) 매수에 그대로 옮겨지지 않는다.
