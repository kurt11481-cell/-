# R-REC1 충격 뒤 회복 매수 관문

## 0. 왜

- S3(2026-09-30): 급락 탈출·FTD 재진입을 기계화하면 15.7년 탈출 57번, 연수익이 보유의 절반 — 가격 반등 신호 단독은 가짜가 많다. 바닥은 실시간으로 알 수 없다.
- S4-3(2026-10-01): 추세(종가 > 200일선) 때만 더하는 T1이 가장 좋았고(연 +4.1%p), 급락 추가 매수 X1은 기각(−1.1%p).
- 사용자 전략: 급락 초기 현금 보유, **회복 초기** 재매수. 2026-10-08 장중 급락(오픈AI 매출 보도·Firmus IPO 연기) 때 즉석 조건을 만든 뒤, 같은 상황에 매번 쓰도록 일반화했다.
- 원칙: 회복 매수는 "가격 반등"이 아니라 "추세 유지 + 충격 흡수 + 테제 훼손 미확인 + 변동성 정상화"일 때.

## 1. 이벤트 열기 (정규장 종가 판정, 하나라도 해당)

| ID | 조건 | 비고 |
|---|---|---|
| EV1 가격 충격 | SOXX 1일 종가 수익률 ≤ −2.0 × σ60(SOXX) | σ60 = 최근 60세션 일간 수익률 표준편차 |
| EV2 누적 하락 | SOXX 종가 ≤ 20세션 종가 고점 × (1 − 3 × σ60) | |
| EV3 테제 뉴스 충격 | 뿌리 테제(AI 설비투자 수요)를 건드리는 뉴스 + 같은 날 SOXX ≤ −1.0 × σ60 | 사용자 지정 또는 통합 점검 표시(출처 링크 필수). 2차 뉴스는 이벤트를 여는 단서일 뿐 근거가 아니다 |
| EV4 계좌 | 계좌 점검선 L1(고점 대비 −10%) 열림 | 기존 S5 R4 |
| EV5 종목 | 후보 종목 자체 1일 ≤ −2.0 × σ60(그 종목) | 그 종목에만 이벤트 |

- 기준점: 이벤트일 벤치마크 종가 C0, 이벤트일 장중 저가 L0(키움 일봉 저가).
- 벤치마크: 포트폴리오 이벤트는 SOXX. 종목 관문 RG2는 그 종목의 R2.1 기준 ETF(기본 SOXX, 전력 인프라는 GRID)와 종목 자체.
- 이벤트 중 새 이벤트가 오면 기준점을 새로 잡는다.

## 2. 회복 관문 (이벤트 중 노출을 늘리는 매수에 모두 필요)

| ID | 조건 | 근거 |
|---|---|---|
| RG1 테제 | 이벤트 뒤 2세션 경과 + 그 사이 테제를 깎는 **공식** 확인 없음(회사·하이퍼스케일러 공식 수치·설비투자 축소). 공식 확인이 나오면 카드 재작성 전 매수 금지. 공식 반박은 기록만 | 공식 출처 원칙 |
| RG2 추세 | 벤치마크 종가 ≥ EMA50 그리고 후보 종가 ≥ 후보 EMA50. 200일선 이력이 저장되면 "벤치마크 > SMA200" 추가 — 그 전에는 "확인 필요" 표시 | S4-3 T1 |
| RG3 충격 흡수 | 연속 2세션 벤치마크 종가 > C0, 그리고 이벤트 뒤 L0 아래 장중 신저가 없음 | S3(단독 사용 금지) |
| RG4 변동성 | 판정일 벤치마크 1일 변화 ≤ ±2σ60, 5세션 σ ≤ 1.5 × σ60 | S3 변동성 비중조절 |

- 판정은 정규장 종가 → 다음 세션 LOC. 관문이 열려도 첫 매수는 기존 첫 진입 ½ 규칙, 세션당 1회. 다음 회차는 RG2 유지 + DS1 없음일 때.
- 이벤트 닫힘: RG1~RG4 모두 충족(회복 확인) 또는 DS1 없이 20세션 경과 + RG2 충족(시간 소멸).

## 3. 하락 지속 규칙 (이벤트 중)

| ID | 조건 | 행동 |
|---|---|---|
| DS1 | 벤치마크 종가 < L0 또는 < EMA50 | 회복 시계 리셋(RG3를 처음부터) |
| DS2 | 보유 종목 카드 가격 트리거 — 정의·강도는 카드 그대로(예: SOXL S4 = 종가가 EMA20 아래로 **2회 연속** 마감, 약 / S5 = EMA50 아래 마감 뒤 2세션 안 미회복, 약, S4와 겹치면 1개) | 카드 규칙 그대로 그 종목 매도 검토 근거. 약 1개만으로는 G3 단계 0(지시 없음) — 종류 다른 약 2개 또는 강 1개 필요. 계획 축소 매도 재발행은 설계 7-2(새 종가 × (1 − σ60)) |
| DS3 | 계좌 점검선 | 기존 규칙(L1 가벼운 점검, L2 전체 검토·매수 멈춤) |

## 4. 권한·실패

- 막기·늦추기만 한다. 매수 근거(G3 카드)를 만들지 않고, 예산(G2)을 올리지 않으며, 매도는 막지 않는다. 노출 한도 예외는 이 규칙의 일부가 아니다.
- 자료가 없거나 오래되면 매수 쪽 fail-closed: "회복 관문: 확인 필요(사유)".
- 적용 범위: 노출을 늘리는 모든 매수(신규·ADD·교체 매수 쪽) — 공식·시범 지시서, Cowork 수시 추천, 사용자 수동 결정 지시서. 위원회는 관문 결과를 입력으로 받는다.

## 5. 검증 사전 등록 (수치는 위 값으로 고정, 계산 전)

- 자료: SOXX 일봉 2011~2026(키움 우선, 없으면 외부 참고용), 후보 대표로 SOXX 자체 1배 추가 매수 가정.
- 비교: 이벤트일 종가 매수(X1형) vs 관문 열린 날 다음 세션 매수 vs 매수 안 함.
- 지표: 매수 뒤 20·60세션 수익, 최대 역행(MAE), 놓친 반등(이벤트일→관문일 상승분), 관문이 끝내 안 열린 비율.
- 채택 기준: 관문 쪽 MAE 중앙값이 2%p 이상 얕고, 60세션 수익 중앙값이 이벤트일 매수보다 3%p 넘게 나쁘지 않을 것. 미달이면 규칙 후보를 재설계(수치 변경은 새 사전 등록).
- 검증 전 상태: 규칙 후보(D). 지시서·추천안에서는 즉시 막기용으로 쓰되, 공식 정책 반영(alert_policy·예약 점검 판정)은 검증 + Judge 뒤(K3).
