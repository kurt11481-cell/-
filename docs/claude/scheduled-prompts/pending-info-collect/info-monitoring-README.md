## 3. 예약 실행 절차 (06:20·19:20 KST)

`C = python3 -I /mnt/project-files/info-monitoring/bin/collect.py` · 날짜는 늘 `--day today`(도구가 KST로 정함 — 컨테이너 시계는 UTC).

1. **숫자**: `C numbers --day today`. 0 = 정상, 2 = 일부 STALE(그래도 계속). 출력에 `STALE_STREAK <자료> <n>`이 있으면 끝에 이 스레드 1줄(4절).
2. **점검**(v0.2부터 X보다 먼저 — X가 늦어져도 시나리오 점검 :45가 새 점검을 놓치지 않게): `C signals --day today`.
   - `DATA_CHECK <D1|D2|D3|D4> …`(새로 열림) → 이 스레드에 1줄 + 시나리오 점검 담당 스레드에 같은 내용 전달(6절). 
   - `DATA_CHECK_OPEN`(이미 열려 있음) → 글 없음(daily 파일에 남음).
   - `DATA_CHECK_OLD`(오늘 원자료 없음, 지난 원자료로 판정) → 글 없음(1의 STALE 알림이 맡음). `DATA_CHECK_SKIP` → 1줄.
   - `DATA_CHECK_CLOSED`(시나리오 점검이 닫음, 6절) → 글 없음. `JSONL_BAD_LINE <파일>` → 1줄(깨진 줄은 건너뛰고 계속).
3. **finviz(06:20 실행만)**: `C finviz --day today`. 2 = 일부 STALE, 계속. 월요일 06:20엔 회사PC가 연결돼 있으면 registry symbols를 읽기만 해서 `tickers.txt`와 대조, 다르면 `tickers.txt`를 고치고 1줄(연결 안 되면 넘어감). **v0.7: 월요일엔 대조 결과를 반드시 기록한다** — 같으면 `C roster --day today --status checked`, 고쳤으면 `--status changed`, 회사PC 연결이 안 돼 넘어갔으면 `--status skipped`. `skipped`가 2주 연속이면 `ROSTER_SKIP_STREAK`이 나온다 → 이 스레드 1줄. 월요일 기록을 빠뜨리면(또는 마지막 기록이 7일 넘으면) 5절 `C daily` 출력에 `ROSTER_NOT_RECORDED`가 하루 한 번 나온다. QQQ는 명단에 넣지 않는다(도구가 기준 지수로 따로 받음). 출력에 `FINVIZ_STREAK`(QQQ 포함 아무 종목이나 못 받은 날이 이틀 연속, 그 뒤 6일마다)·`FINVIZ_GAP`(마지막 기록 뒤 빠진 날)이 있어도 1줄. **v0.8: 같은 명령이 첫 화면 시장 폭도 받는다(따로 할 일 없음).** 출력 `breadth … OK|SKIP|STALE`은 글 없음. `BREADTH_STREAK`(첫 화면을 못 받은 날 이틀 연속, 그 뒤 6일마다 — 종목 화면과 따로 셈)·`BREADTH_GAP`(기록 세션 사이 평일이 빠짐 — 그날 값은 다시 못 받음)·`BREADTH_STOPPED`(기한 지남)이면 1줄. 주말 회차는 못 받은 금요일 세션을 다시 시도한다. 휴장일은 직전과 같은 값이 `repeat`로 남는다(달력은 쓰지 않음).
4. **X**(5절): 세 계정을 읽어 `/tmp` 아닌 세션 scratchpad에 JSON 목록을 쓰고 `C x-add --day today --file <파일>`. 새 글이 없으면 읽은 글 목록을 그대로 넘긴다(중복이라 저장 안 됨, 연속 실패 0). Chrome이 안 보이면 5절 1로 한 번 열어 보고, 그래도 안 되거나 세 계정 모두 못 읽으면 빈 목록 `[]`으로 `x-add`(연속 실패 +1). 출력에 `X_STREAK n`이면 1줄.
5. **요약**: `C daily --day today` → `daily/<날짜>.md`. 약 10초 뒤 파일 줄 수를 다시 확인(공유 폴더 지연). v0.7: 출력에 `FINVIZ_MISSING`(그날 finviz 기록 없음)·`ROSTER_NOT_RECORDED`가 있으면 1줄(하루 한 번만 나옴).
6. 알릴 것이 없으면 글 없이 끝.

종료 코드가 0·2·10 밖(3 = 도구 오류, 1 = 파일 잘림·경로 오류 등)이면 10초 뒤 1번만 다시 하고, 또 그러면 이 스레드 1줄(출력 마지막 줄 첨부)·나머지 단계는 계속.
