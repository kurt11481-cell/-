# 161행 새 문장 읽기 책상 시험 (2026-11-19 KST)

- 목적: 무인 실행 모델이 새 '재원 우선' 문장을 참고 판정 함수와 같게 읽는지(독립 검토 지적 8).
- 방법: Sonnet 작업자 1회(도구 없음)에 새 161행 '재원 우선' 문장만 주고, 관문 날을 가정한 매수 요건 15행(실기록 ② 칸 표기 + 경계 사례)을 행마다 '센다/뺀다'로 판단하게 함. 기대값은 이 스레드가 미리 정함(작업자에게 주지 않음).
- 결과: **15/15 기대와 같음.** 센다 = 1(② 통과)·5(현금 부족만)·6(통과, '… 없음' 부정문)·7(막힘 사유 없는 확인 필요)·12(통과 칸 괄호 속 확인 필요). 뺀다 = 2·8(상품 승인 없음)·3(R5)·4(추가 매수 멈춤(S7 L4·L5))·9(① 막힘)·10(SOXL 배수 3)·11(QQQ)·13(종목 상한)·14(현금 + 배수 확인 필요)·15(⑤ 막힘). 결론 '보류'.
- 작업자가 애매하다고 적은 행: 12(괄호 속 확인 필요), 10(② 통과인 SOXL) — 둘 다 문장대로 판단.
- 한계: 1회·1모델·15행. 실제 예약 실행(Sonnet 5.5, 긴 규칙 전체 문맥)과 같다는 보장은 아니다 → 첫 관문 날 실행 확인(제안서 5절 5번).
