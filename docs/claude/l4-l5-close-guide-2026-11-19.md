## 0. 결론
- **지금 닫을 근거는 충분하다.** 검토에 필요한 카드 3장(BE·LITE·SOXL)이 모두 11/06~11/17에 새로 쓰였고, SOXL 줄이기(3배 계좌 10%)도 11/19 체결·일지 기록까지 끝났다.
- **권장 시점: 11/20(금) 아침 07:45 코어 결과를 본 뒤.** 매도 뒤 E와 3배 비중이 코어 값으로 처음 확인되는 날이라, 결론 문장에 "SOXL 10% 실행 완료"를 확인된 사실로 쓸 수 있다.
- **안 닫아도 위험해지지 않는다.** 새 매수·추가 매수 권고만 계속 멈춘다. 다만 판 돈(현금 약 25%)이 QQQ로 가는 길은 이것 때문에 **영원히** 막혀 있다(시간이 지나도 저절로 안 풀림).
- 닫아도 바로 QQQ를 사지 않는다. R-REC1 관문이 아직 열려 있어 그게 닫혀야 QQQ 줄이 나온다.

## 1. L4·L5가 무엇인가
- S7(계좌 노출 점검)은 계좌가 최고점(HWM) 대비 얼마나 내려왔는지 10%씩 선을 긋는다. L1 = 최고점의 90%, L2 = 80%, … **L4 = 60%, L5 = 50%**, L6 = 40%.
- 선 아래로 내려가면 그 선의 '검토'가 열린다. 할 일은 `full_review_cards_vs_cash_and_spy` = 보유 카드를 현금·SPY와 비교해 다시 보기.
- 열린 날: **L4 11/02, L5 11/05**(holding-card-BE-2026-11-06.md 100행).
- 열려 있는 동안: 추가 매수·신규 매수 권고만 멈춘다. 매도는 막지 않고 자동 매도도 없다(같은 100행).
- 지금 상태(S7 11/18 파일 `workspace/outputs/exposure-review/2026-11-18/portfolio-exposure-review.20261118T211629581124Z.json`):
  - `pauses.new_buy_recommendations` 사유 = REVIEW_LINE_OPEN:L4 · REVIEW_LINE_OPEN:L5 · EXPOSURE_HARD_CEILING
  - `pauses.add_recommendations` 사유 = REVIEW_LINE_OPEN:L4 · REVIEW_LINE_OPEN:L5
  - L6까지 거리 약 14.7%(11/18 종가 기준). L6가 열리면 새 검토가 따로 생긴다.

## 4. 닫지 않으면 막히는 것
```
판 돈(현금) ─▶ QQQ 줄이 나오려면 셋 다 필요
   │
   ├─ ⓐ QQQ 등록 ............ 끝(11/17)
   │
   ├─ ⓑ S7 새 매수 멈춤 없음
   │     ├─ E 절대 상한 ....... 매도로 풀릴 것(11/20 확인)
   │     └─ L4·L5 검토 열림 ... ★ 사장 문장 없으면 안 풀림
   │
   └─ ⓒ R-REC1 사건 닫힘 ..... 시장이 정함(날짜 모름)
   │
   ▼
셋 다 풀린 날 06:40 통합 점검이 'QQQ' 줄을 냄 → 수량은 사장 입력
```
- 같은 이유로 관심 명단·카드 종목의 새 매수 줄도 L4·L5가 닫힐 때까지 안 나온다.
- BE·LITE 추가 매수는 닫아도 안 나온다(두 카드 HOLD·ADD 불가).

## 5. 사장이 할 일 — 한 단계씩
1. **11/20(금) 아침 07:45 코어 결과를 기다린다.** 사장실 첫 답의 주문표 한 줄과 3배 비중이 10% 이하인지 본다. (10%를 넘었다고 나오면 문장 끝의 "실행 완료"를 빼고 그대로 쳐도 된다.)
2. **Cowork 투자_V2 대화를 연다**(이 프로젝트 사장실이 아니다).
3. **아래 문장을 그대로 친다**(예시일 뿐, 이 문서가 대신 승인한 것 아님):
   > S7 L4·L5 검토 결론: BE·LITE HOLD(추가 불가), SOXL은 11/05 결정대로 3배 계좌 10%까지 줄임(11/19 실행 완료). 판 돈은 11/08 결정대로 QQQ 관문 통과 뒤. 이대로 L4·L5 둘 다 일지에 기록해
4. **Cowork가 제안 2건(L4·L5)과 확인 코드 2개를 보여준다.** 내용이 위 문장과 맞는지 본다.
5. **코드를 하나씩 친다:** `확인 <L4 코드>` → `확인 <L5 코드>`. 코드는 Cowork 화면에 나온 것만 쓴다(추측·재사용 금지).
6. **다음 날 아침 사장실에서 확인한다:** S7 파일 `pauses`에서 REVIEW_LINE_OPEN:L4·L5가 사라졌는지. 사라지면 끝.

결론값 고르기: 지난 L3는 `other`(그때 SOXL을 줄일 예정이었음). 이번엔 줄이기가 끝나 `continue`(그대로 이어감)도 맞을 수 있다. 어느 쪽이든 멈춤 해제 효과는 같다. Cowork가 고르게 두면 된다(확인 필요 아님 — 스크립트가 둘 다 받음, 92행).
