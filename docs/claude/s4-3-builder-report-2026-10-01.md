## 4. 해석 주의 (F1.32 통과의 취약점, 확인 필요)

1. **SPX G1은 배당 보정에 의존한다.** 가격 지수 기준 F1.32의 S 평균 연수익 차는 +0.499%p로 기준 +0.5%p에 근소하게 못 미친다. 배당 보정(S_TR)에서는 +1.55%p로 통과한다. 사전 등록 대체 규칙(D1)에 따라 배당 보정으로 판정했다.
   - Shiller 자료가 2023-06까지라 그 뒤 814세션은 마지막 월 값을 이어 썼다.
   - 추가 노출(3배분)이 배당을 3배로 받는다는 모형이다.
2. **G3 꼬리 한도에 가깝다.** F1.32의 S 전체 최대 낙폭 차 −14.0%p(한도 −15%p). N 2010~ −11.0%p, SOX 2010~ −10.3%p. 사용자가 −10%p에서 −15%p로 완화한 뒤에야 통과한 구조다. 1.0배보다 급락마다 9~11%p 깊고, 최악 1년 창은 약 −10%p 더 나쁘다.
3. **수익 이득이 작다.** F1.32의 SPX 연수익 차는 가격 지수로 +0.5%p. N +2.2%p. 시기별로는 2000-04 N −7.4%p/년, 1995-99 N +17.8%p/년이다(G7은 통과: N 1995-99가 42%).
4. 1.32배는 SOX 32년 자료의 최적 고정 배수라서 SOX 설계 오염이 있다. N·S 최적 고정 배수는 N 2.00, S 1.68이다(최적점 주변은 평평).
5. 조건부 후보(T1·T2·K132-G·T2-132b)는 N·S 전체에서 +0.8~+3.1%p, 꼬리 −1.0~−7.6%p로 더 균형이 좋다. G4(N0)에서 졌다. 1985~94 NDX는 추세·게이트 후보가 B0보다 연 −0.6~−3.9%p 뒤처졌다(1990~94 구간). 이를 사후에 완화하지 않았다. S5에서 이 기각을 어떻게 다룰지는 사용자·Judge 몫이다.
