  - 카드 → 일지 → 채점(서보형): 완료 기준과 외부 대조원(키움 종가·현금·SPY)은 있으나 10/9 오전까지 입력 0건, 같은 세션 기록 단계가 없음 → 판정 "수정"(O7, 소급 기록 시작됨).
  - 지시서 루프: 실패 2(피고가 판사) 위험 — 관문 계산·위원회·지시서 작성이 같은 Cowork 세션(D5). 계산기·검증기 전까지 사람 확인이 마지막 스위치.
