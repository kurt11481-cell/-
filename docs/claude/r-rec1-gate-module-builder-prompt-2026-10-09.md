## 3. 동작 정의 (리플레이와 동일, 아래 해석은 바꾸지 않는다)

입력: 벤치마크(SOXX 또는 GRID)와 후보의 일봉 목록(date, open, high, low, close), 외부 이벤트 입력(EV3 날짜 목록, EV4 열림 여부와 날짜, EV5 종목 이벤트일 목록).
출력: 마지막 세션 기준 상태 객체 — 열린 이벤트 목록, 기준점(C0, L0, 마지막 이벤트일), RG1~RG4 각각 참/거짓/확인 필요와 이유, DS1 마지막 날, 닫힘 사유(열림/시간 소멸/없음), 판정 요약("노출 증가 매수 가능/막힘/확인 필요").

- 지표: r = c_t/c_{t−1} − 1, σ60 = 오늘 포함 60개 r의 표본표준편차(ddof=1), σ5도 같음, EMA50 = 지수평균(span=50, adjust=False)이고 50번째 종가부터 유효, 20세션 종가 고점 H20 = 오늘 포함.
- 이벤트: EV1 r ≤ −2σ60, EV2 c ≤ H20 × (1 − 3σ60)(상태 읽기: 참인 날마다 이벤트일), EV3는 입력 날짜, EV4는 입력 열림일, EV5는 그 종목에만.
- 처리 순서: **이벤트일에는 기준점만 갱신하고 관문은 평가하지 않는다**(C0 := 그날 종가, L0 := 그날 저가, t_e := 그날, RG3 카운트 0, 시간 소멸 시계 재시작).
- RG1: t − t_e ≥ 2세션 **그리고** 공식 훼손 입력이 없음(입력 없으면 "확인 필요" — 리플레이와 달리 운영은 막힘 쪽).
- RG2: 벤치마크 c ≥ EMA50, 후보 c ≥ 후보 EMA50. SMA200은 선택 입력(없으면 "확인 필요"로 표시만, 판정에는 넣지 않음).
- RG3: 최근 2개 세션 모두 c > C0이고 DS1 날이 아님, 그리고 t_e 다음 날부터 오늘까지 저가가 모두 ≥ L0. 일봉 저가가 그날 정규장 저가보다 3% 넘게 낮으면 정규장 저가를 쓰는 보정은 **입력으로 받은 정규장 저가 목록이 있을 때만** 적용하고, 적용하면 이유를 출력에 남긴다.
- RG4: |r_t| ≤ 2σ60 그리고 σ5 ≤ 1.5σ60.
- DS1: c < L0 또는 c < EMA50 → RG3 카운트 0, 시간 소멸 시계 재시작.
- 열림: RG1~RG4 모두 참. 시간 소멸: 마지막 이벤트일 또는 DS1일로부터 20세션 + RG2. 같은 세션에 둘 다면 열림 우선.
- 이벤트 조회 창: 최근 60세션(열린 이벤트가 창 밖으로 빠지는 fail-open 차단). 일봉이 부족하거나(σ60·EMA50 계산 불가), 벤치마크·후보 일봉이 없거나, 날짜가 연속적이지 않으면 "확인 필요(막힘)"이고 어떤 경우에도 "가능"으로 기본값을 두지 않는다.
- 이 모듈은 매수만 막거나 늦추는 표시 값이다. 매도에 영향 없음, 매수 근거를 만들지 않음, 예산을 올리지 않음. 주문·키움 도구 호출 없음, 파일 쓰기 없음(CLI는 stdout JSON만).
