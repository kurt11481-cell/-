## 2. 기준선 V0 규칙 (첫 리플레이 그대로 — 독립 재구현이 이 절만으로 V0를 만들 수 있게 적음)

### 2-1. 가격과 지표 (세션 t의 판정은 t 종가까지의 자료만)

- 조정계수 f = adjclose / close. 종가 c = adjclose, 저가 lo = low × f. 신호·수익·MAE 모두 이 조정 기준(F2).
- r_t = c_t / c_{t−1} − 1. σ60_t = 오늘 포함 최근 60개 r의 표본표준편차(ddof=1, 60개 미만이면 없음). σ5_t = 최근 5개 r의 표본표준편차(ddof=1).
- EMA50 = `ewm(span=50, adjust=False)`의 종가 평균, 처음 49개 값은 없음(50번째 종가부터 유효). H20_t = 오늘 포함 최근 20개 종가 최댓값(20개 미만이면 없음).
- 평가 시작 2011-01-03(그 전 2010년은 지표 예열). 자료 끝 2026-09-29.

### 2-2. 에피소드 (V0)

- 이벤트일: EV1 r_t ≤ −2.0 × σ60_t (σ60 있음), 또는 EV2 c_t ≤ H20_t × (1 − 3 × σ60_t) (σ60·H20 있음). EV2는 조건이 참인 날마다 이벤트(상태 읽기).
- 에피소드가 없을 때 이벤트일이 오면 연다: t0 = t_e = t, C0 = c_t, L0 = lo_t, 이벤트 뒤 최저 저가 minlow = +∞, RG3 카운트 = 0, 시계 기준 last_reset = t, 갱신 횟수 0. 그날은 관문을 평가하지 않는다.
- 열린 동안 이벤트일이 오면 기준점 갱신: t_e = t, C0 = c_t, L0 = lo_t, minlow = +∞, 카운트 = 0, last_reset = t, 갱신 횟수 +1. **그날은 관문을 평가하지 않는다(F1, 해석 I2).**
- 이벤트일이 아닌 열린 세션 t에서 순서대로: minlow = min(minlow, lo_t). DS1 = (c_t < L0) 또는 (c_t < EMA50_t). DS1이면 카운트 = 0, last_reset = t. 아니면 c_t > C0일 때 카운트 + 1, 아니면 0.
  - RG1: t − t_e ≥ 2 (공식 훼손 없음은 항상 충족, F5).
  - RG2: c_t ≥ EMA50_t.
  - RG3: 카운트 ≥ 2 그리고 minlow ≥ L0.
  - RG4: |r_t| ≤ 2 × σ60_t 그리고 σ5_t ≤ 1.5 × σ60_t.
  - RG1~RG4 모두 참 → 관문 열림(gate_day = t). t+1이 자료 안이면 체결 f = t+1(상태 opened), 아니면 opened_nofill. 에피소드 닫힘.
  - 아니고 (t − last_reset ≥ 20) 그리고 RG2 → 시간 소멸(decay), 에피소드 닫힘. 같은 세션이면 관문 열림이 우선.
- 자료 끝에서 열린 에피소드는 censored. 에피소드가 닫힌 다음 세션부터 새 이벤트일이 오면 새로 연다.

### 2-3. 비교 팔과 지표

- 체결 세션 f의 진입가 P = c_f × 1.001(매수 회차마다 10bp, F4). R_H = c_{f+H} / P − 1, MAE_H = min(lo_{f+1..f+H}) / P − 1 (H = 20, 60). f + H가 자료 끝을 넘으면 그 값은 없음(미완).
- G = 관문 팔(체결 f). X1 = 개시일 t0 종가 체결(이상형). **X1′ = t0 + 1 종가 체결(실행 가능형, 이번 주 판정).**
- 놓친 반등(첫 리플레이 정의) = c_f / c_{t0} − 1. 이번에는 X1′ 기준 c_f / c_{t0+1} − 1도 함께 낸다.

### 4-3. 채택 기준 (항목 문서 4절)

표본: 각 변형에서 G와 X1′의 R60·MAE60이 모두 완성된 쌍. 15쌍 미만이면 보류.

- **채택 후보 = b 그리고 (a 또는 c) 그리고 d**, 그리고 S4에서 전반·후반·QQQ 모두 b·d를 충족하고 (a 또는 c)의 차이 부호가 같을 것.
- 여러 변형이 통과하면 구조가 단순한 쪽(V1 < V2 < V3)을 고른다. 통과 변형이 없으면 "재설계 미달" — R-REC1은 규칙 후보(D) 그대로, 다음 행동은 사용자 결정(현행 유지 / 보류 K3).
- 기준 c·d는 이번에 새로 더한 것이다. 첫 리플레이에서 미달한 뒤 기준을 더하는 것은 "통과할 때까지 기준 바꾸기" 위험이 있다. 그래서 a·b는 그대로 두고, c는 OR로만 쓰며(기준 a를 대체하지 않음), d는 통과를 더 어렵게 하는 쪽으로만 둔다. 이 판단은 사전 등록 문서에 그대로 적는다.

### 4-4. 고정 문구 (항목 문서 5절)

- F1 이벤트일 처리: 이벤트일에는 기준점(C0·L0·t_e)만 갱신하고 그날 관문을 평가하지 않는다(첫 리플레이 해석 I2). 독립 재구현에도 이 문장을 그대로 준다.
- F2 가격: 판정·수익·MAE 모두 정규장 일봉(조정계수 f 적용). 주간거래·프리·애프터 가격은 쓰지 않는다. 일봉 저가가 정규장 저가보다 3% 넘게 낮은 날은 이상치로 표시만 하고(과거 자료엔 정규장 저가가 따로 없음) 결과에 개수를 보고한다.
- F3 ⅓·⅔ 회차는 세션당 1회, 같은 날 두 회차 없음. V2의 ⅓ 회차는 RG2(벤치마크 종가 ≥ EMA50)와 RG3가 같은 날 충족돼야 한다.
- F4 비용: 매수 회차마다 10bp(V2·V3는 두 번).
- F5 RG1은 과거 재현 불가 → 모든 변형에서 "항상 충족"(첫 리플레이와 같음). 결과 해석에 "실제 운영은 RG1 때문에 더 늦을 수 있음"을 적는다.

## 5. 구현 해석 (계산 전 고정, J1~J21)

원문이 열어 둔 점을 아래처럼 읽는다. 원문의 숫자는 바꾸지 않는다.

- **J1 V0.** 첫 리플레이 스크립트의 `build_ind`·`simulate`·`metr`·`pair_eval`·`full_report`를 수정 없이 불러 쓴다(해석 I1~I10). 변형용 새 시뮬레이터는 V0 설정에서 불러 쓴 `simulate`와 SOXX·QQQ 에피소드(t0·상태·관문일·체결일·시간 소멸일·갱신 횟수)가 완전히 같아야 한다.
- **J2 팔.** 주 판정 = G 대 X1′. X1 값은 같은 표에 나란히 적는다(판정에 쓰지 않음).
- **J3 V1 RG4.** RG4 = (r_t ≥ −2 × σ60_t) 그리고 (σ5_t ≤ 1.5 × σ60_t).
- **J4 V2·V3 회차 시점.** ⅓ 결정 세션 t1 = 에피소드에서 평가되는 세션(이벤트일 제외, F1) 중 RG2와 RG3가 같은 날 참인 첫 세션(F3). RG1의 "2세션 경과"는 RG3의 연속 2세션 카운트에 이미 들어 있다. 체결 f1 = t1 + 1. ⅔ 결정 세션 t2 = t1보다 뒤의 평가 세션 중 RG1~RG4가 모두 참인 첫 세션(V2는 V0의 RG4, V3는 J3의 RG4). 체결 f2 = t2 + 1. 같은 세션에 두 회차를 결정하지 않는다(t1에 RG1~RG4가 모두 참이어도 ⅔는 다음 평가 세션부터 본다).
- **J5 ⅓ 뒤의 진행.** ⅓ 뒤에도 에피소드는 V0 규칙대로 진행한다: 새 이벤트일은 기준점·카운트·시계를 갱신하고, DS1은 카운트와 시계(last_reset)를 리셋한다(원문 "나머지는 시계 리셋"). ⅔ 전에 시간 소멸 조건이 오면 상태 third_only(⅓만 보유)로 닫는다. ⅓ 전에 오면 decay(매수 없음). 같은 세션이면 회차 결정이 시간 소멸보다 우선(I6 확장). ⅓ 또는 ⅔ 결정이 자료 마지막 세션이라 체결이 없으면 각각 opened_nofill · full_nofill로 닫고 판정·합산에서 뺀다. 자료 끝에서 ⅓만 산 채 열려 있으면 censored_third(판정·합산·d에서 뺌).
- **J6 V2·V3 진입가와 기준일.** P_i = c_{f_i} × 1.001, 가중 평균 진입가 P̄ = (1/3)·P1 + (2/3)·P2(회차 비중은 주수 기준 — 설계 7-1 "수량 = Δ × r"). **주 읽기: 기준일 a = f2**(두 회차가 끝난 날). R_H = c_{a+H} / P̄ − 1, MAE_H = min(lo_{a+1..a+H}) / P̄ − 1. **보조 읽기: 기준일 a = f1**(같은 P̄, MAE 창 f1+1..f1+H). 두 읽기의 채택 판정이 다르면 둘 다 보고하고 어느 쪽으로도 채택하지 않는다(첫 사전 등록 7절 5번 선례). ⅓ 회차 보유 구간 MAE = min(lo_{f1+1..f2}) / P1 − 1도 보고한다.
- **J7 third_only.** 판정 쌍(a·b)에서는 V0의 시간 소멸 에피소드처럼 뺀다. 개수와 ⅓ 기준 R60·MAE60(P1 기준)을 따로 보고한다(원문 "별도 보고"). 합산 보기(c)에서는 계획 금액 기준으로 R60 = (1/3)(c_{f1+60} / P1 − 1), MAE60 = (1/3)(min(lo_{f1+1..f1+60}) / P1 − 1)로 넣는다(원문 "⅓만 보유한 것으로 계산").
- **J8 판정 쌍.** V0·V1은 상태 opened, V2·V3는 상태 full인 에피소드 중 G와 X1′의 R60·MAE60이 모두 완성된 쌍. 15쌍 미만이면 "표본 부족 — 보류".
- **J9 합산 보기(c).** 닫힌 에피소드(V0·V1: opened · decay, V2·V3: full · third_only · decay) 중 X1′의 R60·MAE60이 완성되고 G 쪽 값도 완성된 것(decay는 G = 0·0). 하위 10% 분위 = `numpy.percentile(x, 10)`(선형 보간). c = 분위(G MAE60) − 분위(X1′ MAE60).
- **J10 d.** V0·V1 = opened 에피소드의 (f − t0) 중앙값. V2·V3 = full과 third_only 에피소드의 (f1 − t0) 중앙값.
- **J11 채택 판정.** 주(SOXX 2011~) 쌍 N ≥ 15이고 b 그리고 (a 또는 c) 그리고 d. 그리고 S4의 세 부분 표본(전반 t0 ≤ 2018-12-31 · 후반 t0 ≥ 2019-01-01 · QQQ 전체) 각각에서 b와 d를 충족하고, 주 표본에서 충족한 기준(a 또는 c — 둘 다면 어느 하나) 중 적어도 하나가 세 부분 표본 모두에서 차이 > 0(같은 부호)일 것. 부분 표본의 쌍이 15개 미만이면 그 부분 표본은 미충족으로 본다(fail-closed, "표본 부족" 표시). 기준값 비교는 반올림하지 않은 값으로 한다. 통과 변형이 여럿이면 V1 < V2 < V3 순으로 단순한 쪽. J6 두 읽기가 같아야 한다.
- **J12 D1 (V0 주 표본).** 차단일 = 에피소드의 평가 세션 중 RG1·RG2·RG3가 참이고 RG4가 거짓인 날. 보고: 차단일 수, 그중 r_t > 0 비율, 원인별 수(r_t > 2σ60 · r_t < −2σ60 · |r_t| ≤ 2σ60이지만 σ5 > 1.5σ60). "RG4가 마지막 조건"인 에피소드 = 열린 에피소드 중 관문일 g의 직전 세션 g−1이 같은 에피소드의 평가 세션(g−1 > t_e)이고 차단일인 것 — 개수와 그 g−1의 상승일 비율.
- **J13 D2 (V0 주 표본).** 관문 조건에서만 RG2 / RG3 / RG4 중 하나를 뺀다(시간 소멸의 RG2 조건, DS1의 카운트·시계 리셋은 그대로). 보고: 상태 수, 개시→체결 중앙값, 놓친 반등 중앙값(X1′·X1 기준), a·b 차(X1′, X1 병기).
- **J14 S1.** 개시는 V0처럼 EV1·EV2(상태) 모두. 열린 동안 EV1일만 기준점을 갱신하고 평가하지 않는다. EV2만 참인 날은 보통 평가 세션이다(갱신 없음, 시계 리셋 없음). V0~V3.
- **J15 S2.** 시간 소멸 20 → 10세션. V0~V3.
- **J16 S3.** 이벤트에 W = {r_t ≤ −1.0 × σ60_t, EV1 아님, EV2(상태) 아님}를 더한다. W일은 이벤트와 똑같이 열고 갱신한다. V0·V1·V2. 전체 에피소드와 W로 열린 에피소드(t0 ∈ W)를 따로 보고한다.
- **J17 S4.** 전반·후반은 주 표본 에피소드를 t0 날짜로 나눈다(a·b·c·d 모두 그 부분 에피소드로 계산). QQQ는 같은 코드에 `QQQ_combined.csv`(같은 조정 방식, 평가 시작 2011-01-03). V0~V3.
- **J18 S5 (보고만).** 후보 PWR, 벤치마크 GRID, 키움 수정주가 일봉(adjusted 1이라 f = 1, 종가 = cur_prc). 이벤트 = SOXX의 EV1·EV2(SOXX σ60·H20) + EV5(PWR r_t ≤ −2 × PWR σ60_t). 기준점 C0·L0 = 이벤트일 GRID 종가·저가. RG2 = (GRID 종가 ≥ GRID EMA50) 그리고 (PWR 종가 ≥ PWR EMA50). RG3·RG4·DS1은 GRID 값(GRID r·σ5·σ60·EMA50). 시간 소멸의 RG2도 이 RG2. 수익·MAE·X1′는 PWR 가격. 날짜 = SOXX·GRID·PWR 공통 날짜, 평가 2011-01-03~2026-09-29. 앞쪽 거래량 0 자리표시 행이 있으면 지운다. 쌍 15개 미만이면 "표본 부족". V0~V3.
- **J19 F2 이상치 표시.** 평가 구간에서 조정 저가 < 0.97 × min(조정 시가, 조정 종가)인 날을 "정규장 밖 저가 의심"으로 센다(SOXX·QQQ, S5는 PWR·GRID). 과거 자료에 정규장 저가가 따로 없어 대리 기준이다. 표시만 하고 계산에서 빼지 않는다.
- **J20 놓친 반등(V2·V3).** ⅓ 회차 c_{f1} / c_{t0+1} − 1과 P̄ / (c_{t0+1} × 1.001) − 1을 함께 낸다.
- **J21 보고 단위.** 비율 차는 %p, 소수 둘째 자리. 판정은 반올림 전 값.

## 7. 검증 절차

1. 이 문서의 raw·LF sha256을 `.sha256`에 고정 시각과 함께 적는다(4절 원문 대조 결과 포함).
2. 새 스크립트 `stock-strategy-system/backtests/fx5b_r_rec1_redesign_replay_2026-10-09.py`가 실행 전에 이 문서 해시와 1절 입력 해시를 대조한다. 첫 리플레이 스크립트는 `importlib`로 불러 쓰고 고치지 않는다.
3. **V0 대조(계산 전):** 불러 쓴 V0를 SOXX로 다시 돌려 첫 리플레이 결과 JSON의 primary·sens2_rebase·sens3_sma200·sens4·sens5_ev2_crossing과 값이 완전히 같은지 본다. 같지 않으면 멈춘다. 그다음 새 시뮬레이터의 V0 설정이 불러 쓴 V0와 에피소드 단위로 같은지 본다(SOXX·QQQ).
4. 자체 시험(`--self-test`): V1 상승 급등일 통과, V2 ⅓·⅔ 시점과 같은 날 두 회차 금지, ⅓ 뒤 DS1 시계 리셋, third_only, S1 EV2 비갱신, S3 W 이벤트, P̄·⅓ 환산, 분위 계산, 미래 정보 누출 없음(앞부분만 넣어도 닫힌 에피소드가 같음).
5. 계산(`--run`) → 결과 JSON·에피소드 CSV.
6. 독립 재구현: 이 문서와 1-1의 입력 파일만 받은 별도 에이전트(스크립트·결과 미열람)가 구현해 주요 수치(변형별 상태 수, 쌍 N, a·b·c·d, S4 부분 표본 판정, D1, S5)를 대조한다. 차이는 원인과 함께 결과 문서에 적는다.
7. 권한: 과거 계산만. 주문 도구·정책·상태·결정 원장·예약 작업을 바꾸지 않는다.
