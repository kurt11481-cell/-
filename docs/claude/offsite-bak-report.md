- **해석에서 갈린 부분**:
  1. git 출력은 `cmd /c ... 2>&1` 대신 `cmd /c ... > out 2> err`로 임시 폴더의 파일 두 개에 받아 UTF-8로 읽음. 한글 경로가 콘솔 코드페이지 때문에 깨지지 않게 하고, stderr 경고가 경로 목록에 섞이지 않게 하려는 것. note에는 stdout+stderr 마지막 줄을 씀. 목록용 읽기 명령(log·ls-files)에만 `-c core.quotePath=false`(그 명령 한 번에만 적용, 설정 쓰기 아님)를 붙이고, push 명령은 지시 그대로 둠.
  2. DryRun일 때 push·copy state는 `PLANNED`(그래서 status는 WARN). copy의 files·bytes는 계획된 원본 기준.
