## 0. 결론

**바꿔야 한다. 먼저 바꿀 곳은 연구가 판단에 들어가는 길이고, 노출·매도 숫자는 연구 가설을 시험한 뒤 바꾼다.**

지금 원장과 리포트는 회사 공식 사실이 될 때만 코어에 닿는다. 코어의 LLM 입력은 연구 기록뿐이고 그중 회사 공식 출처 사실만 남긴다(CLAUDE.md 48~50행, 코어 코드 auto_core_inputs.py 225~277행). 증권사 리포트로 만든 시장 전제 SCN-27H1은 표시 전용이고(CLAUDE.md 115행), 연구 기록에 실린 SCN 줄(integrated_check_run.market)은 코어가 읽지 않는다(코어 코드에 "market" 키를 읽는 곳 0, integrated_check_run은 비교 모듈만 쓰고 market은 읽지 않음 — auto_core_decide.py 689행, auto_core_compare.py 167~270행). 원장 항목 중 10/4 이후 받은 42개는 카드에 하나도 인용되지 않았다(ledger-apply 45행 G5). 다만 보유 BE·LITE의 원장 항목은 이미 카드 트리거에 이어져 있다(BE3, LT2·LT3 — 원장 64~81·313~324행). 사장이 찾은 자료가 매매에 거의 닿지 않는다는 지적은 대체로 맞다.

**추천 a — 검증 먼저 + 사람 결정 연결** (코어·정책·권한 변경 0):
1. **a-1 원장 종목 항목을 트리거 후보로.** 원장 항목마다 "회사가 공식으로 무엇을 발표하면 + / −인가"를 적고, 관심·보유 종목 것은 다음 통합 점검 규칙 개정 때 트리거로 넣을지 사장이 고른다. 들어가면 06:40 점검이 매일 찾고, 공식 확인되면 코어가 강한 근거로 쓴다(MU U2 선례). 예약 변경이라 그때 따로 직접 입력 승인.
2. **a-2 SCN 🔴 질문의 '효력 정지'에 '노출 축소 검토' 하위 선택 추가.** 연구 전제가 깨지는 날 노출 질문이 사장 앞에 놓인다. 자동 변경 없음, 예산 1.55·상한 1.9 그대로. MS 103행만 고친다.
3. **a-3 가설 3개 사전 등록 시험.** ① 신용(BBB 스프레드) 국면 ② SCN 트리거 과거 성적 ③ C3 레버리지 손절선 매도표(사장 선호, 5년 자료 조건 충족). 통과하면 K3와 forward shadow를 거쳐 그때 넣는다.

**고점 매도·회복 매수의 가격 신호 규칙은 바꾸지 않는다.** 이미 시험했다(고점: c-rule 10/09 지지 0개·사장 A, 회복: R-REC1 r3 10/16 NO_CHANGE). 오늘 받은 키움 SOXX·QQQ는 자료 등급이 높아졌을 뿐 같은 기간의 같은 가격 경로다(S4는 Nasdaq·Yahoo 2010~, s4-builder-report 32·61행 / c-rule은 2011~, c-rule-replay-results 14행). 새 정보는 가격 밖(신용·금리·유가)에 있고, C3는 시험한 적이 없는 가설이라 다시 연다.

**추천하지 않는 것:** b 방어 띠를 지금 K3로(정책 관문·SCN 지침·10/27 A 유지와 부딪히고, 지금은 주문표가 아예 나오지 않아 a보다 빨리 노출에 닿지도 않음 — 4절). c 확인 전 원장 주장을 약한 근거로(출처 판정이 출처당 최대 2건이라 원장 규칙 8에 걸림).

## 4. 다른 선택지

**b. 방어 띠 지금 추진(K3) — 비추천.** a-1·a-3에 더해, SCN 🔴 뒤 효력 정지 동안 노출 띠를 한 칸 내린다(예: 추가 ≤ 0.95·목표 1.25·축소 ≥ 1.55, 숫자는 K3에서 확정).
1. 정책: 국면에 따라 바뀌는 노출 상한은 'dynamic leverage cap'으로 관문 통과 전 금지 목록에 있고 면제 목록에 없다(정책 622~623행). 관문 목록 개정이 같이 필요하다.
2. SCN 지침: 시나리오로 예산·상한을 바꾸려면 K3와 FX-1009 동결 해제 뒤 별도 사전 등록이 필요하다(MS 85). 예산 1.55·상한 1.9는 그대로이고(MS 20), B− 하방 때 자세는 "기존 규칙 그대로"다(MS 50). 효력 정지의 뜻도 "노출·예산·권한·주문은 바뀌지 않는다"(MS 103)에서 바뀐다.
3. 고칠 곳이 넓다: CLAUDE.md 115행 "Premise and display only"(보호 경로 — 수동 경로, CLAUDE.md 129행), 통합 점검 3단계 "노출…에 쓰지 않는다"·알림 ⑪ "노출·예산 변화 없음"(integrated-check-daily.txt 26행, 예약 변경). 🔴 효력 정지를 코어가 읽게 하려면 연구 기록 스키마(최상위 additionalProperties false — manage-us-stock-strategy/schemas/auto-core-research-record.schema.json 7행)와 통합 점검의 기록 만들기 단계(integrated-check-daily.txt 40·76행)를 바꿔야 한다(예약 변경).
4. 10/27 21:10 A 유지(AD 92행)와 부딪힌다. 띠를 낮춰 코어 축소 주문표가 나오게 하는 것은 그때 채택하지 않은 C와 같은 길이다.
5. 효과 시점: 비교 모드라 주문표는 "켜" 전까지 입력되지 않고(CLAUDE.md 7~8행), "켜" 조건은 대조 OK 0/5다(AD 84행). 오늘 코어는 대조 미통과·S7 fail-closed로 주문표가 0건이다(2절). a보다 노출에 빨리 닿는 이득이 거의 없다.
6. 대기열: 권한·한도 변경은 한 번에 1건이고(CLAUDE.md 119행), 순서 duet-q4-coreinput → duet-q4-recon이 이미 정해져 있다(AD 34·163행). b의 K3는 그 뒤다. (AD 86행 recon-cap '병합 승인 필요'는 낡은 줄 — recon-cap3는 10/27 12:44 KST 병합, recon-i3-2026-10-27.md 40행.)
7. 근거 등급: 검증 없음. 1.55는 '사용자 승인 위험 예산, 미검증'(정책 679~680행)이지만 방어 띠는 관문이 막아 둔 종류라 같은 성격으로 넣을 수 없다.
- b를 고르면 K3 제안서 필수 항목: ① SCN 칸이 없거나 무효일 때 쓸 띠(매수만 막고 매도는 열지 않음) ② 🔴 효력 정지를 코어가 읽을 기록 — 코어 LLM 입력은 연구 기록뿐이라 그 안에 넣어야 한다(CLAUDE.md 48~50행, AD 140행) ③ 자동 복귀 조건 — 복귀가 사장 행동뿐이면 무응답일 때 목표 1.25가 SCN 만료(2027-06-30) 뒤까지 굳어 S7 ④ 1.55가 결정 없이 바뀐다(MS 6·103, AD 121행).

**c. 원장 주장(확인 전)을 약한 근거로 — 비추천.** a에 더해 확인 전 원장 주장을 코어 약한 근거 1종류로 센다. 판정이 끝난 결과가 출처당 최대 2건이라 원장 규칙 8("10건 미만이면 비율을 쓰지 않는다")에 걸린다(ledger-apply 20행). 연구 기록 스키마(schema 7행)와 통합 점검 기록 만들기 단계를 바꾸는 코어 입력 변경이라 K3 + 예약 변경이고, ledger-apply 바뀔 조건(강도 0 원칙 변경 + K3, 76행)을 쓴다. D3 예외 4건.

**d. 그대로(NO_CHANGE) — 무응답 기본.** 원장·연구는 지금처럼 공식 사실과 표시로만 쓰인다. C3 b의 재개 조건이 채워진 것은 기록만 남긴다.

## 6. 사장 결정 — rule-1028: 원장·연구를 어디부터 넣을지

이 결정은 방향만 정한다. 예약 지시문 변경과 정책·보호 경로 병합은 그 단계에서 사장 직접 입력으로 따로 승인한다(AD 28·30행).

- **a. 검증 먼저 + 사람 결정 연결(추천)** — a-1·a-2·a-3. 코어·정책·권한 변경 0, 예약 변경 1건(a-1 묶음), D3 예외 3건, K3는 시험 통과 뒤에만.
- b. 방어 띠 지금 추진 — a-1·a-3 + 방어 띠 K3(관문 목록·SCN 85·103행·CLAUDE.md 115행·통합 점검 3단계·연구 기록 스키마 개정 포함). D3 예외 3건, K3 1건(대기열 뒤), 예약 변경 포함. AD 92행 다시 열기.
- c. 원장 주장 약한 근거 — a + 코어 입력 K3·예약 변경. 비추천.
- d. 그대로(NO_CHANGE) — 무응답 기본 처분.
- 추천 이유: 지금 노출에 바로 닿는 길은 사장 결정뿐이고(비교 모드, 오늘 주문표 0건), a-2가 연구 경고를 그 결정 앞에 놓는다. a-1은 코어·정책을 건드리지 않고 원장을 코어의 강한 근거 길(MU U2 선례)에 잇는다. 노출을 자동으로 바꾸는 규칙은 정책과 SCN 지침이 시험을 먼저 요구하므로 a-3이 b로 가는 정식 길이고, C3는 사장이 정한 재개 조건이 채워졌다. 확신도 중간: a-1은 다음 규칙 개정 때부터 작동하고 보유 종목의 새 후보는 거의 없으며, a-3 ①②는 FRED 이력 길이에 달려 있다.
