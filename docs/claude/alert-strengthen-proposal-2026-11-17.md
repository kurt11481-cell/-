# 매도·매수 알림 강화 제안 (alert-strengthen-1117)

**부딪히는 결정(먼저 읽기)**: strategy-check-1105의 '하지 않음' 칸 "알림 문구('1.9 아래로')·예약·정책·코어 변경 없음"(active-decisions.md 137행) — 이 제안은 그 칸의 **'예약'만 이 일에 한해 푼다**(새 예약 1개). 알림 문구·정책·코어는 그대로. room-alert-1101(59행 "읽기 전용·푸시 없음")은 기존 두 예약의 약속이라 그 두 예약은 바꾸지 않는다. board-merge·org-setup의 '새 예약 작업' 제한은 사장 지시(2026-11-17 08:41 KST) 예외로 이 1개만.

## 1. 결론
- 사장님이 이미 정한 주문을 **'사장님 할 일' 장부**에 올리고, **월~금 19:30 KST**(키움 입력 창 18:00~23:30 안)에 계좌 비중으로 끝났는지 스스로 확인해 **안 끝났으면 매일 폰 푸시 + 사장실 글 + 버튼 카드**를 보낸다. 끝나면(코어 표시 SOXL 비중 ≤ 10%) 저절로 멈춘다.
- 버튼('주문 넣었음' / '오늘은 안 함')은 눌러도 되고 안 눌러도 된다. 끝났는지는 시스템이 계좌로 확인한다(사장에게 확인 일을 넘기지 않음 — 2026-11-03 지시).
- 무엇이 신호인가(반등 10%·5세션·E 1.9·급락 경보)는 **안 바꾼다**. 수량·가격도 시스템이 내지 않는다.
