- 상태: 초안. 독립 Judge 확인 전(표가 수량 제안처럼 읽히지 않는지). 이 파일은 M6 비교 카드가 아니다(이름에 m6·relative-comparison을 쓰지 않음 — 10/16 기한 알림의 존재 확인에 걸리지 않게).
- 목적(2026-10-03 사용자 결정): ① 현금 확보(신규 매수 자금) 우선. 가격 타이밍(②)은 참고.
- 가정: 매도한 MVLL 대금 전액으로 DELL을 산다고 가정(계산용). 수수료·세금·환율 미반영.

## 읽는 법·한계

- MVLL은 2배 노출이라 판 돈으로 1배 종목을 사면 N은 매도액 비중의 절반만 줄어든다.
- 10%·25%·50%는 임의 눈금이고, 경계 행은 규칙 지점의 산술이다.
- N 1.9가 "매수 전" 기준인지 "매수 후" 기준인지는 카드 문구만으로 확인하지 못했다 — 확인 필요(두 경계를 모두 표시).
- N 1.9, 종목당 0.4배는 S5 초안으로 미적용. 적용 여부는 사용자 결정.
- 종가가 잠정이라 확정 종가로 바뀌면 값이 달라진다.
- DELL은 현재 매수 시그널이 아니다: 가격 단서 1개(DL6, 잠정)만 충족, 요건 ②(N·현금)·④(M6 카드)가 막힘.

## 매도 후 순서 (현금 확보 목적)
