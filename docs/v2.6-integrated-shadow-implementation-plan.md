## Migration risks

- A formally valid but content-insufficient baseline could incorrectly produce `HOLD`.
- Historical technical or portfolio-fit opinions could leak into current authority.
- Web search snippets or Yahoo-origin pages could be misclassified as independent evidence.
- Manual or test runs could be counted as scheduled delivery sessions.
- Semantic changes could be mixed into an old Shadow cohort.
- Runtime or acceptance artifacts could accidentally retain broker facts or PII.

All risks fail closed. New baseline and Web features remain `SHADOW_ONLY`; no
threshold, quantity, fill, portfolio fact, or live execution state is changed.
